# EDF6VehicleCrew：NPC 开载具 / 开直升机，玩家随时顶替

EDFModLoader 插件，只支持 EDF.dll TimeDateStamp `0x678CCB46`（当前 Steam 版）。版本不符或代码签名对不上时，
插件只写一行 `REFUSED` 日志后自行退出，不改动游戏的任何内容。

## 仓库里的两个插件

| 插件 | 目录 | 做什么 |
|---|---|---|
| `EDF6VehicleCrew` | `src/` | NPC 开载具 / 开直升机，玩家随时顶替（本文下面全部内容） |
| `EDF6AutoTurret` | `autoturret/` | 防空车（KG6 克卜勒系）改高射炮并自瞄、玻尔斯对地自瞄；泰坦和带炮手座坦克的两门副炮自瞄，炮手座没人时自动开火（算驾驶员的）；关卡里 NPC 开的防空车换成 mod 版防空车，NPC 泰坦补上副炮。说明见 [autoturret/README.zh-CN.md](autoturret/README.zh-CN.md) |

两个插件各自独立，可以只装一个。根目录 `build.cmd` 一次构建两个，DLL 和 ini 都输出到 `build/Mods/Plugins/`（构建产物，不进仓库）。
`EDF6AutoTurret` 的武器 / 载具数据由你自己的游戏数据生成，不进仓库：

```
python autoturret\tools\build.py install      （游戏关闭时；--mods DIR 指定 Mods 目录）
python autoturret\tools\build.py uninstall    （按安装清单恢复，别的 MOD 的文件不动）
```

它写 `Mods/WEAPON/`（防空车、玻尔斯的呼叫和炮）、`Mods/OBJECT/`（关卡防空车 `V603_FLAK_*`、NPC 泰坦 `VEHICLE404_BIGTANK_AI`）以及 `WEAPONTEXT` 里这几辆车的说明行，只改自己的行；
做了什么记在 `Mods/.edf6at_data.json`（含备份），卸载照它恢复。这些数据不依赖插件也能用：插件被停用或删掉时，这些炮照原版方式开火，只是没有自瞄和近炸引信。

## 功能

1. **NPC 自动上车**：己方空载具空置 `CrewDelayMs`（默认 3 秒）后，会来一名 NPC 驾驶。用的是任务脚本让 NPC 坦克队出动的同一个原生调用
   `Vehicle_RideAi`（VehicleBase 第 50 槽）。只给玩家同队、离玩家 `CrewRange` 米以内的载具派人。
   - 武装装甲车格雷普斯（`Vehicle_Car`）原版有坦克同款驾驶 AI，只是它的找座位函数和别的车不同，以前一直没被登记、从没派过人；现在会派（同一类的轻卡、拖车头没有武器，不派）；
   - 深渊爬行者（`Vehicle502_GroundRobo`）原版完全没有驾驶 AI，NPC 坐上去由插件来开（`src/ground.cpp`，逆向见 `docs/ground-ai-re.md`）：没敌人时跟随玩家、停在 `GroundFollow` 米处；`GroundRange` 米内有敌人就转身、逼近到射程的七成、机炮和左右臂炮各自对准了才开火，弹道上有玩家不开火；离玩家不超过 `GroundLeash` 米。`GroundPilot=0` 关闭。
2. **玩家顶替 NPC**：原版不允许玩家坐已有人的座位。插件放开了这一限制，所以 NPC 坐着的载具也会照常出现上车提示，按上车键就能坐进去：
   - 被顶下的 NPC 优先挪到空的副座/炮手位；
   - 没有空位时它下车（NPC 会直接消失，这是原版对 AI 乘员下车的处理）；
   - 玩家下车后，过 `CrewDelayMs` 又会有 NPC 来开这台车。
3. **NPC 开直升机**：游戏本身没有直升机驾驶 AI（静态分析结论见 `docs/heli-input-re.md`），NPC 坐上直升机后由插件来飞：
   - **跟随**：保持在玩家旁 `HeliFollow` 米、头顶 `HeliHeight` 米处；
   - **护卫**：`HeliRange` 米内有敌人时，飞到玩家与敌人之间，机头对准敌人，开机枪、发导弹。不会隔着玩家开火。机枪固定朝机头方向、悬停时机头是平的，所以交战时它会压低到目标斜上方约 8 度（至少高出目标 8 米），只在机头（含俯仰）偏离目标 `HeliFireCone` 度以内、且目标在射程内时开火（506 的机枪子弹只飞 160 米）；
   - **盘旋 / 降落**：附近没有敌人时，玩家站着或只在小范围内走动（最近 10 秒的活动跨度不到约 70 米、或来回折返），它沿一个罩住玩家活动范围、外扩 `HeliFollow` 米的椭圆一直朝同一方向绕飞，不会跟着玩家的每次转身掉头；玩家持续朝一个方向走远时才转为在侧翼护航跟随。默认从不自己降落。把 `HeliLandMs` 设成毫秒数可打开降落：玩家原地站这么久、且周围 `HeliRange` 米内同样这么久没有敌人时，降落在玩家身边约 20 米处；玩家在 25 米内时不起飞，方便走过去顶掉 NPC、自己开；有敌人靠近立刻起飞；
   - **炮艇模式**：玩家坐在直升机副座、由 NPC 驾驶时，它不再跟随玩家（玩家就在机上），改为以直升机自己为中心，打 `HeliRange` 米内的敌人（同样是扫射航线）；附近没有敌人时原地悬停。
   - 只接管本插件派了 NPC 的直升机。任务脚本里的直升机（演出机、运输机）不受影响。
4. **战斗机**（`src/jet.cpp`，计划见 `docs/jet-plan.md`）：游戏里没有能被打中的固定翼飞机，插件用 506 直升机的机体（刚体、碰撞、HP、武器、坠毁）套上 BOMBER501 的外形，每帧直接写刚体的速度和角速度来飞：
   - **按机种飞**：对地攻击机巡航 150 m/s、攻击 180 m/s（原版轰炸机的速度）、最大 5 g、滚转较慢；制空战斗机巡航 210 m/s、攻击 260 m/s、最大 8 g、滚转快。接替轰炸机的那架按该轰炸机原版的速度飞（大多 180 m/s，神威 450 m/s）；
   - **像固定翼一样飞**：升力只沿机身「上」方向，要转弯先压坡度再拉杆；机头始终沿速度方向，不会侧滑、悬停；爬升掉速、俯冲加速；
   - **对地攻击机**：在 250 米高接近，目标进入约 850 米且在机头前方时俯冲（约 15–20 度），对准提前量点开机炮、发导弹，改出后爬升、飞出约 1.5 公里再转回来；
   - **制空战斗机**：优先打飞行敌人，按提前量追击，冲过头先拉开再回来；没有飞行敌人才去打地面；
   - 最低离地 25 米（俯冲时按改出所需高度提前拉起），不会飞到天花板以上；
   - 舵面跟着机动动：外翼后缘一对升降副翼，拉杆时两侧同时上翘，滚转时一上一下（bomber501 是无尾飞翼，没有方向舵和平尾；模型由 `pylib/mdb_jet.py` 从本机的 bomber501 切出，格式见 `docs/mdb-format.md`）；
   - 机炮每门 1800 发、导弹 20 发（游戏自带数值）；只在机头对准、没有侧滑时开火，弹道上有玩家时不开火；同一批次的战机（关卡放置的为一批，同一次空袭呼叫的护航机和轰炸机为一批）互相不挡子弹——子弹直接穿过僚机（`docs/bullet-pass-re.md`），其它友军照原版会被误伤；
   - 不补弹。弹药打光、燃料用完（`JetFuelSec`）或血量低于 25% 时，爬升并朝远离玩家的方向全速飞走，**离玩家 1.6 公里以外才删除**（飞到世界边界 2.4 km 附近时，只要离玩家 900 米以上就立即删除；超过 2.7 km 一律删除），不会在面前消失；
   - **远处也看得见**：游戏只把 1000 米内的载具交给近景相机画，飞出 1000 米的战机原本会消失；插件给战机的渲染节点打开原版的远景渲染位（SGO `FarRender` 同一个开关，`docs/jet-model-re.md` §8.4），远景相机画到 20 公里；
   - 战机不受任务移动区域（空气墙）限制，能像原版轰炸机一样飞出地图边缘（游戏每帧把载具夹回移动区域，插件把战机的收缩半径 `veh+0xE00` 设为 -1e6 关掉这一夹紧，见 `docs/map-edge-re.md`）；物理世界在 ±3 km 处结束，战机在 ±2.4 km 前转弯。撞到建筑或别的飞机时，以碰撞后剩下的速度顺着障碍飞，不会顶着障碍悬停或横着滑。
5. **空袭接管**（`src/airstrike.cpp`，逆向笔记 `docs/mission-airstrike-re.md`）：安装器（见「安装 / 卸载」）会在 `Mods/OBJECT` 生成 `EDF6VC_JET_STRIKE.SGO` / `EDF6VC_JET_FIGHTER.SGO`，以及带舵面的战机模型 `EDF6VC_JET.MRAB`（只有这些战机用，原版轰炸机不受影响；测试场之后安装的战机也用它）。
   - **轰炸机由喷气机真投弹**：空袭兵的轰炸机支援（KM6、神威、维斯塔、火卫一等）和任务脚本的低空扫射机（RM034A/B、M116、M118）里的每一架原版轰炸机，都换成一架攻击机，从原版的进场点、沿原航向、按原版高度和速度飞投弹航线；到原版开始投弹的距离时打开弹舱，**炸弹从喷气机身上落下**（弹种、发数、间隔、伤害、散布、归属与原版完全相同）。投完立即退场：沿投弹航线继续飞、爬升离开；
   - 原版的空袭兵呼叫不会再自动附带护航机（2026-10-03 删除）；要战机、直升机，用下面的呼叫武器。
6. **空袭兵呼叫武器**（一份数据 `tools/calls.py`：`tools/call_weapons.py` 据此写武器行，`tools/gen_calls.py` 据此生成插件侧 `src/calls.inc` 的 `kCalls`）：武器表里共 21 行，其中 19 种呼叫（类别 312，和 KM6 同类，大多每种飞机一把「守点」、一把「跟随」），另 2 行是玩家喷气机的载具请求（见「玩家战斗机」）；数目以 `tools/calls.py` 为准：
   - 守点：飞机围着呼叫标记（投出去的信号弹落点）巡逻、打标记附近的敌人；跟随：围着玩家打；跟随版装填更慢、等级更高；
   - 守点直升机不再悬停：以 `HeliGuardRadius`（默认 120 米）为半径、`HeliGuardSpeed`（默认 12 m/s）绕标记盘旋，机头沿圆周，Brute 内侧的门炮一直朝着标记；两架守同一点时在圆上对置。从远处来时先直飞、近了顺势切入圆周。交战时 Brute 继续绕圈，圆心移向目标（目标落在圆内半径一半处，门炮够得着），打完回到标记；506/409 守点时照常扫射、打完回到盘旋。离地/避障照旧。`HeliGuardRadius=0` 恢复悬停；
   - 截击机 ×2、对地攻击机 ×3、多用途 ×3、制空战斗机 ×4、空中航母 ×1（6 个无人机位，共 18 次出击）、直升机 ×2（守点是 410 Brute，跟随是 506 Eros）；越强装填越久、等级越高（截击机守点 Lv 0.3 / 900pt … 航母跟随 Lv 2.0 / 3450pt）；
   - 撤离以弹药为主：不补弹，打光就走（空母是 18 次无人机出击用完、无人机都回来后走）；其次是油料（喷气机 240–300 秒、直升机 360 秒、空母 600 秒）和重伤（血量低于 25%）。撤离时飞离玩家，离远了才删除；
   - 空母用 V508 运输机的四旋翼机体，悬停在锚点（守点：标记；跟随：玩家）上空约 150 米，机头对着目标，放无人机；四个旋翼喷口挂原版 Booster 尾焰（随推力变化），加减速时低头/抬头、转弯时向内压坡度（最多约 17°，`docs/jet-model-re.md` §8.1–8.2）；
   - **自爆无人机母舰 / 人偶无人机母舰**（2026-10-04 追加，各一把守点、一把跟随，排在原 12 把之后）：同一架空母，放出的是旋翼近炸无人机，不开枪，直接悬停着冲向目标，进入 8 米（人偶 6 米；被敌人身体挡住时 4 倍距离内）就引爆一发点爆炸药（基于 409 直升机炸弹 `GrenadeBullet01`，到期必爆：自爆无人机 1200 伤害 / 15 米半径，人偶 3000 / 25 米），0.3 秒后机体删除，母舰该位 10 秒后补一架（18 次出击用完照常撤离）。爆炸伤害按队伍过滤，不伤友军；
   - 人偶无人机机腹下 4 米挂一个 hololive 招募员人偶（Ayame / Mio / Fubuki 轮流，原版诱饵对象 `e_throw_decoyscreen_*.sgo`，队伍 4：敌人会去打它），人偶自己唱歌跳舞（原版 random_action），跟着无人机走，血量 2000，随无人机一起删除。人偶是 DLC 内容：没装对应 DLC 时人偶造不出来，无人机照常飞去自爆（日志 `JET doll ... not made`）。人偶无人机巡航 25 m/s（慢，先把敌人引过来），自爆无人机 70 m/s；
   - **潜水母舰支援**（`EDF6VC_CALL_SUB`，`src/subcarrier.cpp`，逆向与设定对照见 `docs/subcarrier-re.md`）：任务演出物件 EV603 潜水母艦按原尺寸（全长 1664 米，和原版任务里同大），套 506 机体，船体血量默认 100000（ini `SubHullHp`：SGO 里是 30000，出生时按比例抬到这个值），指挥塔上方显示船体大血条（名称和血量%），每个甲板部件上方各一条小血条（打坏时显示 DOWN 和修复倒计时）。在信号弹前方 1000 米浮上，甲板（碰撞箱顶面，宽 242 米、长 1664 米的平面，主甲板高约 193 米）能站人，指挥塔和炮塔不实心；左舷两座炮塔各自转向目标（浮在水上时整艘不转艏，保持甲板平稳；搁在陆地上时转艏对准目标），机炮按炮口实际朝向、射程约 580 米内开火，导弹舱的追踪导弹（射程约 2000 米，打空 12 秒后在舰内装填）自动攻击；玩家走远 1500 米外以 25 m/s 跟过去，1000 米内停下。不撤离，留到任务结束，同时最多 3 艘。原作没有它放飞机或无人机的设定，所以不放；模型由安装器生成（约 39 MB）；
   - **炮舰机**（`EDF6VC_CALL_GUNSHIP` / `_F`，2026-10-04 追加，守点、跟随各一把，排在玩家喷气机请求之后；0.7.0 曾把它们插在玩家喷气机请求前面，那样装过的照样原位升级）：一架 bomber401 外形的喷气机，在锚点（守点：标记；跟随：玩家）上空 350 米、半径约 600 米大圈盘旋，不俯冲、不开机炮；每 2.5 秒从机身向 1800 米内的地面敌人打一发任务里鲸鱼炮舰的炮弹（`DEMOGUNSHIPFIREE25`，伤害 300），撤离时停火。燃料是战机的 3 倍。炮舰机有自己的机体文件 `EDF6VC_JET_GUNSHIP.SGO`（由安装器生成；没生成时这把呼叫叫来普通战斗机）；开不开火只看喷气机自己的条件，与直升机的 `HeliFire` 无关；
   - **局内切换呼叫**：任务中按 `]` / `[`（ini `CallNextKey` / `CallPrevKey`，虚拟键码，0 关闭）在「按各武器原样」和 19 种呼叫之间切换，之后任何一把呼叫武器开火都叫来选中的那种；游戏窗口上方显示当前选择（独占全屏时看不到，但照样生效，日志 `CALLS pick`）；
   - **落水救援**（ini `SeaRescue` / `RescueBelow` / `RescueAutoBoard`，`docs/rescue-re.md`）：有潜水母舰在场时，步行玩家落海（低于 `RescueBelow` 持续 1.5 秒），从母舰甲板上空飞来一架布鲁特（410，有两个侧门座位），降到玩家身边悬停，玩家自己按上车；上车后飞回甲板上空约 8 米悬停，玩家自己跳下。插件从不移动玩家（不传送）；`RescueAutoBoard=1` 时，侧门上车点进入原版上车距离内后替玩家按一次上车键；
   - 安装：游戏关闭时运行安装器（开发者：`python tools/make_jets.py` 生成呼叫用直升机 `EDF6VC_HELI_410/506.SGO`、近炸无人机 `EDF6VC_JET_BLAST/DOLL.SGO` 和炸药 `EDF6VC_BLAST/DOLL_CHARGE.SGO`，`python tools/call_weapons.py install` 写武器行）。存档按行号记武器，所以本插件的行一旦装上就不再挪动：已有的行（按 ID 找，不要求连续）原地更新，缺的行追加在表末尾，后面有别的 MOD 的行也没关系；其它行的内容逐行核对不变。新呼叫只会追加在 `tools/calls.py` 末尾（CI 的 `tools/selftest.py` 检查历次发布的顺序）。插件在每次读档时把它们设为已拥有（不用在任务里捡箱子，第一次进本部会带 NEW 标记，出击一次后消失）；
   - **卸载不影响正常游玩**：这些武器本身就是 KM6 的复制品，只删插件时它们照原版 KM6 轰炸机呼叫。安装器「卸载」→ 1 连武器一起删时，武器表里本插件的行变成「已卸载」占位行（原版 KM6 / N9 Eros 的行，名字标明已卸载）：行号不变，存档装备着也不会崩溃，别的 MOD 的行不会前移、也不会继承这些行的「已拥有」；以后重新安装会用回这些行。真要删掉行只能用 `python tools/call_weapons.py uninstall --delete-rows --unequipped`，而且只删表末尾、后面没有别人的行（之前必须在所有存档里卸下这些武器）；
   - 插件启动时检查武器表，有呼叫武器的行缺失（例如别的 MOD 覆盖了 `WEAPONTABLE.SGO`）会在日志里写 `CALLS ... missing`，关掉游戏重新运行安装器选「安装」即可补回（插件自己不写共享的武器表）；`python tools/call_weapons.py check` 列出每一行的位置、是否被挪过；
   - 写武器表是一个整体：武器表、5 个武器说明和呼叫武器 SGO 要么全部写入、要么全部保持原样（中途出错当场恢复，进程被杀则下次运行先恢复）。武器说明和武器表行数对不上时（例如旧版本安装中途失败），安装器会说明原因并提议把这几个文件恢复到第一次安装本插件之前的备份（`call_weapons.py repair`）；
   - 联机时只有呼叫者自己的游戏里出插件的飞机，其他玩家看到的是原版 KM6 轰炸机。
   - 炮击、导弹、卫星激光这类「天降弹」没有飞机，保持原版；
   - 没生成 SGO、或这一关没能预载时，自动退回原版轰炸机。
7. **玩家战斗机**（`src/playerjet.cpp`，逆向与置信度见 `docs/player-jet-re.md`；ini `PlayerJet` / `PlayerJetInvertPitch`）：两架给玩家自己开的喷气机，和 NPC 战机一样是 506 机体，空着停放，插件不派 NPC：
   - **玩家战斗机**（深色截击机外形，耐久 1400，起飞 75 m/s、最低 65、最高 260 m/s、最大 6 g（带只在俯仰方向的迎角，机头不侧滑）、滚转快）；**玩家攻击机**（带舵面的 bomber501 外形，耐久 2200，起飞 70、最低 60、最高 240 m/s、最大 5 g）；武器都是两门机炮 + 导弹（数值以 `src/playerjet.cpp` 的 `kKinds` 和 `pylib/vcobjects.py` 的 `JETS` 为准）；
   - 来源：测试场生成列表里的「玩家战斗机 / 玩家攻击机」；或空袭兵的载具请求武器「玩家战斗机 / 玩家攻击机」（类别 308，同 N9 Eros 请求，运输机把它空投到信号弹处）；
   - **操作**（原版上车键上下机，其余沿用直升机的键位）：空中按 Ace Combat 的方式——左摇杆前推 / 上升键（键盘 W / 上升）按住 = 加力到满，左摇杆后拉（键盘 S）按住 = 收油门并减速，都松开 = 回到巡航油门（55%）；地面上油门是一根停在原位的杆（前推加、后拉减，用来滑行、停住）；右摇杆 / 鼠标左右 = 转弯（自动压坡度），右摇杆 / 鼠标上下 = 俯仰（沿机体自己的上方拉：正飞时爬升、倒飞时往下，一直拉就是筋斗；默认往前推 = 机头向下，`PlayerJetInvertPitch=1` 反过来）；左摇杆左右（键盘 A / D）= 横滚（绕机头转，按住同时拉杆就是滚筒机动），松开横滚且不拉杆时自动回正；输入经过约 0.12 秒的平滑（鼠标每帧的移动量忽大忽小，不平滑时飞机会抖）；地面滑行时左右摇杆都能转向；主射击 = 机炮，副射击 = 导弹（沿机头方向）。驾驶时屏幕下方显示速度、离地高度、爬升率、耐久、油门条和按键提示；
   - **碰撞箱**：按模型实际外形（含机翼、机头、机尾）在生成机体时量出，和看到的飞机一致；
   - **起飞**：地面上加油门滑跑，机头轮转向；到起飞速度后拉杆离地，油门过 60% 时再快 20 m/s 会自己离地；
   - **飞行**：一直向前飞，不会失速、不会悬停（最低速度兜底），爬升掉速、俯冲加速、急转掉速；最陡约 70 度，不翻筋斗；不受任务空气墙限制，飞到 ±2.4 km 世界边界时沿边界转向（不会停在边界上），天花板处贴着滑；
   - **降落**：收油门减到降落速度以下、下沉不超过 10 m/s、机翼基本水平、机头不朝下扎时接地即降落，之后滑跑，收油门停下；
   - **坠毁**：下沉太快、太快、坡度太大接地，或撞到建筑 / 敌人（空中，或地面滑跑超过 20 m/s 时），按冲击扣最大耐久的 20%–150%（1 秒内只算一次），扣到 0 机体按原版死亡流程爆毁；落水算坠毁，浮在水面约 5 秒解体；
   - **撞击伤害**：撞到东西（不含着陆、撞地、落水）时，撞击点附近（战斗机约 10 米、攻击机约 12 米）的敌人受到「本机这次掉的耐久 × `PlayerJetRamDamage`（默认 1.0，0 关闭）」的伤害，归属是玩家，不伤友军（用安装器生成的 `EDF6VC_IMPACT_*.SGO`，没安装时只扣本机、不伤敌人）；
   - 玩家下机后它原地停着（空中下机会掉下去）；
   - 安装：安装器一并生成 `EDF6VC_PJET_FIGHTER/STRIKE.SGO` 并写入 2 行载具请求（连同呼叫武器共 21 行）；测试场：启动器里给「玩家战斗机 / 玩家攻击机」填数量后安装（NPC 驾驶那一栏也按空机放）。

8. **载具状态显示**（`src/hud.cpp`，ini `VehicleHud` / `VehicleHudCount` / `VehicleHudRange`，逆向笔记 `docs/hud-re.md`）：离玩家 500 米内最近的 6 台 NPC 驾驶的友军载具，头顶显示「机种 血量%  G 机炮余弹  M 导弹  D 剩余无人机出击  F 剩余燃料」一行和一条血条（没有的项不显示，燃料只对插件限时的喷气机、呼叫直升机显示，撤离时显示 RTB）；潜水母舰在屏幕右侧有自己的面板（深蓝底、青色边）：船体大血条和数值、4 个子系统各一条，打坏时显示 DOWN 和修复倒计时。所有血条都带黑边、十分刻度和掉血余影（刚掉的血先显示成浅色，约 0.5 秒后流走）；头顶的血条越近越大、越远越小（有上下限）。用游戏自己的 HUD 绘制（血条的四边形和救援提示的文字），独占全屏也能看到；日志 `HUD`（Debug=1）记下显示了什么。
10. **敌方战斗机**（测试场生成列表里的「敌方战斗机」，`EDF6VC_JET_ENEMY_FIGHTER.SGO`，标记 7020）：和截击机同一外形与武器，由插件驾驶；第一次出现时插件把它设成敌方阵营（team 1），于是它绕着玩家飞、攻击玩家和友军飞机，友军喷气机也会去打它（选目标都按「本阵营的敌人」）。
9. **喷气机音效**（`src/jetsound.cpp`、`src/jetaudio.cpp`，ini `JetSound` / `JetSoundVolume`，逆向笔记 `docs/sound-re.md`）：插件的喷气机（AI 战机、无人机、炮舰机、玩家战机）带一个跟着飞的引擎声，由插件自己播放（游戏里没有喷气引擎声，也没有多普勒）：机头方向主要听到涡轮尖啸、机尾方向主要听到轰鸣，飞得越快越响、音调越高；飞掠时按喷气机和镜头的相对速度做多普勒变调（迎面来时高，飞过去后低）；按镜头朝向分左右声道，远处变小变闷；音量跟随游戏的主音量 × 效果音量，游戏暂停时静音。默认是插件内置合成的声音，在 DLL 旁边放 `EDF6VehicleCrew_jet.wav`（16 位 PCM）就改用这段录音（例如 Freesound 上 CC0 的喷气机录音）。另外：喷气机原来一直在放的直升机旋翼声已去掉；导弹改用空袭的导弹发射声和持续的推进声（`EDF6VC_JET_MISSILE.SGO`）；NPC 驾驶的载具锁定目标时的提示音不再传到玩家耳边（原版只对 AI 士兵静音，对载具没有）。旋翼声、导弹声来自安装器生成的文件，升级后要重新运行安装器选「安装」才有。

所有参数都在 `EDF6VehicleCrew.ini`（中文注释）。游戏运行中改完保存，约 1 秒内生效。

## 安装 / 卸载

**玩家：解压即用，不需要 Python。** 前提是游戏目录已装好 EDFModLoader。

1. 退出游戏，解压发布包 `EDF6VehicleCrew-<版本>.zip`，双击 `EDF6VehicleCrew安装器.exe`，输入 1。
   它自动在 Steam 库里找游戏目录（也可以把 exe 放进游戏目录再运行；都找不到会让你粘贴路径），然后：
   先用你本机的 `Root.cpk`（只读，不修改）在内存里生成战机 / 直升机 / 无人机 / 潜水母舰和呼叫武器，并检查武器表；
   全部成功才开始写：生成的模型（每个文件原子替换）→ 武器表和武器说明（整体写入，见上）→ 最后才换插件 DLL。
   已有的 `EDF6VehicleCrew.ini` 不覆盖：你的设置和注释原样保留，只在末尾补进新版本新增的设置（带默认值和说明）。
   这些资源不能预先打包：它们由游戏本体文件派生，武器表又是各 MOD 共用的，只能在你机器上现场生成。
   生成的文件由 `Mods/.edf6vc_files.json` 登记归属（安装器、测试场等谁在用），卸载只删没人再用的文件。
2. 卸载：运行安装器输入 2。选 1 连呼叫武器一起删（武器行变成「已卸载」占位行，存档装备着也不会崩溃）；
   选 2 只删插件，武器照原版 KM6 轰炸机呼叫，不影响游玩。
3. 游戏运行中安装器会拒绝执行，不会替你关游戏。
4. 升级：退出游戏后直接运行新版安装器选「安装」即可，旧版装的武器行原位更新、新行追加在表尾；新版本新增的模型（例如炮舰机 `EDF6VC_JET_GUNSHIP.SGO`、撞击装药 `EDF6VC_IMPACT_*.SGO`）要这样重新安装后才有。

**开发者**：`build.cmd` 构建到 `build/Mods/Plugins/`（DLL 和 ini 都在那里，ini 由 CMake 自动复制）。
`python tools/build_release.py` 用 PyInstaller 打出 `release/EDF6VehicleCrew-<版本>.zip`（安装器 exe 内含 DLL 与 ini）；
版本号只有一处：`CMakeLists.txt` 的 `project(VERSION)`（DLL 自报的版本也来自它）。CI 每次推送都打同样的安装器包，
推 `vX.Y.Z` 标签时要求它与 `project(VERSION)` 一致。不打包时也可直接 `python tools/installer.py install`（从 `build/` 取 DLL，没构建会提示先运行 `build.cmd`）。
`python tools/selftest.py` 是安装链的自测（CI 里跑）；改了 `tools/calls.py` 后运行 `python tools/gen_calls.py` 重新生成 `src/calls.inc` 并一起提交。

- 与 `EDF6AutoTurret` 共存：两边都 hook 了坦克的第 55 槽，本插件会串在它后面，也就是先执行它、再执行本插件，所以加载顺序无所谓。

## 批量实测清单

**先离线（单人）测**。联机时 NPC 是由主机生成的，客机这边会不会重复生成还没验证过。

日志在 `Mods/Plugins/EDF6VehicleCrew.log`。实测时把 ini 的 `Debug` 改成 1（默认 0），下表很多日志行只在 `Debug=1` 时出现。

| # | 怎么测 | 期望 | 日志关键词 |
|---|---|---|---|
| 0 | 启动游戏进主菜单 | 不崩溃 | `HELI profile=1`、`HOOK crew findSeat=23/23 prompt=1` |
| 1 | 进任意任务 | — | `HOOK inputs=16`（若有 `chaining onto` 说明串在了 AutoTurret 后面，属正常） |
| 2 | 呼叫坦克（空降兵）或开着坦克再下车，走开等 3 秒 | 一名 NPC 上车并开走 / 开火 | `CREW v=... 403_Tank` |
| 3 | 走到 NPC 坦克边 | 出现上车提示；按键能上去，NPC 挪到副座 | `BUMP ... moved to gunner seat`（没有副座则为 `kicked`） |

| 9 | 把 ini 的 `HeliLandMs` 改成 6000，站着不动 6 秒、附近没有敌人 | 降落到你身边约 20 米处 | `land`，`ground=1` |

如果直升机飞得不对，把整个 `.log` 发回来。飞控每秒记录模式（`orbit` / `follow` / `run` / `aim` / `hold` …）、高度、爬升率、油门、悬停油门、旋翼转速、三个摇杆量和偏航学习状态。
飞控增益（旧版的 `HeliMoveGain` / `HeliBrakeGain` / `HeliClimbGain` / `HeliHoverLearn`）已固定为常量，ini 里还有这几项会被忽略（日志说一次）。常见现象：
- **一直原地打转**：偏航方向学反了，日志里应能看到 `yaw sign flipped`；
- **飞不起来**：看 `rotor` 和 `thr` 两项。

日志与配置的约定：
- 日志超过 32 MB 时改名为 `EDF6VehicleCrew.log.1` 再写新的；
- ini 每项读入时检查范围，超出的值改成最近的合法值，日志写一行 `CONFIG ... out of range`；`Enabled=0` 之后改回 1 也能热生效；运行中把 `JetPilot` 改成 0，在飞的插件战机会立即删除；
- 某个每帧步骤出了内存访问异常时，只跳过这一步（这台车这一帧），日志写 `FAULT <步骤>`（每步每 10 秒最多一行，带累计次数）；
- 每次进任务（含重试）都有一行 `MISSION start`：上一关的逐载具状态在这里清空。

## 测试场（testrange/）

双击 `testrange/测试场.bat` 打开启动器（需要 Python 3，自带的 tkinter 即可）：

- **载具**：每种填数量，放在玩家出生点 30–160 米的平地上（最多 12 台）。可以设等级。
- **敌人波次**：选种类、每波数量、场上少于几只才刷下一波、开局延迟、间隔、等级。开局先留 30 秒给你试车。
- **安装**：先在「装进」里选覆盖哪一关，再点安装。生成 `Mods/MISSION/EDF6/<任务>/MISSION.AC`，地图用 M045 那片平原
  （`ig_Heigen601`，阴天），点位文件 `MISSION.RMPA` 从你本机的 `Root.cpk` 里取出来一起放进去。难度随意。
  - **第 14 项「转机」（RM015，默认）**：空袭兵呼叫的载具和空中支援会到。测直升机用这个。
  - **第 2 项「非法入侵者」（M001）**：新存档也能进；但开头几关是战后废土剧情，空袭兵的呼叫会被接受却永远不来。
  这一关不会自己结束，测完从暂停菜单撤退即可。
- **卸载**：删掉测试场所在的目录，原任务恢复原样。目录里有 `EDF6TestRange.txt` 才会删；别的 mod 放在那里的文件不会动。
- 设置保存在 `testrange/testrange.json`，下次打开会还原。
- **强制装备**：勾「启用」后选兵种和每一格的武器 / 支援装备 / 载具（下拉框可打字筛选，列表来自当前生效的武器表，中文名）和星级。
  启动器在 `Mods/Plugins/` 写一个 `EDF6TestRange.loadout.ini`，插件在任务预加载和建人这两次调用里临时把装备写进内存、调用完立刻还原，
  所以**存档、主菜单、出击前的装备界面都看不到改动**，没拥有的武器也能装。只对离线 1P 生效，**而且对所有任务都生效**：
  不用时取消勾选再点安装，或点卸载（两者都会删掉这个 ini）。日志里每次生效有一行 `LOADOUT preload/create class=...`。
  勾「开局补满」时，进关建人后再把所有武器弹药和空袭兵的载具呼叫次数补满（`LOADOUT refill weapons=N`），不用先攒点数。

### 自动实测（run_test.py）

一条命令：启动游戏 → 认画面走菜单（标题、存档、模式这些绿色菜单一路回车；作战指令总部 → 出击 → 任务列表按到顶再往下数到测试场那一项，
核对任务说明文字的参考图后才确认）→ 选上次的难度 → 进关后按脚本操作、截图 → 退出游戏 → 汇总插件日志。

```
python testrange/run_test.py --heli --act "wait:3 key:z:300 wait:60 shot:t60"
```

- `--heli`：空袭兵、载具格 N9 风神直升机、开局补满、不放脚本载具（`--enemies` 再加敌人波次）。`--plan 文件` 用启动器存的方案。
- `--act`：`wait:秒`、`key:键[:毫秒]`、`hold:mouse1:毫秒`、`look:dx:dy`、`shot:名字`、`repeat:N:键`。
- `--trace` 菜单每一步截图；`--keep` 结束时不退出；`--attach` 接着用已在标题画面的游戏；`--cdb` 挂调试器抓崩溃转储。
- 第一次换到新的槽位先跑 `--learn`：走到那一项后存下说明文字参考图（`testrange/refs/<任务>.png`）并停下，确认截图里光标对了再正常跑。
- 结果在 `testrange/runs/<时间>/`：`summary.txt`（各类日志行数和首末几行）、`log.txt`、截图。
- 发键前都会确认 EDF6 在前台，不在就拒绝发键。启动前会等 Steam 的 `RunningAppID` 清零（刚退出时立刻再启动会被 Steam 拒绝）。
- 退出走 Alt+F4 对话框：标题菜单里用左方向键、任务中只认 A 键切到「是」，按截图确认选中了才回车；没退成会在 summary 里写明。

## 源码

- `src/plugin.cpp`：入口、配置、日志、代码签名检查。
- `src/crew.cpp`：NPC 上车（Vehicle_RideAi）、顶替（slot 49 FindSeat + 上车提示访问器）、每帧入口（slot 55 串接）。
- `src/heli.cpp`：直升机自动驾驶。
- `src/playerjet.cpp`：玩家驾驶的战斗机 / 攻击机飞控（`docs/player-jet-re.md`）。
- `src/jet.cpp`：战斗机飞控与运行时生成；`src/airstrike.cpp`：空袭接管与呼叫武器（`src/calls.inc` 由 `tools/gen_calls.py` 生成）；`tools/make_jets.py`：生成战斗机 SGO（`pylib/vcobjects.py`）。
- `src/loadout.cpp`：测试场强制装备（`docs/loadout-re.md` 是逆向笔记，`docs/weapons.csv` 是武器 ID 表）。
- `docs/re-notes.md`：上车门槛与座位函数的逆向笔记；`docs/heli-input-re.md`：直升机输入块的逆向笔记。
- 构建：`build.cmd`（MSVC x64 + Ninja，RelWithDebInfo），产物输出到 `build/Mods/Plugins/`。
- `tools/`：安装链（`installer.py` 安装器、`calls.py` 呼叫武器数据、`call_weapons.py`、`make_jets.py`、`make_sub.py`、`build_release.py`、`selftest.py`）和逆向用的小工具。
- `pylib/`：`tools/` 和 `testrange/` 共用的 Python 库：读 `Root.cpk`（`cpk.py`、`crilayla.py`、`rootcpk.py`，edf6-cpk 部分的许可见 `pylib/LICENSE.edf6-cpk`）、SGO 读写（`sgo.py`）与 DSGO 读写（`dsgo.py`）、模型（`mdb.py`、`mdb_jet.py`、`jet_models.py`）、生成的载具（`vcobjects.py`）、生成文件的归属登记（`ledger.py`）与原子写入、运行中检测（`modfiles.py`）。
- `testrange/`：测试场启动器（`gen.py` 生成脚本）。
- `probe/`：早期调研用的任务脚本探针（用 CreateFriend 生成直升机），已不需要，也未安装。
