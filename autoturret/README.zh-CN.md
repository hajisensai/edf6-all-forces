# EDF6：防空车一定要能防空

[English](README.md)

原版 KG6 克卜勒是 EDF6 的防空车，却打着又慢又不会爆炸的实心弹，对空中目标大多打空，耐久还不到同级坦克的一半。
这个 mod 让它真正能防空，并把 DLC 的 KG7 玻尔斯改成会自己瞄准的对地榴弹车。

由两部分组成：

- **EDF6AutoTurret.dll**：[EDFModLoader](https://github.com/BlueAmulet/EDFModLoader) 插件。炮塔自己瞄准：
  直接从游戏的敌人列表里选目标，计算提前量，按炮弹的抛物线解算仰角，并用前馈控制炮塔，炮弹不再拖在横穿目标的身后。
  高射炮弹带定时引信（目标距离处空爆）、近炸引信和触发引信。按住瞄准摇杆可以手动瞄准，松开后炮塔立即接管。
  还会辅助**泰坦和游骑兵带炮手座的坦克的副炮**：真实、存活的 NPC 坐进炮手座后，在控制该 NPC 的机器上瞄准和开火；空座、假人、死亡乘员不会开火。玩家坐炮手座时可启用瞄准辅助，扳机仍由玩家控制。这部分不需要武器文件，原版载具直接生效。
- **武器数据**：直接覆盖原版载具自己的文件，不新增武器行。`WEAPONTEXT` 里这几辆载具的说明会改成新数值；只改它们自己的行，并叠加在 `Mods` 里已有的表上，改表的 mod 的内容会保留。
  数据可以单独工作：这些炮是原版游戏照常会开火的普通炮，只带一个只有插件读取的标记。没有插件时（删掉、关掉，或游戏更新后插件拒绝加载），克卜勒和玻尔斯照样能开火、打新炮弹，只是不自瞄，高射炮弹在最大射程处空爆。

## 改了什么

| 载具 | 改动 |
|---|---|
| KG6 克卜勒、E、F、YE、YF | 改为高射炮：爆炸弹（爆炸半径 8m），近炸／定时／触发引信，射程 480m。射速减半、单发伤害 ×2（账面 DPS 不变，同屏爆炸减半）。耐久 ×2。炮塔转速用 DLC YF-HV 的。优先打空中目标。 |
| 关卡里放的克卜勒（NPC 驾驶的、可搭乘的关卡载具） | 换成 mod 版 KG6 克卜勒：用它的高射炮（替换 NPC 克卜勒自带的 1 伤害机炮），耐久在关卡自身倍率上再 ×2，快速炮塔。 |
| KG6 克卜勒 YF-HV（DLC） | 只加自瞄；保留它的高速实心弹、耐久和炮塔。 |
| KG7 玻尔斯、玻尔斯 B（DLC） | 对地模式自瞄：优先打地面目标，按抛物线瞄准，保持原版触地爆炸。耐久 ×2，爆炸半径 4m → 6m，爆炸可以破坏建筑。 |
| 泰坦（全部，含 DLC 副炮） | 仅插件：真实 NPC 炮手自动瞄准和开火；玩家炮手保留扳机，空座与假人不自动开火。主炮不动。 |
| NPC 泰坦（如第 64 关「殿军」） | 数据：原版 NPC 泰坦的两个副炮位是空的；`build.py` 把玩家泰坦的两门副炮装上，真实 NPC 进入炮手座后才由插件瞄准、开火。 |
| 关卡里放的坦克和机车（NPC 泰坦、艾普瑟隆、布莱克战车、霸里亚斯、尼库林格；可上车的泰坦、布莱克战车、奔驰装甲机车） | 数据：原版关卡文件把开炮时的车体后坐力（车被往后推、前后晃）写成 0 或与玩家版不同；`build.py` 让每个炮位用玩家呼叫版同一门炮的值（`tools/npc_recoil.py`，逆向见 `docs/recoil-re.md`）。 |
| 游骑兵带炮手座的坦克（Vehicle403） | 仅插件：两挺副机枪，同上。单座坦克（空爆兵的、Vehicle601）没有副炮。 |
| 喀秋莎火箭炮车（EDF6VehicleCrew 的载具，`tools/make_katyusha.py`） | 仅插件，**只瞄 NPC 开的车**：发射架带「高抛」标记（7303），优先打地面目标，走**高抛弹道**：仰角取两个解里大于 45° 的那个；高抛解超出发射架的仰角上限（80°）时才退回低伸解（目标太近）。玩家自己开的喀秋莎插件完全不碰（`PlayerLofted`）：游戏的镜头跟着座位的瞄准轴走，插件转瞄准轴就是替玩家转镜头（以前抬到 75°～79° 时镜头一直看天）；玩家用镜头瞄地面点，由 EDF6VehicleCrew 只把发射架骨骼抬到高抛仰角（`src/katyusha.cpp`）。 |

标记：炮的 `LockonTargetType` 写成插件才读的标记（`common/edf/weapon.h`）：7301 防空炮（优先空中目标、高射炮弹带引信），7302 对地炮（优先地面目标、低伸弹道，玻尔斯和自行榴弹炮），7303 高抛发射架（优先地面目标、高抛弹道，喀秋莎；只瞄 NPC 开的车）。旧版插件不认识 7303，喀秋莎照常能打，只是不自瞄。

弹道解算（`common/weapon.cpp` `edf::BallisticArc`，两个插件共用一份）按游戏逐帧推进炮弹的方式修正：游戏每帧先把重力加到速度上再移动炮弹（`0x233DC4`），所以第 n 帧比连续抛物线多掉 重力×n/2；插件把瞄准点抬高这么多再解（三次迭代，`pylib/ballistics.py` 离线验证误差小于 5 厘米）。高抛弹飞行十几秒，这个修正约 2 米。

原因：原版克卜勒的 DPS 只有同级坦克、直升机的 1/3～1/2，耐久不到一半，射程还是同期最短。玻尔斯的 DPS 已经高于同级的霸里亚斯 TZ4，但耐久远不到对方的一半。

## 玩家的炮塔：自瞄，看哪锁哪

你坐在插件瞄准的炮位上时（克卜勒、玻尔斯、自行榴弹炮的炮塔；泰坦和游骑兵坦克的炮手座；你开这两种坦克时的驾驶座也有锁定）：

- **默认关闭，按 J 开启**（2026-10-25 用户：「怎么自动开启自动瞄准了，而且也没啥提示欸。不应该有对应的hud吗，锁定上的敌人……自动瞄准不要开启，开启以后应该有被瞄准敌人的高亮圈之类的？」）：ini `AutoAim=0` 是每个任务开始时的状态（需要 EDF6VehicleCrew 通知新任务开始；只装本插件时保持到退出游戏），游戏中按 **J**（`AutoAimKey`；手柄 `AutoAimButton`，默认不设）切换，改 ini 的 `AutoAim` 立即生效。不用 V：V 是 EDF6VehicleCrew 的 FirstPersonKey，`FirstPersonVehicle=1` 时任何载具座位松开 V 都切第一人称，炮塔座位上会和自动瞄准开关同时触发；J 在按键盘点（docs/plan-2026-10-25-keybinds.md）里步行、载具、炮手座都没有占用（只有地图里的集火，地图开着时插件不读自己的键）。**关闭时**本插件不转你的炮（不论有没有炮塔镜头、第一人称、炮手座），不锁定、不读 Q（Q 只是 EDF6VehicleCrew 的 NPC 标记）；屏幕下方写 `自动瞄准：关   [J] 开启`，切换时屏幕中间大字显示「自动瞄准 已开启 / 已关闭」1.5 秒（瞄具放大、高视角、第一人称等不画下方这一行的视角里也显示）。**开启时**照下面说的工作；没锁定时，炮正转向的敌人（炮塔镜头下则是此刻按 Q 会锁定的那个）上画一个带四根短刻线的绿色圆圈。
- **只有一种自瞄**：炮塔自己转向目标、算提前量和弹道（配合 EDF6VehicleCrew 的炮塔镜头时只转向你锁定的目标，见下）。2026-10-25 起删掉了原来按 **V** 切换的「预瞄圈」模式和它的 ini 项 `AimMode` / `AimModeKey` / `AimModeButton`（用户：「这个自动瞄准是不是多余了一个版本，删掉一个」）：它画的「往哪打才能打中」和 EDF6VehicleCrew 载具 HUD 自己的提前量标记重复，炮塔镜头下「炮塔归你」也和不锁定时炮塔跟镜头走一样，切换键只是让屏幕下方同时出现「自动瞄准 开」和「[V] 自动瞄准 关」两行。旧 ini 里留着的这三项不再读取，可以删掉。防空炮弹的定时引信照样按目标距离空爆。
- **锁定**（看哪锁哪，「头瞄」）：按 **Q**（手柄 X，和战斗机的切换目标键一样；ini `LockKey` / `LockButton`）锁定**离屏幕中心最近**的敌人：视线方向 `LockCone`（默认 20°）以内、`LockRange` 以内（默认 0 = 这门炮的射程）、中间没有地形或建筑挡着的（EDF6VehicleCrew 的地图开着时 Q 是地图的转向键，本插件不读自己的键）。准星已经在锁定的那个上时再按一次，换成离中心第二近的；准星不动连续按，依次往外，最后一个之后回到最近的；准星移到别的敌人上再按，锁的就是准星上的那个（2026-10-09 起，以前是从旧锁定往外数下一个，会锁到准星以外的敌人）。锁定距离从车体算（以前从镜头算，泰坦的镜头在车后 37 m）；坦克驾驶座的锁定距离是主炮射程（以前是炮手的 300 m）。**按住**（`LockClearMs`，默认 0.6 秒）解除锁定。锁定后：
  - 屏幕上和战斗机一样：黄色方框收缩表示正在锁定（约 0.4 秒，等目标速度测稳），红色菱形表示已锁定；
  - 炮塔**只打锁定的目标**，够不着时就停着等，不会去打别的；
  - 同一辆车上 AI 炮手（你开泰坦时的两个炮手座）够得着时优先打你锁的目标；
  - 目标死了、不能再锁、跑出锁定距离 1.5 倍以外，或者你下车 / 换座位，锁定自动解除。
  - 没锁定时自瞄照旧自己挑目标。
  - 炮塔座位上 EDF6VehicleCrew 的 Q 标记一律按锁定的规则拾取（视线 `LockCone` 内、看得见的第一个），自动瞄准开或关都一样：以前它沿另一条射线、只认 8° 以内、不判遮挡，锁定框已经框住的敌人它却提示「对准敌人才能标记」。自动瞄准关：Q 标记（或取消）这个敌人，视线内没有敌人时照旧标地面点、派地图里选中的小队过去；自动瞄准开且用键鼠：Q 是锁定，锁到谁就给 NPC 标记谁。用手柄时锁定是 X，键盘 Q 仍是标记。
- 屏幕下方一行（需要 EDF6VehicleCrew 的 `TurretAimHud=1`）：`自动瞄准：开   [J] 关闭   [Q] 锁定（长按：清除）`（锁定后写「下一个」并变红）；坐泰坦 / 游骑兵坦克驾驶座、锁定交给炮手时写「炮手：自动瞄准」；关闭时写 `自动瞄准：关   [J] 开启`。
- **配合 EDF6VehicleCrew 的炮塔镜头时**（它的 `DecoupledTurretCam=1`，默认：鼠标 / 右摇杆转镜头，炮塔跟着屏幕中心走），你坐的炮位默认归镜头：本插件不再自己挑目标去转你的炮。只有**你锁定了目标**（Q / 手柄 X）时才把炮塔转到锁定目标上，镜头照样由你转；解锁或目标丢失后炮塔回到跟镜头走。这时右摇杆是镜头的，不会被当成「手动拖炮」（该座位不看 `DragDeadzone`）。2026-10-09 起这一条对**所有地面载具的驾驶座**都一样（`common/edf/aimlink.h` V4，用户：「v键自瞄按了没反应」「防空车的自瞄好像是单独写的，统一一下」）：防空车、泰坦 / 游骑兵坦克的驾驶座和其它坦克，同一个 Q、同一套锁定规则和提前量（本插件 `designate.cpp` 一份），炮塔都由 EDF6VehicleCrew 的炮塔镜头转向提前量点；坦克驾驶座的主炮因此也能自瞄（以前只把锁定交给炮手）。防空车特有的只是标记表里的数据（`common/edf/weapon.h` `kGunRoles`：优先空中目标、引信）。两个插件互相告知谁在转哪个座位（`common/edf/aimlink.h` V2 / V4）；没装 EDF6VehicleCrew、它的炮塔镜头关着，或它是没有这条约定的旧版时，一切照上面说的（自瞄自己挑目标、推摇杆拖炮）。防空炮弹的定时引信照样按跟踪目标的距离空爆。NPC 炮手不变。
- **配合 EDF6VehicleCrew 的炮管稳定器时**（它的 `GunStabilizer`）：车身颠簸、转弯时稳定器让炮管守住世界里的方向；本插件转这门炮（防空炮、炮手座）时从稳定器守住的角度出发，车身的转动交给稳定器（`common/edf/aimlink.h` V3），不会补两次。

锁定框和「离屏幕中心最近」用的镜头视线与遮挡判断都来自 EDF6VehicleCrew（它的 HUD 和地图射线，ini `TurretAimHud`）；只装本插件时自瞄和锁定照样能用，只是没有画面提示，锁定沿炮管方向找、也不判断遮挡。玩家自己开的喀秋莎不在其中（插件不碰它，见上表）。

## 安装

需要 Steam 版 EDF6，并已安装 [EDFModLoader](https://github.com/BlueAmulet/EDFModLoader)。

**玩家用全军出击的安装包就行**：`EDF6VehicleCrew-<版本>.zip` 里的安装器（见[仓库 README](../README.md)「安装 / 卸载」）选 1 时
连同本插件的 DLL、ini（已有的保留你的设置，只补新增的项）和下面第 2 步的武器 / 载具数据一起装好，选 2 卸载时一起恢复，选 5 检查。
下面的手动步骤只在单独使用本插件（或开发）时需要。

1. 把 release（或 CI 构建产物）里的 `EDF6AutoTurret.dll` 和 `EDF6AutoTurret.ini` 放进 `<EDF6>\Mods\Plugins\`。
2. 用你自己的游戏数据生成武器文件（它们派生自游戏数据，所以不随包分发），需要 Python 3.10+，直接装进游戏的 `Mods` 文件夹（在仓库根目录运行；游戏目录取 `EDF6_DIR`，没有就在 Steam 库里找）：

   ```
   set EDF6_DIR=C:\Program Files (x86)\Steam\steamapps\common\EARTH DEFENSE FORCE 6
   python autoturret\tools\build.py install
   ```

   它在 `Mods\WEAPON\` 下写这几辆载具自己的 call 和炮文件，在 `Mods\OBJECT\` 下写关卡克卜勒和关卡里的坦克（含 NPC 泰坦），以及 `WEAPONTEXT.*.SGO` 里它们的 8 行说明；只读取游戏的 `Root.cpk`，不修改它。游戏运行时它会拒绝执行；`Mods` 里已有别的 mod 放的同名文件时不会覆盖（`--force` 先备份再覆盖）。写了什么、替换了什么记在 `Mods\.edf6at_data.json`（被替换的文件备份在 `Mods\.edf6at_backup\`）。装了别的会整份替换 `WEAPONTEXT` 的 mod 之后要再运行一次。`--no-text` 不动文本表；`check` 查看安装状态。

卸载：游戏关闭时运行 `python autoturret\tools\build.py uninstall`，再删掉插件。它恢复被替换的文件、删除自己新建的文件，并把 `WEAPONTEXT` 里那 8 行说明恢复成安装前的原文；别的 mod 的文件和行保持不动（安装后被别人改过的会原样保留，加 `--force` 才恢复）。旧版 `build.py` 装的（没有记录）也能卸，只删除和生成结果逐字节相同的部分。只删插件也安全：数据没有插件照样能用。设置在 `EDF6AutoTurret.ini`，游戏运行中保存即生效；`Debug=1` 会把炮塔的行为写进 `EDF6AutoTurret.log`。

安装或升级中断后，可以不加 `--force` 重新安装，也可以卸载：清单记录每个待写文件和说明行在写入前后的状态，并保留首次备份。之后被其他 MOD 改过的内容仍会保留。`check` 遇到缺失或尚未完成写入的文件会报告安装未完成。

## 构建插件

需要 Visual Studio 2022 及 C++ x64 工具（自带 CMake 和 Ninja）：

```
build.cmd
```

DLL 输出到 `build\Mods\Plugins\`（构建产物，不进仓库）。每次 push 都会由 CI 构建。

## 兼容性

针对 TimeDateStamp 为 `0x678CCB46` 的 EDF.dll。插件会校验要打补丁的代码，游戏更新后对不上就自动停用（武器数据没有插件照样能用）。0.3.0 之前的 `build.py` 生成的武器数据在这个插件下仍然能用（插件会像旧版一样改游戏的开火检查）；重新运行 `build.py install` 即可换成新数据。

坦克副炮现在要求真实炮手，原版 `DummyVehicleRider` 不算真实士兵；武器操作员始终沿本席位的原生查询，不再借用驾驶员。远端玩家或 NPC 的复制体不在本机重复瞄准、开火，玩家瞄准辅助仍由 `GunnerAssist` 控制。本次变更通过生产代码离线回归，未重新做游戏内或双机验收。输入挂钩仍串接其它插件同槽函数。

联机未经测试。这个 mod 不新增武器行，没装的玩家不会遇到自己没有的行；但每台机器都按自己的文件模拟载具，混装房间里克卜勒在各人眼里的表现不会一致。建议所有玩家都装。逆向笔记见 [docs/re-notes.md](docs/re-notes.md)。
