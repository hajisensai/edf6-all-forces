# 整备（玩家说明）

「整备」是离线 HQ 和联机待机房间里的一块全屏配置界面，替代 2026-11-24 之前的「支援战前配置」对话框菜单。在这里配自己的武器、支援小队、载具挂载和自定义机甲，并把整套配置存成「方案」随时切换。实现与逆向细节见 [armory-re.md](armory-re.md)，设计过程见 [plan-2026-11-24-ui-rewrite.md](plan-2026-11-24-ui-rewrite.md)。

> 现状（直说）：整备是 2026-11-24 新写的界面，目前**只做过离线构建与离线测试，没有在游戏里实测过**。3D 预览的位置、HQ 顶栏 / 底栏和弹窗会不会盖住整备等，都还没有实机确认（见 [armory-re.md](armory-re.md) §5）。

## 打开与关闭

- **打开**：
  - HQ / 房间菜单里的原生「整备」按钮（鼠标、键盘、手柄都能选）；
  - 快捷键 `F2`，手柄按住 `L3+R3`。快捷键在 ini 的 `RoomLoadoutKey`（键盘虚拟键码，默认 `0x71` = F2）和 `RoomLoadoutButton`（XInput 按键位，默认 `0xC0` = L3+R3）里改，也可以在插件的按键设置里改（「整备」一项）。
- **关闭**：在最左列按 `Esc` / `B`，或者再按一次打开整备的快捷键。
  - 有没保存的修改时，关闭前会先问：「保存并关闭 / 放弃修改并关闭 / 返回」。
  - 游戏弹出窗口、进入子画面或过场时，整备会先把各页的修改提交，再自动关闭。
  - 开始任务时整备直接关闭，不提交。
- 整备开着的时候，房间里的网络、成员列表和聊天照常运行；只是 HQ / 房间画面本身不再响应你的按键，等关掉整备再交还。
- ini 里 `RoomLoadout=0` 会把整个功能关掉：按钮不出现，快捷键也没有反应。

## 画面

- **顶栏**：标题、页签（武器 / 小队 / 载具 / 任务）、方案标签（1～8 和「＋」）。有未保存修改的页签会带标记。
- **中间三列**：左边是列表，中间是条目，右边是详情和可以改的字段。
- **底栏**：当前能用的按键提示。

光标从左往右走：在列表里确认进入中间列，在中间列确认进入详情；取消就往左退一列。

## 通用操作

手柄只用十字键和按钮，左摇杆不移动光标；右摇杆只在武器页用。

| 操作 | 键盘 | 手柄 | 鼠标 |
|---|---|---|---|
| 切换页签 | `Q` / `E` | `LB` / `RB` | 点页签 |
| 子页签（兵种）/ 视角预设 | `Z` / `C` | `LT` / `RT` | 点 |
| 移动光标 | `↑` / `↓` | 十字键上下 | 滚轮，点行 |
| 进入下一列 / 执行 | `Enter`（列表与中列里 `→` 也行） | `A`（十字键右也行） | 点行进入；再点已选中的字段执行 |
| 退回上一列；在列表里关闭 | `Esc`（中列里 `←` 也行） | `B` | — |
| 改详情字段的值 | `←` / `→` | 十字键左右 | 滚轮 |
| 切换方案 | `1`～`8` | — | 点方案标签 |
| 把当前配置存入方案 | `R` | `X` | — |
| 方案菜单 | `F` | `Y` | 右键点方案标签 |

## 各页

### 武器

给玩家本人配武器，只管 1P（分屏 2P 的装备不在这里改）。

- **左列**：一个槽位一行。用 `Z` / `C`（`LT` / `RT`）切换兵种。
- **中列**：
  - 顶上是类别标签，用 `A` / `D` 或右摇杆左右切换，也可以直接点；
  - 来源开关：EDF6、EDF5 移植、EDF4.1 移植；
  - 搜索框；
  - 下面是按系列折叠的武器列表，每个系列显示「持有 n/m」和等级范围。
- **搜索**：
  - 键盘按 `Tab`（或点搜索框）后直接打字，`Backspace` 删字，`Enter` 保留搜索结果，`Esc` 清空；
  - 没有屏幕键盘。手柄可以用右摇杆上下（键盘 `PgUp` / `PgDn`）按名字首字跳转。
- **灰显的武器**不能装，详情里会写明原因：尚未持有、超过等级上限（联机时）、这个槽装不了、已经装在别的槽。
- **右列**：
  - 上方是 3D 预览，玩家本人拿着光标所指的武器（只在看当前兵种时显示）；
  - 下方是「装备 / 展开系列」「收藏」「来源」「显示未持有」「只看收藏」，以及和当前装备的参数对比：数值读法、格式和原版说明面板相同（按武器当前星级），每行标 ▲ / ▼ 表示更好 / 更差。
- 新拿到的武器在列表里带「新」，强化过的带「提升」，和原版武器选择画面同一套标记（出击时由游戏清掉，整备不改它）。
  - 收藏的武器存在 ini 的 `WeaponFavourites` 里。
- **装备即生效**：确认装备后立刻写进游戏，没有单独的「保存」步骤，规则和原版武器选择画面相同。

### 小队

配你呼叫的支援小队：每个士兵的兵种、颜色和背包武器，以及人数（「＋ 添加士兵」，最多 12 人，分第 1/2/3 小队；小队页签用 `A` / `D` 或右摇杆左右切换（首尾循环），也可以用鼠标点）。

- 中列上方的 3D 视口**只显示所选的那一名士兵**。
- 用 `Z` / `C` 或视口右下角的按钮切换视角：自由、正面、侧面、俯视、特写。
- 联机时右列上方是「我的呼叫 / 房主规则」面板（只读），显示这项支援能不能叫、多少 pt、价格。
  - 注意：面板里的规则读的是**你自己 ini** 的设置。房主停用的支援（`SupportDisabled`）目前不会同步给客人，所以客人看到的规则不一定和房主一致。

### 载具

配载具挂载与机组颜色：

- 挂载的「＋ 添加挂架（X / Y kg）」：战机挂载总重不超过机体净重的 40%，只列出装得下的选项；
- 弹数（「＋ 添加弹药」）；
- 机炮 / 主炮；
- 机组颜色；
- 「我召唤的·…」：你自己用载具请求召唤的战机；
- 「我召唤的·机甲」：自定义机甲，选底座请求，再配机体、四个武器槽和核心，详见 [feature-2026-11-21-mech-custom.md](feature-2026-11-21-mech-custom.md)。

每项都可以「复制」「移除」「恢复默认」。

3D 视口的限制：

- 所有机体都显示 3D：预览用的就是战斗里会刷出的那个模型文件（同一个统一文件，有挂载配置时是这套配置生成的变体）。刚改了配置、变体还没生成时显示「这套配置的模型还没生成：保存后在后台生成」。
- 挂载（导弹 / 炸弹等外挂物）**不画在模型上**，只在旁边列出；机甲的 6 个槽位标注是固定位置，不跟骨骼走。

「开火键」一列按挂载自己的设定和本机的按键绑定显示它跟哪个键发射：「开火键 n：键盘键 / 手柄键」（额外开火键，见 [multi-weapon-keys.md](multi-weapon-keys.md)）、「随主炮（切换键 切换弹种）」或「随主武器（切换键 切换）」。

### 任务

- **世界地图**：打开任务选择（世界地图）。地图上「本关出动」一行可以用 `1`～`8` 或鼠标点选这一关用哪个方案出击；还没有方案时按当前装备出击。
  - 选了方案后，如果它的变体文件还在生成，出击会等生成完再自动开始，这一行变成琥珀色并显示进度；光标移开就取消。
  - 生成失败或找不到生成器时不出击，这一行变红并写明原因；在同一行再确认一次，就按现有文件出击（会记进日志）。
- **对战设置**：只在联机房间里有，打开原版的对战设置对话框。

### 保存与联机

- 小队页和载具页的修改要保存才生效。保存发生在以下时机：
  - 切换页签时；
  - 做任何方案操作之前；
  - 关闭时选「保存」。
- 保存失败时整备停在原处，并显示原因。
- 游戏界面强行把整备关掉（比如画面被切走）时，没保存的修改会被**放弃**，不会悄悄保存；下次打开会提示放弃了几页。
- 整备底部的状态栏（最多 4 行，警告为红色）显示：房间开始被挂起、对战等待、上次保存结果、生成器状态、房间同步和房主设置。
- 保存成功后插件重新生成支援变体文件，下次出击使用。
- 联机时，每个成员在房间里保存的配置用于**他自己呼叫的支援**；保存后同步给全员，全员按它生成文件。某种支援能不能叫仍以房主为准。
- 房主开始任务要等全员的文件就绪：有人还在生成时开始会被挂起，状态栏写明原因。超过房间上限的文件（按原版出动）和读不出的成员配置（按默认）不挂起开始。

## 方案

一个方案就是一整套整备配置，最多 8 个，存在 `Mods\Plugins\EDF6VehicleCrew.presets.ini`。每个方案包含：

- 全部支援配置：小队、载具挂载、机组颜色、「我召唤的」战机与机甲；
- 玩家的兵种，以及 4 个兵种各 6 个槽位的武器。武器按名字记，所以重装武器表后仍然对得上。

操作：

- **切换**：`1`～`8`，或点方案标签。
  - 切换时插件把支援配置整份换成该方案的（全部成功才生效，失败就一项都不改），再把兵种和武器写进游戏。
  - 武器表里找不到、还没持有、或者这个槽装不了的武器会跳过，那个槽保持原样。
  - 小队 / 载具页没保存的修改会被丢掉。
- **存入**：`R` / `X`，把整备当前的状态存进当前方案。
- **方案菜单**：`F` / `Y`，或右键点方案标签。可以「新建」「复制」「改名」「删除」（删除前会再问一次）。
  - 改名时直接打字，`←` / `→` 可以选现成的名字（主力、对空、据守、突击）。

方案文件损坏、读不出来时，整本方案视为空，并且拒绝任何修改，不会覆盖原文件；顶栏会显示「方案不可用」和原因。
