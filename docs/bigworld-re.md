# 更大的真实物理世界：逆向笔记与步骤

EDF.dll TimeDateStamp 0x678CCB46，RVA。置信度：H 读代码确认，M 推断，L 猜测。全部为静态分析，尚未实测。

## 目标

用户想要「更大的地图，全部是真实物理」。方案是以平原地图 ig_Heigen601 为中心，把它的真实地形（碰撞和画面）平移复制到四周，并放大 Havok 物理世界的边界。

## 1. 物理世界边界（`src/bigworld.cpp`，已实现）

- `0x11AD340` 构建世界的参数（cinfo）。在 `0x11AD395` 执行 `movaps xmm1,[0x17BE0E0]`，把 ±3000 写进 broadphase 的范围：`cinfo+0x90` 写 −3000，`+0xA0` 写 +3000（H）。
  - 每次场景重置时，`0x1193400` 调用它两次，分别对应 `g+0x10` 和 `g+0x130` 两个世界（H）。
- **补丁**：把 `0x11AD398` 处的 disp32 从 `44 0D 61 00` 改成 `A4 64 61 00`，让它改为读游戏自带的 `0x17C3840 = {10000,10000,10000,10000}`（H）。
  - 签名在 `0x11AD391`：`89 5C 24 68 0F 28 0D 44 0D 61 00 0F 57 C0 0F 5C`。
  - DLL 加载时打补丁，从下一次构建世界（载入任务）起生效。
- `0x42C7A0` 也读 `0x17BE0E0`，但只是拿 3000 当长度相乘（H），所以不能改那个常量本身，要改引用它的地址。
- **精度**：broadphase 的 AABB 是 16 位量化，±10000 时步长约 0.3 m（M）；float32 在 12 km 处约 1 mm（H）。
- **物体越出边界**：处理方式由 `cinfo+0x86` 选择，默认 1，可能是「移除物体」（L）。不要让任何东西碰到边界。

## 2. 地图碰撞的复制（下一步）

- `.MAD` 里有一个 `collision.hkt`，每个地图件对应一个物理系统。加载入口 `0x190770`，由 `0x117f90` 调用（H）。
  - 平原的地面是 `ig_heigen507_2`；另有四块 `ig_heigen601_enkei*`（远景地面），它们也有碰撞（M）。
- **摆放**：每个 `.fmb` 件生成一个 `Preload_Fmex` 对象（ctor `0x1527d0`，vtable `0x176BF88`）。
  - 世界矩阵在 `+0x1200`，`map::havok_Body` 在 `+0x1240`。
  - 碰撞体信息是个 std::list，在 `havok_Body+0xA8`；每个节点 `+0x10` 是一个条目，条目里 `+0` 是 cinfo（0xA8 字节），`+0x80` 是 body 句柄（H）。
- **挂进世界**：vtable 第 0 槽 `0x153eb0`（`add rcx,0x1240; jmp 0x17dd40`）。对每个条目，`0x17d2a0` 执行（H）：
  1. 用 `0x11b0780` 建描述符。
  2. 把 cinfo 复制进描述符。
  3. 设置共享 motion 指针 `desc+0x180` / `+0x190`。
  4. 调 `0x11ac750(*(image+0x20B2958)+0x10, &handle, desc)` 创建 body 并加入世界。
  5. 由 `0x17d7d0` 写入属性。
- **复制方案**（M）：
  - 对每个地面条目照同样的流程再建一个 body：位置加上偏移，`desc+0x180/+0x190` 必须从原件复制，否则会变成动态物体。
  - 句柄由插件持有，任务结束时释放。
  - 碰撞层是 17，地图射线检测的层 22 能命中 15–20 层，所以复制件也会被射线检测到。
- 本步骤先挂第 0 槽记录每个地图件的位置和 body 数量（日志 `BIGWORLD map piece`），用来确认哪些是地面件。

## 3. 画面的复制（之后）

- 摆放记录由 `0x1169b0` 处理，每条 0x48 字节：位置在 +4/+8/+C，旋转（角度）在 +10/+14/+18（H）。
  - `.fmb` 件生成 `Preload_Fmex`，`.mdb` 件生成 `Preload_Model`（ctor `0x1555a0`）。
- 远景地面和远山（`ig_far_heigen507_2`、`ig_farmt_heigen507_2_out`）只在远景相机里画（500–20000 m）。近景相机只画到 1000 m，所以复制地面时，必须把它对应的远景件和 enkei 件一起复制，否则超过 1 km 就看不见（M）。
- **最佳做法**：把加了偏移的摆放记录重新送进摆放流程（`0x11e1e0` → `0x114a40` 任务 → `0x1169b0`），这样得到的复制件画面和碰撞都有。
  - `0x1169b0` 的三个栈参数还没解出来（L）。
- **隐藏远山**：对远山模型的节点调 `setFarRender(node,false)`（`0x11b3020`）（M）。

## 4. 到 6–12 km 外会有什么问题

- **移动范围**：`move_limit` ±999 仍然限制玩家、NPC 和载具。想让地面单位走到复制出来的地形上，需要用 `0x5AA5C0` 放大这个范围（H）。插件的喷气机本来就绕开了它。
- **导航网格**：每张地图只有一份。寻路失败时，地面单位会直线朝目标走（`0xE5B50`）（H/M）。
- **雷达**：位置是相对玩家算的，没有世界坐标的钳制（M）。
- 远处的雾和远裁剪面可以另外调。

## 实验顺序

1. 打开边界补丁，载入测试场。日志应出现 `HOOK bigworld bounds=1` 和若干 `BIGWORLD map piece` 行。确认能正常游玩。
2. 在 x+3500 处复制一份地面碰撞。向下做射线检测，应能在相同高度命中。然后让喷气机低空飞过去。
3. 复制画面，并隐藏远山。
4. 放大插件的世界墙（`kWorldWall`）。
