# 伤害数字：弱点 / 误射颜色与 NPC、援军的数字（逆向与钩子）

EDF.dll（Steam，TimeDateStamp `0x678CCB46`）。证据级别：H = 反汇编逐条读过；M = 静态推断、未实机；L = 猜测。
实现：`src/dmgnum.cpp`（钩子）、`src/dmgnum.h`（纯逻辑，`tools/dmgnum_check.cpp` 离线检查）。需求原话：`docs/feedback-2026-11-10-dmgnum-colors.md`。
伤害函数整体见 `docs/damage-stats-re.md`、`docs/edf41-classes.md` §2b–2d；HUD 的伤害数字层见 `docs/hud-re.md`（伤害数字一节）。

## 1. 原版的伤害通知（H）

伤害函数 `0x547C30`（ApplyDamage，`rdi` = 受击对象，`r13` = GameDamageInfo）扣完血后在 `0x548206..0x54823D` 造一个 0x40 字节的通知
放在 `[rbp]`，交给攻击方：

| 地址 | 指令 | 含义 |
|---|---|---|
| `0x548206` | `mov rcx,[rbp-38h]` | 攻击方（GDI+0x10 的 weak_ptr 在 `0x5481C9` 锁出来） |
| `0x54820A` | `test rcx,rcx; je 0x548244` | 没有攻击方就不发 |
| `0x54820F` | `movaps xmm0,[0x1765B90]; movaps [rbp+20h],xmm0` | 填充色 = (1,1,1,1) 白 |
| `0x54821A` | `movaps xmm1,[0x1765B30]; movaps [rbp+30h],xmm1` | 第二色 = (0,0,0,1) |
| `0x548225` | `[rbp]=rcx` 攻击方，`[rbp+8]=rdi` 受击，`[rbp+10h]=r13` GDI，`[rbp+18h]=xmm6` 带符号的 HP 变化 | |
| `0x54823D` | `call [rax+0A8h]`（攻击方 slot 21），`rdx = rbp` | |

- slot 21 的基类实现 `0x54AAC0`（123 个 vtable 用它）：`[通知]->攻击方 +0x340`（玩家输入）为 0 就返回；否则遍历 4 个镜头（`[0x20B2958]+0x4D8`，
  步长 0x188）调镜头的 `+0x40`，带上通知。**只有玩家（或玩家坐的载具，`0x62F4F0` 把通知改成乘员再发）的伤害能到镜头**。(H)
- 镜头处理 `0xF7550`：消息号对上后比较 `通知.攻击方 == 镜头跟随的玩家（+0x350）`，只有自己的镜头收下交给 HUD。(H)
- HUD 把通知的两种颜色拷进它画的数字（`0x820710` 拷 0x30 字节的条目）。(M，静态，颜色从通知到数字层的具体槽位未逐条核对)

所以：原版只显示**本机玩家自己和自己坐的载具**打出的伤害，NPC、援军、哨戒炮打的伤害不进任何镜头。(H)

## 2. 伤害函数自己知道的两件事（H）

- **误射**：`[rsp+20h]` 在 `0x547DA6` 清 0，`0x547DE6` 置 1——条件是 GDI 的队伍（`+0x24`）与受击对象队伍（`+0x314`）都不是 -1，且关系表
  `relation[GDI 队伍][受击队伍] == 1`（友方）。随后 `0x547DEB` 起：GDI 没有 `0x20`（允许误伤）且受击对象没有 `+0x380 & 0x100000` 就直接返回，
  否则 `0xD8110` 取难度的误伤倍率进 `xmm8`。`0x5483CD` 再读这一位（误伤不触发受击对象的激活）。自伤（攻击方 == 受击，`0x547D12`）同队，也算误射。
- **部件倍率**：`[rsp+44h]` 在 `0x54806D` 置 1.0，slot 17（`+0x88`，`bool Scale(obj, float out[2], GDI*)`，`rdx = rsp+40h`）可写 `out[1]`；
  GDI `+0x60` 的 `0x400` 位在 `0x5480EC` 把它重置成 1.0；`0x548148` 读它乘进伤害。

两个值在 `0x54820F` 时都还在函数自己的栈帧里（函数体内 `rsp` 固定，`sub rsp,190h` 之后不再变），钩子直接读。

## 3. 谁写部件倍率（slot 17 的覆盖，H 为反汇编，倍率的数据来源 M）

扫描所有 slot 16 / slot 17 为默认（`0x54AA40` / `0x54AA30`）的 vtable，列出 slot 17 不是默认的：

| slot 17 | 类 | 写 `out[1]` |
|---|---|---|
| `0x4704B0` | `HumanoidBase` / `Humanoid_Basic` / `Humanoid_BigGreyBoss` / `EDF6_Martian` / `EDF6_Venus` 等 6 个 | `0x4915D0(this+0x6C0, GDI)` 按子命中找到的部件返回的倍率（`0x47064D`）；GDI+0x20 == 4 时强制 1.0 |
| `0x3C06E0` | `EDF6_ShellFish` | 先写默认倍率 `[+0x1120]`，命中判定 `0x3BEA60` 为真时改写 `[+0x1124]` |
| `0x3D5F80` | `EDF6_SpinnerUfo` | 同上的两段式 |
| `0x34F110` | `EDF6_Berserker_Large` | `[+0x1A98]` |
| `0x34AB10` | `EDF6_Berserker_Equipment_Bomb` | 计算值 |
| `0x37C7A0` | `EDF6_GrandMotherParts_Weak` | **不写**：命中在弱点定位盒内才返回真（`docs/edf41-classes.md` §2d） |
| `0x379B90` / `0x37EF90` / `0x393380` / `0x398590` / `0x38D920` | GrandMother 门 / 臂、约尔孟甘德各部件 | 不写 |

结论：

- 部件倍率 **> 1** 就是游戏自己算出的「这一下打在更脆的地方」（弱点 / 头部 / 开壳），< 1 是装甲。判定阈值 1.001（`dmgnum::kWeakAbove`）。(M：哪些部件的倍率实际 > 1 未在游戏里读过)
- 有一类弱点是**单独的部件对象**：GrandMother 的弱点 `EDF6_GrandMotherParts_Weak` 不缩放伤害、只在打中弱点时收下伤害，所以按受击对象的类名也算弱点
  （`dmgnum::kWeakPartClasses`，RTTI 名比较）。(H 类名；M 语义)
- 没有覆盖的：`MovingFortress`（`0x4C6650`）、`UfoCarrier508`（`0x4F7190`）只在 slot 16 里「只收核心」，它们收下的每一下都在核心上，但核心不是独立对象、
  也不缩放；这一版**不**把它们的命中标成弱点（若要标，需要在 slot 16 的判定结果上再加一层，见 §6 待办）。

## 4. 钩子

`0x54820F..0x548225`（22 字节，两条颜色写入）改成 `jmp rel32` 到近处分配的小段代码（`dmgnum::kStub`），其余 17 字节填 `int3`（不会执行：小段代码返回到 `0x548225`；
函数内没有跳进这段的分支，已扫描 `0x547C30..0x548700`）。小段代码：

```
push rcx; sub rsp,38h
mov [rsp+20h],rcx       ; 第 5 参：攻击方
movss [rsp+28h],xmm6    ; 第 6 参：HP 变化
mov rcx,rbp; mov rdx,rdi; mov r8,r13; lea r9,[rsp+40h]   ; 通知、受击、GDI、伤害函数的 rsp
mov rax,Hit; call rax
add rsp,38h; pop rcx
jmp [rip] -> 0x548225
```

`Hit` 先写回原版两种颜色，再按 `dmgnum::Classify(误射位, 部件倍率, 弱点部件对象)` 改填充色。`rcx` 在 `0x548225` 还要用，原样恢复；其余易失寄存器在那里是死的
（下一条 `call [rax+0A8h]` 只吃 `rcx` / `rdx`）。

**NPC / 援军的数字**：攻击方不是本机玩家时，按伤害统计的归类（`AttackerSide`：`squad` NPC 队员、`support` 没有玩家坐的载具、`ally` 友方非士兵物体）
造一份同样的通知、攻击方换成本机玩家，直接调原版玩家路径 `0x54AAC0`——与原版 `0x62F4F0` 把载具的通知转给乘员同一个做法，位置、大小、合并、淡出都是原版的。
其它玩家（`teammate`）的数字原版会送到他们自己的镜头，不转；敌人、无主的伤害不显示。HP 变化为 0 的不转（避免刷屏）。

启动时校验的原版字节：`0x54820F`（22 字节）、`0x54820A`、`0x548225`（30 字节）、`0x547DE6`、`0x5483CD`、`0x548148`、`0x54AAC0` 的函数头。任何一处不同：写一行
`HOOK damageNumbers: ...` 日志，功能不装。与伤害统计（`0x547C30` 函数头的钩子）、`subcarrier.cpp` 的伤害签名（`0x548109` 等）不重叠。

## 5. 联机（H 为结算位置，显示效果未实测）

伤害只在受击对象的权威机器上走到 `0x548134` 以后（`docs/damage-stats-re.md`、`src/host_settings_logic.h` 的说明）；非权威机器在 `0x548625` 返回，不到 `0x54820F`。
所以颜色与 NPC 数字只出现在结算那台机器上。只改本机画面，不改伤害、不发网络消息，**不需要升房间协议**。
