# UfoRobo（EDF4.1「アルゴ」/ 巨神船）原生类移植

2026-10-15。4.1 的 `OBJECT/UFOROBO401.SGO`：出生是飞行舰，脚本一句 `ObjectAction 0` 变形落地成巨型步行机器人。EDF6 没有能承担它的类
（飞的只会飞、走的只会走，而且脚本在变形前后对**同一个句柄**登记耐久事件，换对象不行），所以插件注册自己的类 `UfoRobo`。
解锁的关：本篇 **M007**（巨神船）、**M411**（アルゴ01，开局就是机器人）、任务包 1 **M415**（三艘，只飞不变）、**M416**、任务包 2 **M010**。

逆向出处：`jobs/14618f05/tmp/rerobo/SPEC.md`（4.1，EDF41.exe RVA）、`tmp/re6/PRIMITIVES.md` 与 `tmp/re301/SPEC2.md`（EDF6，EDF.dll
TimeDateStamp 0x678CCB46）。可信度：**H** 反汇编读到，**M** 推出，**U** 未核。

## 1. 4.1 的行为（规格摘要，全部 H，细节见 SPEC.md §3）

- **身体状态机 12 态**（4.1 `+0x15B0`）：S0 飞行待机 / S1 小炮齐射 / S2 中炮 / S3 巴斯特炮（蓄力 300 帧、每 31 帧一发、持续 600 帧）/
  **S4 变形（此态不受伤）** / S5 下落（切机器人形态）/ S6 着地 / S7 机器人主态（选步伐、转身、攻击）/ S8 一段步伐或转身 / S9 攻击 /
  S10 死亡（8–15 秒）/ S11 残骸（10 秒后删除）。
- **AI 6 态**：A1 飞行——在目标 300–500 m 外、上方 250 m 盘旋并面向目标（偏航每帧至多 0.01 rad，速度命令 ≤ 90），之后直飞一段，
  另有横移；身体在 S0 时三个计时器：小炮 180–720 帧（0–500 m）、中炮 300/s–480/s（150–800 m）、巴斯特 1800/s–3600/s（0–1000 m），
  距离不在区间内不倒数。A3 机器人——普通模式先只转身、再前进（2/3）或后退（1/3）；接近模式按半径进退；转身按目标方位 36°/72°/126°
  选 45/90/180 度转身动画；攻击计时器 600/s–1800/s 到期 → A5 按 `robo_attack_table` 的距离 / 角度窗口等概率选一项。
- **运动**：飞行时速度每帧向命令插值 0.25 %、横滚 = clamp(−30·偏航速率, ±0.9425) 每帧趋近 10 %；机器人靠**动画根运动**，按步伐开始时
  的朝向旋转，地面射线贴地，离地则每帧 −0.008 的下落加速。
- **四组炮**（各自 G0 待机 / G1 蓄力 / G2 射击）：小（膝，BeamBullet01，速度 2、寿命 180、伤害 0.5·s、瞄准上限 0.5、散布
  max(0.05, 0.25/s)、每 6 帧一轮持续 300 帧、蓄力 180）、中（肩，RocketBullet01，伤害 30·s、爆炸 9+s、每 3 帧、1 轮、蓄力
  max(20, 180·(1+0.1(s−1)))）、大（手，RocketBullet01，速度 10、伤害 40·s、爆炸 40）、歼灭（手，速度 0.1、寿命 6000、伤害 80·s、
  爆炸 100）。机器人化后膝炮 900–1200 帧、肩炮 300–480 帧自动开火。`s = level/10`。
- **MAB 事件**：每一步脚落地都是范围伤害（`攻撃判定` 伤害 20、着地 30、劈砍 / 践踏 40，× s）；`砲撃開始 / 砲撃終了` 是手炮光束攻击，
  `ジェノサイド砲発射` 是歼灭炮；其余是音效。
- **ObjectAction**（4.1 消息 0x80000009 → EDF6 **0x1000000D**）：0 = 存活则变形；1 = 立即机器人形态 + 播 `stand` + 接近模式；
  2 = 只置接近模式。

## 2. EDF6 实现

### 2.1 数据（`tools/make_edf41_objects.py` 的 `ROBO_*` / `robo_fix`）
- 新 ROOT `UFOROBO401.SGO`（`ROOTS` 记 2 关：M007、M411；DLC 的三关名字是同一个本篇文件），**没有 Alias**：类名保持 `UfoRobo`，
  4.1 的键全部保留（插件读）。`NATIVE_FIXES` 现在对没有 Alias 的原生根也跑（在 check_materials / check_sounds 之前）。
- CAS：`main` 补 `default`（EventAnimationObject 的构造播它）= `ship`；会移动的 18 个状态（走 / 横移 / 转身）的根骨 `globalSRT`
  轨道删掉（`cas_pose.strip_bone`），否则模型会自己再走一遍。
- `edf41_robo_motion`：这 18 个状态的根运动，每个关键帧 `(x, z, yaw)`（相对起点，`cas_pose.root_motion` 从 CANM 读）：
  `walk_f_nl` 前进 50、`walk_f_lr` 100、`walk_b_*` 后退、`side_step_l` +80 x、`turn_l45/90/180` +45°/90°/180°（180 度转身同时前进
  150）。插件按 4.1 的做法：位置 = 起点 + 起点朝向 × 曲线，偏航 = 起点偏航 + 曲线。
- `edf41_robo_events`：每个 CAS 状态、每段剪辑的 MAB 事件 `[时间, 种类, 文本, a, b, c]`（`mab_legacy.mab_event_params` 读事件的内嵌
  SGO 参数；`attack_fire_genocide` 状态依次播两段剪辑，`cas_graft.state_clips` 给出顺序）。
- `edf41_se`：`se41_table(games, ('ロボ',))` 的 4.1 SEPRESET 项（只留本对象真的会播的 39 个；`ロボ３６０停止` 的 cue EDF6 的库里没有，
  也没人播）。**原因**：EDF6 带着 `TIKYUU4_EN_UFOROBO.ACB`（全部 `en_Robo_*` cue），但它的 SEPRESET 一个 4.1 名字都没有，所以插件按
  cue 名播（`edf41c::PlaySe`）；`check_sounds` 对 `edf41_se` 里的名字改查「cue 在对象加载的库里」。
- `material_animation` 去掉：4.1 的是裸 MTAB 块（EDF6 材质代码会崩的形式，check_materials 拒），EventAnimationObject 不读它，灯光动画
  不移植。
- `CLASS_NAMES['UfoRobo']`：插件播的状态与用的定位点必须在文件里。

### 2.2 插件（`src/edf41robo.cpp`）
- 对象由 **EventAnimationObject** 的构造（0x5B5FB0，0xC90）造，克隆虚表（槽 0 / 5 / 9 自己的，**槽 6 OnLevel** 也换）。
  - 构造后清 `+0x380 bit0`（EAO 构造置的「不掉血」，H）。
  - 槽 6：脚本 CreateEnemy 设等级（SetLevel 0x54E740）时调一次；EAO 原本 `return true` 不按等级缩放耐久，这里用 UfoCarrier508 的
    公式（0x4F6D00：`0xD7720(base × 等级/10)`，H）写最大 / 当前耐久，之后脚本的 3019 百分比照常生效（M416 的 80 %）。
  - 队伍：CreateEnemy 给 SetTeam(1, true)（H），所以它是敌人、会被计数、会成为友军 NPC 的目标。
  - **锁定点**：EAO 不登记锁定点（H），插件用 `AddLockTarget 0x547A50(obj)` 加一个，每帧把位置写成 MAB 定位点 `ロックオン`（M：位置
    字段 `+0x10` 来自 PRIMITIVES §6 的瞄准点规则）。
- 每帧：AI → 身体状态机 → 运动 → 四组炮 → 写 `+0x60` 矩阵 → 原 Update（模型 / 骨骼跟随矩阵）→ 读 CAS 时钟触发 MAB 事件 → 锁定点。
- **MAB 事件**：插件自己比较主播放器的剪辑时间（`+0xE8`，与 MAB 事件时间同单位，巨龙模块实机验证过），越过即触发；同一状态时间回退
  = 下一段剪辑。`攻撃判定`：定位点处震屏（0x2E9B30）+ 尘土（ExplosionWind 0x2E4D90）+ 范围伤害；`se`：按 `edf41_se` 播 cue。
- **范围伤害**：`edf41c::Blast` = 一颗不动、寿命 1 帧、`CP#0 = 1`（到期必爆）的 GrenadeBullet01，爆炸半径 = 4.1 的 scale × 定位点尺寸，
  伤害 = damage × s（4.1 0x28B930 的 EDF6 对应物 0x542490 / 0x542670 要一个完整的 GameDamageInfo 和命中集合，没有照抄的把握，未用）。
  这颗手雷会画出爆炸，所以**只在目标进了半径 + 10 m 时才放**（4.1 的范围伤害不画东西；目标外的友军 NPC 因此不吃脚步伤害——偏差）。
- **炮**：炮口 = MAB 定位点（`robo_*_muzzle_setting`），方向 = 炮口 +Z 转向目标、至多转瞄准上限，再在散布锥内随机；子弹用 `edf41c::Fire`
  （InitParam 速度 +0x94、寿命 +0x98、伤害 +0x9C、爆炸 +0xB0、大小 +0xC0、颜色 +0xD0、自定义 +0xE8）。小 / 中炮的**瞄准骨转动没做**
  （只影响外观；方向仍按上限转向目标）。蓄力特效 `UfoRoboCanonChargeEffect`、炮口火光、命中音没做。
- **目标**：GameObjectBase 自己的目标（0x30C0F0，每 60 帧换最近的敌对对象，瞄准其锁定点），没有时用玩家。
- **受击 / 死亡**：伤害消息 0xF0000000 在 S4 直接吞掉（= 4.1 槽 10）。耐久 ≤ 0：飞行形态大爆炸（Explosion_Big，向后）+「ロボ飛行形態死亡」、
  然后按 −0.008 下落到地面；机器人形态爆炸 +「ロボ死亡」+ 播 `dead`（4.1 是 ragdoll 接管：EDF6 的 ragdoll 激活 0x6E40B0 是别处的
  线索，未核，未用）；8–15 秒后大爆炸，10 秒后删除。击杀计数、掉落、9201 由基类。受击击退、火花、受击音没做。
- **驱动音**：`ロボ駆動音` 出生起循环，跟随位置，死亡淡出。

### 2.3 开关（`EDF6VehicleCrew.ini`）
`Edf41Robo=1`（发布开）；开发开关发布版全关：`Edf41RoboLevel`（炮的等级）、`Edf41RoboGunEvery`（飞行三炮每 n 帧轮流、机器人膝 / 肩炮
每 n 帧）、`Edf41RoboAttack`（机器人每 10 秒攻击一次且固定第 n 项）、`Edf41RoboPlace`（出现时放到相机前 n 米）、
`Edf41RoboTransformAfter`（出现 n 秒后变形）。

### 2.4 联机
没有移植 4.1 的同步（`+0x24F0..`）。每台机器各自跑这个类（脚本在每台机器上造它的话），位置 / 开火不同步；不会因此崩（没有任何只在
主机才有的指针）。**未在联机下跑过。**

### 2.5 规格更正
- M415 / M010 的 `CreateEnemy(…, 0.75, …)` 的第三个参数**不是尺寸**，是等级倍率（EDF6 原生 2000 `0x2154C0` 的 xmm3 level，
  PRIMITIVES §3/§10）：它们的 s 小 25 %（耐久、伤害、计时器都跟着变），模型大小不变。插件仍从创建矩阵的行长读缩放（= 1）。
