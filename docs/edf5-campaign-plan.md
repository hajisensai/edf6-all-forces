# EDF5 战役任务包：实现计划

目标：在 EDF6 里完整打一遍 EDF5 的战役，听到 EDF5 的全部任务台词。仓库只放生成工具和少量文本数据，游戏数据全部在安装时从玩家本机的 EDF6 生成。

## 1. 现状（已核实）

| 事实 | 证据 | 可信度 |
|---|---|---|
| EDF6 的 `Root.cpk` 自带 EDF5 全部任务脚本：`MISSION/EDF5_OLD_SCRIPT/` 下 146 个 `MISSION.BVM`（本篇 110 关 + DLC 29 关 + 测试关），EDF5 列表里的 139 关全都有 | 解包比对 | H |
| 这批脚本相对 EDF5 原版只多了一个 `SetUndergroundSoundReverve` 调用，其余字符串完全一致：开发组为 EDF6 引擎维护过它们 | 字符串池比对 | H |
| `EDF.dll` 保留 BVM 任务执行器 `MissionScriptBVMImplement`；任务目录后面拼 `/mission.bvm`（`0xE1560`） | 字符串 + 逆向 | H |
| EDF6 自带 EDF5 语音包 `TIKYUU5_VOICE.*.AWB`（与 EDF5 逐字节同大小），语音表 `EDF6_VOICETABLE.*.SGO` 收录全部 5719 句 `A*` 台词。EDF6 现有任务只用到其中 552 句，4526 句没有任何任务播放 | 解包统计 | H |
| 本篇 110 关引用的地图和对象 EDF6 里全都有；缺失的只有 DLC 的 DM015（`e510_dlc_fortress`）、DM018/DM020（`ig_desert508`）、DM019（`ng_dlc_edfroom03`） | 引用扫描（Root + Chunk01/02） | H |
| 存档每个模式写死 512 个任务（`clear[10][512]` + `seen[512]`，`0xDF790` / `0xDFA40` / `0xDFAB0`），记录下标 = 列表行号；追加到 282 行（147 + 135）不越界，旧存档第 147–281 列全为 0，无需迁移 | 静态逆向，见 `docs/mission-list-re.md` | H（未实机） |
| 离线和在线剧情共用 `M00.MST`，前 147 行一行都不能动，只能在末尾追加 | `config.sgo` ModeList | H |

**还没有在游戏里跑过任何一关 EDF5 任务。** BVM 脚本能不能在 EDF6 里从头跑到结算，只能实机确认，这是本方案最大的风险（见第 6 节）。

## 2. 方案：追加到本篇离线列表末尾

不新增模式。模式表在 `DefaultPackage/config.sgo`，但模式选择界面是否受加密的 `addon.sgo`（DLC 校验）门控没查清；而且护甲倍率等常见 mod 都会整份覆盖 `CONFIG.SGO`，冲突面大。

### 2.1 生成的文件（安装器写入 `Mods/MISSION/`）

| 文件 | 内容 |
|---|---|
| `MISSIONLIST.OFFLINE.LIST.SGO`（DSGO） | 原 147 行原样保留，末尾追加 EDF5 任务行 |
| `MISSIONLIST.OFFLINE.TXT.{CN,EN,JA,KR,SC}.SGO` | 每种语言都补齐到同样行数，每行 [标题, 简介]。文本按行号读、不检查边界，**五种语言缺一种就可能崩溃** |
| `MISSIONLIST.OFFLINE.IMAGE.RAB` | 缩略图包补上新行的图（原包只有 147 张；缺图时的表现未查，所以补齐）。图用该关地图在 EDF6 里对应关卡的缩略图，或统一一张 |

每个追加行的取值（参照 EDF6 表里 28 行 EDF5 时代任务的写法）：

```
[i, 'app:/Mission/EDF5_OLD_SCRIPT/Mxxx', 'EDF5_OLD_SCRIPT/Mxxx', [i+1], 显示编号, 0, 0, 0,
 'BGM_E6M29_MissionEDF5', EDF5 列表第 4 项, flags=8]
```

- 第 10 项必须是带名字 `"flags"` 的成员。缺了它，任务开始和结算都会空指针崩溃（`0xE0AF0`），所以用 `pylib/dsgo.py` 按原表的节点结构写；`flags` 不带 bit7、bit8 和 0x20（剧情分支和台词过滤位）。
- 字段 3 依次接成 `[i+1]`，最后一关为 `[]`，都 < 总行数。
- 字段 6 = 0：没有自选外观时用 EDF5 士兵模型。

### 2.2 收录范围

- 本篇 110 关：全部。
- DLC1 / DLC2：29 关里资源齐全的 25 关，排在本篇之后；DM015、DM018、DM019、DM020 缺 EDF6 没有的地图或对象，不收录。

### 2.3 消除两个副作用（插件补丁，`src/edf5campaign.cpp`）

只追加列表会改变原版行为，插件把这几处「取总行数」的调用改成「EDF6 原有行数」：

| 副作用 | 调用点 |
|---|---|
| 打完 M152 不放结局，要打完最后一个 EDF5 任务才放；新存档也要那时才解锁全难度 | `0x70EDB7`（最后一关判断）、`0xDF9B8`（全难度解锁） |
| 通关率按 282 算，原来 100% 的存档显示约 52%；「通关率 ≥70% 解锁武器上限」变难 | `0xDCD3B`、`0xDD108`、`0xD8586`、`0x7480F6` |

- 「EDF6 原有行数」= 第一个路径以 `app:/Mission/EDF5_OLD_SCRIPT/` 开头的行号；没有这种行时等于总行数，即没装任务包时补丁不改变任何行为。
- 不 hook 取总行数的函数 `0xE0650` 本身：选关界面和读档都要用真实行数。
- 沿用仓库惯例：每个调用点先核对是原版的 `rel32 call`，对不上就不打这处补丁并写日志；ini 开关 `EDF5Campaign`（默认 1）。
- 插件没装或被停用时，任务包照样能玩，只是带着上面两个副作用。

### 2.4 解锁

EDF5 第一关接在 M152 之后（原表最后一行的后继本来就是 `[147]`）。默认再把它加进第 0 行（M000B）的后继列表，**新存档开局就能进 EDF5 战役**，不必先通关 EDF6；这只往第 0 行的解锁列表里加一项，不改任何行的顺序。

### 2.5 文本来源

- 标题和简介取自 EDF5 的 `MISSIONLIST*.OFFLINE.TXT.{CN,EN,JA,KR}.SGO`；SC 由 CN 繁转简（OpenCC）。
- 玩家不一定装了 EDF5，所以由开发工具 `tools/make_edf5_campaign_text.py` 一次性从 EDF5 提取，入库为 `edf5campaign/missions.json`（约 139 关 × 5 种语言）。安装时不需要 EDF5。
- 标题前加前缀「EDF5 · 」（各语言对应），在任务列表里一眼能看出是 5 代任务。

### 2.6 安装 / 卸载（`tools/make_edf5_campaign.py`，接进 `tools/installer.py`）

- 游戏运行时拒绝写入（`modfiles.refuse_while_running`）。
- 基表优先读 `Mods/MISSION/` 里已有的列表（别的 mod 改过的），没有再读 `Root.cpk`。已有列表的前 147 行和原版不一致（别的 mod 动了顺序）时拒绝安装并说明，因为存档按行号对应。
- 写入的文件和原内容记进账本（`pylib/ledger.py`）。卸载时，文件还是我们写的那份才删除或还原，被别的工具改过就保留并提示。
- 卸载提示：存档里记着的「当前任务」如果 ≥147，选关游标会退回第一行；建议卸载前在离线模式选一个 EDF6 任务再存档。
- 在线模式不改：在线列表仍是 147 行，联机房间里没有 EDF5 任务（v1 只做单人）。

## 4. 不做的事

- 不改 EDF6 原有 147 行的顺序和内容（只往第 0 行的后继里加一项）。
- 不改在线列表、DLC 列表、`CONFIG.SGO`。
- 不打包任何游戏文件；脚本、语音、地图都用玩家自己 EDF6 里已有的。

## 5. 验证

离线（我能做）：
- 生成的列表读回：行数 = 147 + N，前 147 行与原版逐节点一致，每行 11 项、第 10 项名为 `flags`，后继链连续且都在范围内；五种语言的 TXT 行数一致；RAB 读回张数一致；写出→读回→写出逐字节一致。
- 每个追加行指向的 `MISSION.BVM` 在 `Root.cpk` 里存在，引用的地图和对象都在。
- 补丁：每个调用点按 `EDF.dll`（`0x678CCB46`）核对原字节；行数函数的离线单测。
- `build.cmd` 编译通过，CTest 全过，`tools/selftest.py` 全过。

实机（需要你或测试站的测试者）：
- 进 EDF5 第一关能加载、能打、能结算；台词有语音和字幕。
- 抽几关不同地图（城市、洞窟、基地、欧洲）。
- 打完 M152 仍放 EDF6 结局；通关率仍按 147 算。
- 卸载后旧存档正常。

## 6. 风险

1. **BVM 在 EDF6 里能不能跑完（最大）**：执行器还在，脚本也被维护过，但 EDF6 把原生函数表改过的话，某些关可能卡住或崩溃。只能实机逐关确认；有问题的关可以从列表里剔除，不影响其它关。
2. 缩略图缺失的表现没查（所以补齐）。
3. 与其它改任务列表的 mod 冲突：前 147 行不一致时拒绝安装；只追加行的 mod 会被我们的行接在后面，卸载时按账本只撤我们的行。
4. 第 10 项 `flags` 各位的语义只查到去向（L），先照 EDF6 里 EDF5 时代任务的取值 `8`。
