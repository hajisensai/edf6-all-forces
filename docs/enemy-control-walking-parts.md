# Walking detached parts: complete accepted native creation

Supported executable: Steam EDF.dll timestamp `678CCB46`. This module owns only the complete `33FCB0` entry, its typed action extension, and its process-local Unit factory provider. The PvP Berserker module owns the constructor/fallback/publication callsites and delegates through the public bridges. The shared factory dispatcher is owned by `enemy_control_gun_factory.*`.

`33FCB0(root, group)` may create several physical parts. The actual runtime group uses root `17F0/17F8/1800`, stride `100`; expanded entries use group `8/10/18`, stride `28`. Grapple has two physical nodes in each stock group. A wrapper GOB is not its projectile: constructor `351940` creates a real Unit at `3525A3`, or native fallback `351660` at `3526B9`, and retains the projectile weak pair at wrapper `5D0/5D8`. The original controller then follows this actual projectile and installs its real callbacks. The parent binding at `3557B0` only identifies the existing wrapper; it does not broadcast creation of the projectile.

The authority executes the original complete group under the PvP transaction. Its constructor bridge captures only the eleven declared numeric words, two boolean bytes, and forty floats from the true `148`-byte input. World transforms are copied by value. Scene objects, resource owners, output shared slots and SGO references remain local. Host constructor `60.xyz` is the existing canonical accepted camera point, without another raycast. The central factory provider captures the complete actual `NativeProjectileSample`; it does not publish at factory return. A nonnull actual result is never replaced by a fabricated object or lost when subsequent pin/cleanup admission fails.

The final pure validator checks retained identities, current authority, all expected constructors, every real `5D0/5D8` link, root membership and empty native descriptor journals. This validation runs inside `EnemyControlBerserkerPvpExecutePartsValidated` before native publication `1197050`. Only its successful return completes the group and queues its outcomes.

Guests suppress the original complete group before any constructor or PvP reservation. Each physical part crosses two explicitly encoded packets, both under 512 bytes: typed constructor values, then the actual projectile sample. Intermediate packets commit only persistent staging and exact receipts. The last packet preflights every projectile dependency before native calls or RNG writes, then synchronously replays the entire original group. At each real constructor, the central provider deep-copies the local native descriptor and supplies the actual host projectile sample. The original constructor receives a genuine native object immediately, so it retains the true weak pair and its native callbacks. The direct native fallback uses the same complete-group discipline.

Only root identities, semantic asset hashes, group/expanded ordinals, native RNG cursors, the original `1940` binding cursor, declared numeric fields and native IDs cross the wire. Native addresses, raw padded structs, resource handles, shared controls and function pointers do not. The immutable PartsShootList digest includes exact literal values, VM bytes and named-child order. Reordered string pools do not alter the semantic hash.

Every packet has a monotonic private serial and an exact receipt. A changed duplicate or a conflicting pending final packet fails. A missing dependency leaves the final packet pending with zero constructors and zero RNG changes. A partial native failure never ACKs the complete group. Persistent descriptor journals and strong references survive failed cleanup; uncertain native ownership cannot be cleared or retried as a new spawn. Quiesce stops future triggers while complete captured groups remain drainable. Normal restore requires every queue and stage to be empty. Trusted old-epoch abort cleans unpublished real objects and their retained journals.

The sole PvP constructor guard preserves the original caller ABI: a refused bridge result never reaches the native `34045F` dereference as null; the guard finishes and deletes a genuine native wrapper. The fallback bridge initializes its output weak pair before every refused path. The original native Part descriptor has no persistent muzzle pointer, so this codec rejects one rather than leaving a bullet pointing into reusable staging memory.

Startup must call `InstallWalkingPartsAcceptedActions()` after the Berserker PvP guards are ready. Parts capture yields without dequeuing while `WalkingAcceptedEntryPending()` reports an uncaptured entry prefix. New root entries are gated on `WalkingPartsEmpty()` before their seed mutation, so a newer entry cannot overtake the previous group's fragments. The shared reliable journal preserves this resulting append order across extensions.
