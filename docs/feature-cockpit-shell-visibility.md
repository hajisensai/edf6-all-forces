# 第一人称座舱的原车壳残留

2026-10-16。用户截图指向 V506 直升机前窗中的悬空方块、弧片和细条，并要求检查所有载具。

## 根因

将最终 MRAB 的原模型材质与 `edf6vc_cpit_*` 新座舱材质分别渲染，确认红框里的零件来自原版 V506 车壳。新 AH-64 座舱单独渲染时没有这些碎片。原适配只检查新座舱有没有露出外壳，错误地假定背面剔除会使内部视野干净；原窗沿、双面细节、仪表背面和装甲接缝仍有朝向眼睛的三角形。

## 处理方式

- `pylib/cockpit_shell.py` 明确区分完整替换座舱与保留原结构的套件。摩托、敞开乘员、原版乘员舱、遥控武器位及保留原内饰的轿车保留原结构；测试要求所有套件都声明策略。
- 在添加新座舱前测量原舱体范围。仅选取三个顶点均在范围内、刚性归属该舱体／炮塔的三角形，以及原生车门。跨出舱区的大型翼面和机身面完整保留，不能因包围盒相交就整块隐藏。救援车第一块轴向玻璃距眼睛约 0.8 米，但倾斜窗沿延伸至约 2.7 米，适配数据显式声明 3 米前沿。
- 将选中的三角形分组到原动画骨骼的恒等子骨骼 `vc_shell_<seat-mask>_<source-bone>`。位置、法线、UV、材质、顶点格式、权重和绕序保留，子骨骼继承原动画。混合不同活动部件的三角形不拆开蒙皮归属。
- 同一舱体上多个完整替换席位共享各自区域的并集。后排乘员朝驾驶舱看时不会看到驾驶席的旧窗框；遥控炮位和车斗乘员不进入这套掩码。
- 原生绘制仅对本机当前乘员的载具实例临时折叠对应子骨骼，随后逐字节恢复整份姿态。不依赖仪表读数就绪，没有独立仪表的乘员位也执行显隐。第三人称、其他实例及原阴影绘制保留原几何。
- 转子、车轮、悬挂、独立炮管和机械臂等活动部件保持原归属。轻卡／拖车头之前永久裁掉旧仪表的做法改为绘制期间显隐，保留完整外部模型。

## 覆盖与验证

资源清单共 65 个支持模型、122 个席位，包含换色型号及插件生成载具。逐模型隔离原外壳并比较修复前后视图，57 个模型需要显隐，另 8 个保留自身结构。这一清单不包含原游戏的不可驾驶单位。

离线清单及逐席位截图位于 `tmp/stray-model-audit/all/` 和 `tmp/stray-model-audit/after/`；后者 `inventory.json` 记录每份输入 MDB 的 SHA-256。对 65 个模型逐三角形比较材质、原始顶点载荷及有效蒙皮归属，确认完整保留外部绘制数据；生成载具的完整重建另由安装链自测验证。

`tests/cockpit_shell_test.py` 覆盖父骨骼／车门动画、远处外壳与转子保留、混合蒙皮、共享乘员掩码、无界舱体、half／大写位置和超过 64 KiB 的顶点切片。`cockpit_build_test.py` 将原生模型的三角形完整性、显隐遗漏及新增骨骼预算加入既有全席位适配检查；`fp_view_check` 检查第 12 号乘员位、无读数显隐及非法位移防护。

离线预览使用实际席位掩码：

```powershell
python tools/cabin_view.py ARCHIVE MODEL.mdb --bone vc_eye_0 --first-person-seat 0 --cull --out tmp/seat.png
```

省略 `--first-person-seat` 可检查完整外部模型。`cockpit_preview.py` 的席位和自由观察预览自动带此参数，外部预览保留完整模型。

更新需要完整安装器同时安装 DLL 并重建资源。`cockpit_shell` 已进入冻结导入检查及资源配方依赖，更新会触发对应缓存重建。实机抽查和最终检查结果记录在第一人称反馈记录中；离线遍历不等同于所有型号的实机／多人验收。

## 真实驾驶室的后墙（2026-10-19）

用户反馈「救护车往后看会看到空气」：救援车驾驶席向左后方看，座椅靠背与车门后柱之间有一条竖缝，能看到车外。

根因不在显隐：关掉席位掩码、完整绘制原模型时缝仍在。救援车、机器人卡车、拖车头和喀秋莎共用的 ARHAN P880 驾驶室（`truck_cab` / `trailer_cab`）由 `tools/prep_cockpit_ground.py` 按眼睛坐标系的 `box` 裁出，原后界是眼后 0.45 m，而 P880 的后墙在眼后 0.86–0.93 m（角上更靠外），整面后墙被裁掉，只剩座椅靠背挡住正后方。座椅外侧的视线落在原车壳上，从车内看到的是车壳背面，游戏不画，于是露出外景。

修复：P880 的后界放到 1.0 m，重新生成 `cockpits/parts/sf-arhan-p880/cab.npz`（贴图不变）。机器人卡车车壳的后下角比座舱空间的测量值更窄，新后墙的五个顶点会从车外露出，而它们未超过任何一面墙的 `NEAR`，原逻辑直接报错；`cockpits._sides` 改为在点同时超过两面墙的 `CORNER`（0.5）时收缩最靠外的那面墙，只影响原本会报错的情况。

`tests/cockpit_build_test.py` 新增后方封闭检查：`truck_cab`、`trailer_cab` 的每个席位在左右 100° 以后、俯仰 −40° 到 +20° 的视线都必须碰到座舱正面。修复前救援车、机器人卡车和拖车头各有 31 条视线漏光。`apc_cab`（M-ATV）与 `tracked_cab`（Tigr）的后舱同样在前排座椅后方被裁掉，离线射线显示格雷普、纳格林驾驶席向后也有类似漏光，但它们的原车后舱另有乘员区，补后墙要另做取舍，本次没有处理也没有纳入检查。
