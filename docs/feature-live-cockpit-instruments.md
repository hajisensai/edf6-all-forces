# 原模型仪表逐块替换

2026-10-16。对应用户要求：飞机、直升机、卡车原模型里残留的静态小表盘和模糊仪表贴图逐块替换。

## 覆盖范围

`pylib/cockpit_retrofit.py` 的坐标均在各准备素材的原始驾驶员眼位坐标系中，随原座舱缩放、裁切或变形。

| 素材／套件 | 替换区域 |
| --- | --- |
| War Thunder F-16A，含窄舱版本 | 右侧飞行仪表、中央备用仪表、侧杆旁上下辅助表、两侧控制板、中央控制板、已有显示器的旧表面 |
| C-130J 驾驶舱，含炮舰 | 备用仪表、下排小表、上排五块静态文字屏、下部文字屏、中央控制台和下方控制板；五个主显示面全部接入读数 |
| AH-64A 前席 | 右侧仪表簇、左右侧控制台、已有三块显示面的旧表面 |
| AH-64A 后席 | 左侧备用表、右侧仪表簇、中央罗盘、下部辅助表、左控制板、两侧控制台与已有显示面 |
| UH-60M 驾驶席 | 中央备用仪表簇、中央控制台及左侧控制条、准备模型中实际存在的显示面 |
| M-ATV／Grape | 原速度／油量／车况表区域与显示面 |
| GAZ Tigr／Naegling | 主仪表簇、辅助罗盘与显示面 |
| ARHAN P880，含喀秋莎、机器人卡车、救援车、拖车头 | 驾驶位速度／燃料表与显示面；状态屏移到仪表簇外 |
| Lightbody 85，含皮卡和轻卡 | 驾驶位速度／燃料表与显示面；状态屏移到仪表簇外 |

主体、座椅、玻璃、方向盘、操纵杆和仪表区域以外的材质沿用各自原模型。替换的是上述仪表／控制面，不是给外部低清图片做插值放大。

## 几何处理

1. 按测量的有向薄棱柱切分原三角形。跨界的边插值位置、法线和 UV，保留邻接结构。共面的边界只归属一侧，避免重复表面。
2. 切分出的仪表表面改为统一的非发光材料，保留原来的斜边、弧面和外轮廓；旧贴图不再承担数字、指针、开关的表现。
3. 在原表面探测支撑位置，按周边覆盖缩小圆形表体，并检查整个表体范围内的凸起；新表盘有独立圆形表壳、表面、刻度、数字、单位及指针。
   显示窗口则真正移除旧透镜／表面，加入实体边框和不透光背板；只给旧透镜改颜色仍会遮住新数字。
4. 卡车驾驶室先完成原有 `squeeze` 变形，再变换测量区域、安装刚性表体和控制轴。新增部件继续服从驾驶室边界。前方方向盘继续参与遮挡。
   已经处于最终座舱坐标的显示面直接使用，不能再次缩放／变形。
5. 标签包含中、繁中、英、日文；数值刻度和 SI 单位为模型字形，不依赖纹理清晰度或玩家机器上的字体。

## C-130 备用仪表孔位

备用仪表区使用 `Block.dials`／`DialAt` 逐表记录原始眼位坐标与表壳直径，不再以整块面板的等距网格推算。原模型前表面 16 边圆孔的上排中心为 `(-0.16737,-0.43739)`、`(-0.29443,-0.43739)` 米，表壳直径 0.118 米，覆盖内孔并保持在原外框内。下排两块安装于下方空白面板，纵坐标 -0.59299 米，保留四项读数。

安装中心、表壳与指针轴心共用一次素材适配变换；已测量孔位不再因探测到空孔而自动缩小表壳。刻度名称放在最下排数字下方，四种语言均检查字形位于表面内且不重叠数字。所有采用该 C-130 素材的驾驶舱，包括炮舰与运输机，共享此修正。

纯几何回归验证非等距安装、缩放后的表壳／指针与文字边界；原素材回归从前表面的 16 个圆孔顶点测量中心，容差 0.05 毫米，以适应素材坐标量化。需要重建座舱模型资源。

## 数据与生命周期

`ScreenFeed` → `PublishInstruments` → `FirstPersonInstrumentReadings` → `InstrumentPose`。HUD 渲染器不在小表盘上覆盖二维图形。

| 表盘 | 来源／量程 |
| --- | --- |
| 速度 | 当前车辆速度转 km/h；卡车 160、直升机 400、C-130 700、战机 2000 |
| 高度 | 当前离地高度；直升机 3000 m、固定翼 10000 m |
| 航向 | 机体前向投影，0–360° |
| 燃料／耐久 | 当前车辆实际燃料比例／车体耐久比例 |
| 升降 | 当前飞行快照的有符号升降率，±50 m/s |
| 俯仰 | 当前机头方向的实际俯仰，±90° |
| 动力百分比 | 固定翼的油门比例；原版／插件旋翼机的动力读数。不是虚构的发动机转速或温度 |

缺失读数显示横线并隐藏指针；有效的零值继续显示真实零位。升降率和俯仰通过 `Readings.flight` 区分负数与不可用状态，离开飞行载具即失效。未提供的发动机传感器不会生成随机或固定读数。

`r_field_max` 是可配置量程的正值指针，`a_field_half_range` 是有符号指针，`q_field_max` 使用真实比例，`u_field` 是未知标记。既有 `n_` 指针保持兼容。新控件在邻席没有读数时保持未知；每次绘制后还原骨骼。

新生成的数字／条形／触点使用 `D`／`B`／`T` 版本，所属席位以外的数字显示横线，条形和触点隐藏；旧资源的小写 `d`／`b`／`t` 保持原有兼容行为。带量程的新 `n_` 同样在邻席无数据时隐藏指针。

只控制显示／隐藏的数字、语言和状态控件可在同一席位共享骨骼，指针和条形控件保留独立轴心。镜像显示器可有相同种类和尺寸，重复屏幕标记增加序号后缀；原生解析保留尺寸和位置。所有资源仍检查 256 根蒙皮骨骼上限。

## 验证入口

- `cockpit_retrofit`：切分面积、UV 插值、共面边界、前方方向盘／后方表面保留、实际指针与未知控件。
- 小窗口实际切除旧透镜，且不重复变换坐标；高纵横比显示器的标签宽度、五位高度刻度和航向行均限制在显示区域内。
- `cockpit_build`：所有现有席位的真实模型适配、封闭驾驶舱、骨骼预算和实际 MDB 构建。
- `fp_view_check`：有符号负读数、量程、有效零值与未知。
- `hud_view --check-feed`：直接运行生产 `FeedOf`／`PublishInstruments`，验证飞机和直升机的单位及数据源、离车失效。
- 完整安装链和冻结安装器检查包括新模块、字形及资源配方；更新必须同时安装新 DLL 并重新生成座舱。

本轮后台实机抽查截击机、C-130 炮舰、V506 直升机与 V607 机器人卡车，确认目标驾驶席、仪表显示和临时 DLL／模型哈希；卡车完成行驶检查。所有临时游戏文件恢复。其余型号／席位以完整真实模型适配、骨骼预算和离线检查覆盖，本轮未穷举实机或多人。

## 2026-10-19：仪表种类按真实座舱重做

航向不再是 270° 指针表，改为转动的罗盘卡（`h_`）；俯仰改为人工地平线（`g_`，滚转取自座位标记矩阵）；高度表改为整圈两针（`w_`）；飞行屏是主飞行显示（姿态仪 + 空速表 + 高度表 + 补零航向），导航屏是 HSI；武器屏按弹种分色。原模型仪表替换中的航向 / 俯仰 / 高度表同样改为罗盘卡、姿态仪、高度表。上表的「航向」「俯仰」「高度」行以此为准。详见 `docs/feedback-2026-10-19-cockpit-ammo.md`。
