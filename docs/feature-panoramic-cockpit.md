# 全周天驾驶舱（2026-11-25）

## 用户原话

> 我想把巴尔加的第一人称改成 全周天驾驶舱
> 进去以后有一段动画启动屏幕，然后变成全周天的

确认时的选择与补充：

- 启动后保留：「座椅+两侧悬浮仪表」。
- 动画：「黑屏→分块点亮 约3秒」。
- 「启动的时候播一次。强制播放不可跳过。播放判定是是否启动」
- 「某些一直被挡视野的载具也改，比如kg6，也套用到其它机甲」
- 「蜘蛛车也要全周天」「尼克斯你觉得半周天好的话也可以半周天」

## 做法

**全周天显示**：模型里，全周天席位的套件不再挂在载具自己的骨骼上，改挂恒等子骨骼 `vc_pan_<席位>`。本机乘员绘制这台载具时（`src/firstperson.cpp InstrumentPose`），把载具自身的所有骨骼（名字不以 `vc_` 开头的，以及 `vc_shell_*`）折叠，只剩座椅、悬浮屏和启动分块。

- 车体、炮架、躯干都不再挡视线，看到的就是外界。
- 只改绘制用的姿态数组，`+0xB0` 世界矩阵不动，炮口、弹道、联机都不受影响。
- 阴影 pass（3）不进这个钩子，载具的影子照常画。
- 其他人和第三人称看到的仍是完整车体。

**启动动画**：舱壁就是屏幕，切成约 0.3 m 的方块。每块有两层：暗块 `vc_boot_<席位>_<步>_0`，和离眼点近 4 mm 的发光层 `…_1`。共 12 步（`kBootSteps` / `BOOT_STEPS`，`tests/cockpit_panoramic_test.py` 校验两边一致），按方块与正前方的夹角从前往外排，再加 0–2 步随机抖动，所以是一块块亮起来，不是一圈一圈。

时间轴（`src/cockpit_instruments.h`，共 3 s，游戏时间，暂停时也停）：

- 0–0.6 s：全黑，仪表未通电（读数按未就绪显示）。
- 0.6 s：三块悬浮屏通电。
- 1.0–2.8 s：各步依次在 ±0.14 s 内闪一下发光层，暗块随后消失，露出外界。
- 3.0 s：全周天。

不可跳过。

**「是否启动」**：按载具判断，见 `crew.cpp VehiclePowered`。

- 本局任务里，只要有别人上过这台车（NPC，或其他机器的玩家），或者本机玩家已经在它上面启动过一次，就算已启动，不再播放。
- 状态记在 crew 的载具表里，用对象引用加 weak 控制块防地址复用，任务开始时清空。
- 载具表满时，按未启动处理。
- 中途切第三人称再切回来不会重播。

## 未验证

- 未实机：动画观感、方块大小，以及发光层亮度（发光材质走 `Light01`）。
- 未实机：KG6 小炮塔里座椅被缩到约一半大小的观感。座舱必须留在炮塔内，否则从外面会露出来。
- 未实机：车体折叠后，巴尔加自己的手臂和武器（若为独立模型）是否仍出现在视野里。
- 联机：动画只在本机绘制。「已启动」的判断依赖本机能看到其他机器玩家的座位占用（`Rider::other`）。
