## 做法

**全周天显示**：模型里，全周天席位的套件不再挂在载具自己的骨骼上，改挂恒等子骨骼 `vc_pan_<席位>`。本机乘员绘制这台载具时（`src/firstperson.cpp InstrumentPose`），把载具自身的所有骨骼（名字不以 `vc_` 开头的，以及 `vc_shell_*`）折叠，只剩座椅、悬浮屏和启动分块。

- 车体、炮架、躯干都不再挡视线，看到的就是外界。
- 只改绘制用的姿态数组，`+0xB0` 世界矩阵不动，炮口、弹道、联机都不受影响。
- 阴影 pass（3）不进这个钩子，载具的影子照常画。
- 其他人和第三人称看到的仍是完整车体。

**手臂保留**：折叠时手臂链的骨骼不折（`cockpit_instruments.h PanoramicArm`）：巴尔加 `jowan_ / kawan_ / hand_ / fing*`，贝加尔塔、尼克斯、608 的 `jowan_ / kawan_ / arm_* / weapon_hand_ / weapon_lowerArm_ / weapon_upperArm_`。肩甲（`shoulderArmor*`、`kata_`）贴在眼旁，照样折叠。蜘蛛车没有手臂骨骼，不变。

**座椅裁剪**：座椅资产按座舱盒裁剪时，以「连通块」为单位整块保留或整块丢掉（`_seat` / `_pieces`）。以前按三角形裁，被切开的方块只剩一两个面悬在空中，封闭舱有墙挡着看不出，全周天墙没了就露出来了（截图里的深色板）。此外，挨着被裁掉的大件、长度超过 0.3 m 的导轨，以及裁完后不挨任何东西的小件，也一起去掉（`_orphans`）。

**操纵杆**：座椅两侧各一根操纵杆（`_sticks`），各自一根仪表骨骼 `vc_i_<席位>_<序号>_j_<手>_<最大角>_0`，支点在杆脚。插件每个相机步读本机乘员座位的摇杆块（`seat+0x2C0/+0x2C4` 左摇杆、`+0x2D0/+0x2D4` 右摇杆，见 `docs/heli-input-re.md` §4），按 0.08 s 时间常数平滑（`StickFollow`，鼠标的右摇杆是每帧位移，不平滑会抖），再把杆倾斜到最多 18°（`StickPose`）：左杆跟移动，右杆跟瞄准。别人的席位不动。

**启动动画**：舱壁就是屏幕，切成约 0.3 m 的方块。每块有两层：暗块 `vc_boot_<席位>_<步>_0`，和离眼点近 4 mm 的发光层 `…_1`。共 12 步（`kBootSteps` / `BOOT_STEPS`，`tests/cockpit_panoramic_test.py` 校验两边一致），按方块与正前方的夹角从前往外排，再加 0–2 步随机抖动，所以是一块块亮起来，不是一圈一圈。

时间轴（`src/cockpit_instruments.h`，共 3 s，游戏时间，暂停时也停）：

- 0–0.6 s：全黑，仪表未通电（读数按未就绪显示）。
- 0.6 s：三块悬浮屏通电。
- 1.0–2.8 s：各步依次在 ±0.14 s 内闪一下发光层，暗块随后消失，露出外界。
- 3.0 s：全周天。

不可跳过。

**「是否启动」**：按载具判断，见 `crew.cpp VehiclePowered`。

- 本局任务里，只要有别人上过这台车（NPC，或其他机器的玩家），或者本机玩家已经在它上面启动过一次，就算已启动，不再播放。
- 状态记在 crew 的载具表里，用对象引用加 weak 控制块防地址复用，任务开始时清空。
- 载具表满时，按未启动处理。
- 中途切第三人称再切回来不会重播。

## 未验证

- 未实机：动画观感、方块大小，以及发光层亮度（发光材质走 `Light01`）。
- 未实机：KG6 小炮塔里座椅被缩到约一半大小的观感。座舱必须留在炮塔内，否则从外面会露出来。
- 未实机：保留下来的手臂在视野里的位置和遮挡程度；手臂网格若有顶点同时绑在肩甲骨骼上，会被拉伸。没有做线框 / 半透明效果。
- 未实机：巴尔加的手臂。2026-11-26 实机（巴尔加对决 `drive.py run range:4`）L3 自由视角向下、向左右都没拍到手臂，需要再拍一次朝下侧方的画面确认是否画出来了。

## 已实机（2026-11-26，巴尔加 515，`drive.py run range:4`，`--ini Debug=1`）

- 座椅周围不再有悬空的裁剪碎片；两根操纵杆在扶手前端，中间是控制台。
- 摇杆数值：`FP sticks` 日志里左摇杆推右 = 左 x 1.00、推前 = 左 y -1.00，右摇杆（视角）照实到 `+0x2D0/+0x2D4`。
- 倾斜方向：L3 朝下看、左摇杆推右时，左杆在画面里竖直、右杆外倾。这和离线渲染一致：中立时透视让两杆向外张，左杆右倾 18° 正好抵消，所以方向和左右对应都对。
- 联机：动画只在本机绘制。「已启动」的判断依赖本机能看到其他机器玩家的座位占用（`Rider::other`）。
