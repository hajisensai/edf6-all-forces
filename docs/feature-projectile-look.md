# 导弹、火箭、炮弹的观感：皇牌空战 / 战争雷霆风格（2026-11-26）

## 用户原话

- 「所有导弹、炮弹之类都换得了。抄抄战雷、皇牌空战之类的游戏」
- 「可以搬」（允许直接取用战雷的素材，见下文「战雷素材」）

声音不在本文范围（见 `docs/feature-wt-sound.md`）。天顶截击机的 SALVO 由另一会话负责，本文不涉及。

## 原版弹类能调到哪一步（静态逆向，EDF.dll 0x678CCB46）

完整结论见共享笔记 `projectile-re.md`。这里只列做观感用到的部分，置信度都是 H。

### MissileBullet01（插件的所有导弹，模板 V_506HELI_MISSILE01）

- **CP[2]**：只是一个 int，表示尾烟节点的寿命，取 CP2·0.9 到 CP2·1.1 帧（`0x268D31`）。
  - 烟留在原地，不漂移。
  - 起始色是 AmmoColor，线性淡到 alpha 0。
  - 宽度是 AmmoSize·0.005 到 0.05，每帧变宽 0.01。
  - `docs/missile-re.md` 原来写的「尾烟 M」已更正。
- **尾焰**：寿命写死 9 到 11 帧，颜色恒为 (R·4, G·2, B, A)（`0x268AEB`），所以亮度只能经 AmmoColor 调。
- **CP[7] = [点火延迟帧, 点火前继承速度倍率, 自身速度倍率]**：
  - 点火前每帧做三件事：继承速度乘 [1]，自身速度乘 [2]，再加上 +0x13F0。
  - +0x13F0 是 AmmoGravityFactor 折算的每帧重力（ctor `0x268F5E` ← `0x231C10`）。
  - 点火后没有任何代码再读 +0x13F0（`0x26A880`；核心步进 `0x235D50` 不读 core+0xBA0）。
  - 尾焰和尾烟的发射器在点火那一帧才打开（`0x26AA02`），所以「先掉落，再点火」是原版自带的能力。
- **AmmoSize 动不了**：它同时决定弹体模型的缩放（`Look`，按真实弹长），尾迹和尾焰的粗细只能跟着它走。

### 其他弹类

- **RocketBullet01**（原版的坦克榴弹、机关炮榴弹）：CP[1] 是尾焰寿命，颜色等于 AmmoColor。CP[2] 是尾烟寿命，烟色写死为白色（`0x17A3B60`），AmmoColor 管不到。
- **SolidBullet01 / Rail**（穿甲弹）：曳光是 12 点亮条，加弹头一个光点，颜色等于 AmmoColor（可以大于 1）。长度等于一帧的位移。没有尾迹参数，也没有烟。
- **爆炸**：只有 Explosion（尺寸 = 半径 / 5）和 Explosion_Big（尺寸 = 半径 / 70）两种，都由 gpufx 分层接管，大小只来自 AmmoExplosion。所以「落点按弹种分爆炸大小」原本就成立，没有改。
- **地面扬尘**：原版没有武器参数能触发炮口地面扬尘，所以这部分全由 gpufx 画（`gpufx_layers.h`）。

## 改了什么

### 1. 导弹（`pylib/vcobjects.py` 的 `Plume` / `PLUMES`，`src/missile.cpp` 的 kDrop）

| 弹种 | 点火延迟（帧） 前 → 后 | 尾烟寿命（帧） 前 → 后 | AmmoColor 前 → 后 | 尾焰色（由 AmmoColor 推出） 后 |
|---|---|---|---|---|
| AAM_S AIM-9X | 0 → 12 | 300 → 420 | (1,1,1,0.5) → (1.5,1.4,1.3,0.85) | (6.0,2.8,1.3) |
| AAM_M AIM-120 | 0 → 12 | 300 → 450 | 同上 | 同上 |
| AAM_L AIM-54 | 0 → 14 | 300 → 480 | 同上 | 同上 |
| AGM AGM-65 | 0 → 12 | 300 → 300 | 同上 | 同上 |
| AGM_L AGM-114 | 0 → 10 | 300 → 240 | 同上 | 同上 |
| ESSM / 9M311 / 天启防空 / PAC-3 | 0 → 4 / 3 / 4 / 4 | 300 → 420 / 360 / 420 / 480 | → (1.6,1.5,1.4,0.9) | (6.4,3.0,1.4) |
| GLM LAHAT / 9M120 / 9M120F | 0 → 0 | 300 → 180 | → (1.2,1.1,1.0,0.6) | (4.8,2.2,1.0) |
| RKT Hydra 70 | 0 → 0 | 300 → 150 | → (1.25,1.15,1.0,0.7) | (5.0,2.3,1.0) |
| 萨扎比护盾导弹 | 0 → 6 | 300 → 240 | → (1.5,1.4,1.3,0.85) | (6.0,2.8,1.3) |
| SALVO | 不动 | 不动 | 不动 | — |

各项改动：

- **CP[7][1]**：0.98 改为 1。点火前完整保留载机速度，弹不会在机翼下被甩到后面。
- **下坠不用 AmmoGravityFactor 做**：插件里 HoldFire、瞄具、弹道解算等好几处都把它当成整段飞行的重力。导弹若写成 5，`jet_combat` / `heli` 的开火判定会以为弹体大幅下坠，从而不开火。所以 AmmoGravityFactor 仍保持 0，改由 `missile.cpp` 在点火前每帧把 kDrop（5 g）加进继承速度。12 帧大约下坠 0.8 米，点火时下沉速度约 10 m/s，随后的导引把它拉回来。
- **动力段从点火那一帧开始算**：原来从发射算起。
- **扇形散开再收拢**（多目标齐射）：这一轮没做。点火前没有导引，弹沿载机速度方向走，散布锥对方向几乎没有影响。SALVO 那边做齐射效果，合并后再看能不能推广到这里。

### 2. 开火的 gpufx 分层（`src/gpufx/gpufx_layers.h` 的 ShotPower）

- **问题 1：坦克的 APFSDS 没有炮口烟**。分层按 AmmoExplosion ≥ 2 才触发，APFSDS 的 AmmoExplosion 是 0，所以开炮只有原版的蓝色小闪光。
- **问题 2：导弹出架也画坦克炮的整套效果**。导弹的 AmmoExplosion 是 6 到 15，于是每发都有冲击环、扬尘和一个 8 到 20 秒的大烟团，空中的战机也一样。
- **改法**：
  - 炮弹的规模取 AmmoExplosion 和 AmmoDamage / 40 中较大的一个，只对载具生效。APFSDS 的 350 / 40 = 8.75，和同炮的 HE（8 米）一样大。步战车的 AP（40）、机枪都不到 2，不出烟。手持武器从不按伤害算。
  - 出膛速度低于 2.5 m/帧的算「发射」，即导弹和火箭：
    - 不画闪光和冲击环。
    - 只有在离地 5 米以内才画尾喷的扬尘（10 颗）和向后吹的烟（6 颗）。
    - 空中挂架发射什么都不画，交给导弹自己点火后的尾焰和尾烟。
    - 原版发射管的小烟保留。

### 3. 炮弹（`vc.wt_tracer`、`AP_TRACER`，`tools/make_tracked_combat.py`）

| 弹 | 前 | 后 |
|---|---|---|
| HE（坦克 105 mm）、HEAT-MP、AC_HE（RocketBullet01） | CP [1, 20 或 40, **100**, …]：100 帧的白色烟迹 | CP[1]=14、CP[2]=**0**：没有烟迹，只留一段 14 帧的热尾焰当曳光 |
| 炮台 / 88 炮 / 天启 / TOS-1 等用 EMPLACEMENT_SHELL 的炮 | 同上，烟迹 100 帧 | 同上 |
| AP（APFSDS）、AC_AP | AmmoColor (0.8,1.0,3.2) / (2.2,3.2,1.6)：原版的蓝 / 绿 | (3.6,1.4,0.5)：战雷那种橙红曳光 |
| CANISTER | (2.6,2.2,1.4) | 不变 |

**没有改初速，原因是**：插件的 AP / HE 弹和原版坦克炮自带的弹装在同一门炮上（`make_stock_stores` 的 `_rounds('AP', 'HE')`，「原版炮是哪种，就补另一种」），而原版那发弹改不了。只把插件这边改成真实初速（APFSDS 约 1650 m/s，即 27.5 m/帧，原版是 18），同一门炮的两种弹弹道就会差一大截，AI 的提前量、射程平衡也都跟着变。要不要连原版载具的炮一起改成真实初速，留给用户决定。

榴弹炮（GrenadeBullet01，CP[5]=20 帧烟迹）和喀秋莎（120 帧）本来就是「榴弹 / 火箭有烟迹」，没有改。

## 预算

- 导弹尾烟是原版 LineStrip，每枚导弹一个环，容量 = CP[2]。最长的 480 帧比原来的 300 帧多 60%，节点数随在空导弹数线性增长。原版同类武器本来就是 300 帧，没有触及 gpufx 的 8192 预算。
- gpufx 方面，导弹发射从原来每发约 32 颗粒子（其中 16 颗活 8 到 20 秒），降到空中 0 颗、地面最多 16 颗。APFSDS 新增的约 50 颗和 HE 开炮一样，已在 `kShotRefire` 的节流之内。

## 需要实机确认的点（攒成一次运行）

1. 战机挂架发射 AIM-9X / AIM-120：下坠约 0.8 米后点火。点火前近炸不触发，保险照常（`fuze.h`）；点火后导引能把下沉拉回来，近距离（< 300 m）的命中率没有明显下降。
2. 尾焰 (6.0, 2.8, 1.3) 是否亮成白热色而不过曝；尾烟 (1.5, 1.4, 1.3, 0.85) 在天空背景下是否偏发光。
3. 7 到 8 秒的尾烟，在多架 AI 战机同时缠斗时的帧时间（对照原版 300 帧）。
4. 坦克 APFSDS 开炮：炮口烟、冲击环、地面扬尘是否出现，规模与 HE 是否一致；橙红曳光。
5. HE / HEAT / 炮台炮弹不再拖白烟，只有一段热曳光。
6. 地面载具（BMPT、通古斯卡、爱国者）发射导弹：只有尾喷扬尘和向后吹的烟，没有坦克炮那种冲击环。
7. 直升机（409）悬停发射 AAM_S / AGM_L：下坠是否会撞上自己的机身或起落架。
