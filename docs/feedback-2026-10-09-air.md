# 2026-10-09 实机反馈：直升机飞控、飞机停地抖动、空母碰撞（air 组）

只做了静态逆向（EDF.dll TimeDateStamp `0x678CCB46`，RVA）、离线仿真和构建；**没有启动游戏、没有安装 DLL、没有游戏内实测**。
下面每条的「游戏内」部分都需要集成负责人实机确认。

## 1. 「这个直升机的飞控依旧怪怪的，参考战雷做吧」

### 根因（基线 b89d26a）

- **升降执行器慢 17–24 s，定高回路在它上面来回振荡。** 原版旋翼是一阶滞后：`rotor += rate·(throttle − rotor)`，
  上升 rate = `veh+0x1BCC` = 0.001/帧、下降 `+0x1BD0` = 0.0007/帧（`0x656744` / `0x656770`，本次反汇编确认）。
  油门夹在 0..1，所以无论油门律怎么写，转速每帧最多变 0.0006 左右。`src/heliaim.h:198 StockThrottle`
  （NPC 的律）配 `heli.cpp:2536` 定高（`heliaim.h:143 Climb`，0.5/s）跑在这个执行器上，悬停转速学习又在饱和的过渡段积分。
  离线复现（`heli_aim_check` 的 before 行，原律 + 原版旋翼）：
  - 按住上升 3 s：1 s 时只有 +0.33 m/s（要 6 m/s），松开后超调 5.4 m，32.6 s 才稳住，竖直速度反向 4 次（上下“海豚跳”）；
  - 按住下降 3 s：1 s 时 −0.10 m/s，反向 3 次。
- **机头俯仰和运动脱节。** `heliaim.h:164 Fly`：瞄准点高低角 = 爬升/下降，W/S = 前进速度设定；而 `PlayerAttitudeHook`
  把机头俯仰设为瞄准点高低角（`heliaim.h:72 PitchInput`）。结果：鼠标压低时机头下压但直升机垂直下沉；按 W 全速前进机头却是平的。
  倾角平滑 `+0x1644` = 0.005/帧（τ≈3.3 s），机头还落后鼠标 3 s（before 行：1 s 后机头只到瞄准角的 28%）。
- 转弯无协调倾侧（横滚只来自横移量）。偏航在 #91 已按原生滞后反解，本次沿用。

### 修法（`src/heliaim.h` Instructor 段、`src/heli.cpp` AimFly / PlayerMouseTune / PlayerAttitudeHook）

在现有三层结构上重构为清晰的控制律：**目标姿态 → 姿态控制器 → 原生输入块**。

1. 目标姿态 `aim::Instructor`（战雷鼠标瞄准/教官）：
   - 航向 = 瞄准点方位；俯仰 = 瞄准点高低角（夹在本机最大倾角 `+0x1640` 内）；
   - 周期变距：机头下压 = 前进，越低越快（满倾角 = 极速），抬头 = 减速/后退（最多极速的 30%），水平 ±3° 内悬停（`CyclicSpeed`）。
     原版直升机的前进量本来就同时决定倾角和速度（`0x654E69` / `0x651E2F`），所以现在机头和运动一致；
   - 总距：**W / S**（以及空格 / 减速键）以最大爬升率升降，松开在当时高度保持（`Collective`，与旧 `Climb` 同一套保持逻辑）；
   - **A / D** 横移（战雷鼠标瞄准模式下 A/D 为横滚 → 侧飞；偏航由鼠标负责）。
2. 姿态控制器：偏航沿用 `PlayerYawInput`（原生滞后反解）；俯仰交给姿态函数；横滚 = 横移量 + 协调转弯倾侧
   `BankInput = atan(V·ω/g)/maxTilt`（ω 用机头朝 row0 的实测转速，左右手性由原生通道自己承担）。
   `PlayerAttitudeHook` 现在替换姿态函数那份输入的俯仰和横滚两项，运动用的输入块不变。
3. 原生输入块：前进/横移仍是速度律的 `StockStick`；油门 `CollectiveThrottle` 按原版垂直律精确反解
   （`0x651D6B–0x651F47`，本次读出：`hover = M·g/(60·L)`，`t = (rotor−idle)/(hover−idle)` 夹 0..1，
   `vy' = (1+(vdamp−1)·t)·vy + rotor·L − G`；悬停以下阻尼随转速消失，线性前馈会让 6 m/s 的下降变成 15 m/s 自由落体），
   求出下一帧把 vy 推向目标 1/12 的转速，再按旋翼一阶律反解油门（一帧到位，夹 0..1）。悬停转速只在高度稳定（|vy| < 1 m/s）
   且油门不饱和时学习，消除积分饱和。
4. `PlayerMouseTune`：键鼠鼠标飞行期间把旋翼升降速率提到 0.05/帧（`aim::kPlayerRotorRate`）、倾角平滑提到 0.05/帧，
   与已有的偏航参数一起记在 `Assist` 里，下机 / 改用手柄时原值写回（只增不减：本来更快的保持原值）。
5. HUD：`HeliFlight::collective` 标记教官模式，操作提示改为「鼠标：航向/机头（压低=前进） W/S：上升/下降 …」，
   地面提示「按住 W/空格起飞」（`hudtext.inc` 新增 2 条，4 种语言）。速度框下的「前速目标」现在是机头俯仰对应的前进速度。
6. 插件旋翼机（空母、无人机）仍用旧的 `aim::Fly`（未要求改，避免一起改变它们的操作）；需要统一时把
   `playerjet_board.inc HoverAim` 里的 `aim::Fly` 换成 `aim::Instructor` 即可。

### 测试

- `tools/heli_aim_check.cpp`（重写，替身按 aircraft-re 的原版律，新旧律对比）：14 个方向场景 + 阶跃响应：
  - W 3 s 松开：1 s 时 +5.81 m/s，保持 +18.4 m，超调 0.00 m，2.0 s 稳定，0 次反向（before：0.33 m/s / 5.40 m / 32.6 s / 4 次）；
  - S 3 s 松开：−4.78 m/s，超调 0，3.7 s，0 次（before：−0.10 m/s，11.9 s，3 次）；
  - 悬停转速初值偏 47%：超调 0.57 m，5.3 s，1 次反向（before：5.48 m / 32.7 s / 4 次）；
  - 鼠标压低 20°：目标 9.9 m/s，峰值 9.9（无超调），0.8 s 到 90%，1 s 后机头到瞄准角 97%（before 28%），回平后停住不倒飞、不掉高；
  - 前飞中扫鼠标右转：横滚输入同右横移符号；转向跟随 49°/s（≥40）。
- `tests/heli_player_input_test.cpp`（包含生产 heli.cpp）：107 项通过，新增：机头压满倾角飞到真实极速、回平刹停、
  W 只升总距不压机头不前进、鼠标上抬=抬头且后退、鼠标下压=低头且前进、转弯倾侧方向、地面 W 起旋翼、
  旋翼/倾角参数在手柄和下机时恢复。
- `heli_yaw_native`（私有映像执行原生姿态函数）通过。

### 未实测

- 游戏内手感、W/S 改为升降后的玩家接受度（与 README 旧说明不同，README 已改）、`+0x1BCC/+0x1BD0` 放大后旋翼动画与油耗观感；
- 替身的重力用 9.8（游戏实测 14.7），悬停转速由学习补偿，阶跃数值会有出入；
- 联机时别的机器上这架直升机按复制的摇杆走原版参数（升降仍慢），未改。

## 2. 「飞机没起飞的时候，会在地上一抖一抖的」

### 根因（基线 b89d26a）

- 滑跑（`playerjet.cpp:591 Ground`）每帧整份覆盖刚体速度和角速度（`PlayerJetBodyStep:1735`）：
  竖直速度 `min(0, measured)`（`:607`，求解器把机体顶出的向上速度被丢掉、下沉被反馈；`measured` 还因 GetTickCount64 15.6 ms 量化偏大约 6.7%），
  角速度用 `BodyAttitude` 拉向 ±3 m 四根探针拟合的平面（`:611-616`），而真实接触是 8 m 轴距的三个机轮。
- 停放（`:1711 j.active=j.phase!=parked`）交给原版直升机步：任何接触都把俯仰/横滚目标归零（`0x654E0F`），
  `0x6CE8D0` 的弹簧（0.15×60/s，混合 0.125）把机体往水平拉，坡上或机轮平面不水平时就压着一侧机轮。
- 两种情况都是插件/原版每帧把某个机轮压进地面，Havok 再把它顶出来，下一帧又压回去。

### 修法

- 新契约 `pjet_handling.h GroundContact`：在地面（滑跑、停放；旋翼机落地停放）时，插件只拥有沿地面的速度和绕法线的偏航，
  **法向速度、俯仰和横滚完全沿用求解器**（法线取机体自己的 up 行，即机轮接触平面）。
- `body506.cpp PhysicsHook` 在原版步之前读出刚体速度（`0x11B1300` / `0x11B1060`，带签名校验；不匹配时退回整份写入并记日志），
  作为 step 函数的输入；其它 step 照旧整份写，行为不变。
- `Ground` 去掉 `vy=min(0,measured)`、探针平面和 `BodyAttitude`，改为沿机体平面的速度 + 绕 up 的偏航角速度；
  停放也保持 `active`（插件按住：切向 0、偏航 0），不再交给原版步。`GroundUpAt` / `handling::GroundUp` 随之删除。

### 测试

- 新增 `tools/ground_contact_check.cpp`（CTest `ground_contact_check`）：二维双轮（8 m 轴距、离中心 2 m）、重力 14.7、
  速度级接触求解（Baumgarte、摩擦）的替身，比较旧滑跑律、旧原版停放律与新契约：新契约在平地、4° 坡、起伏地面、15 m/s 滑跑下
  两轮始终着地、间隙与倾斜无波动、停放不滑移；旧律在 3 个场景里把一只机轮一直抬离地面（与接触对抗）。契约本身的分量拆分也有断言。
- `jet_ground_settle`、`playerjet_recovery`、`playerjet_payload_click` 等既有测试通过。

### 未实测 / 局限

- 替身复现的是「与接触对抗」，**没有复现游戏里的抖动本身**（Havok 的迭代、穿透恢复、休眠无法离线执行）；是否完全消除需实机看。
- 无人驾驶停放的飞机（玩家下机后）仍由原版步保持，未改。
- `Measure` 的 tick 量化偏差（影响空中等其它读 `measured` 的地方）未改，只在本条路径上不再依赖它。

## 3. 「空母的碰撞体积和实际外观不符。我都撞地上了，还会把空母往天上弹」

「空母」= 玩家可驾驶的空中航母（`Body::carrier`，blastCarrier / dollCarrier 同模型）；潜水空母 subcarrier 玩家不能开，排除。

### 根因（基线 b89d26a）

- **外观与碰撞不符：推进舱。** 碰撞体（`pylib/aircraft_collision.py`，365 个凸块）是绑定姿态，机底 = 模型原点平面，
  静止姿态与模型一致到毫米；但 `jet_flight.cpp:331 Thrusters` 悬停/停放时把四个推进舱转到 −90°，
  前推进舱最低点到机底下 **5.19 m**（Root.cpk 实测，逐 5° 表见 `src/nacelle_reach.h`），画面上插进地里，碰撞体却还悬着。
- **撞地被弹上天：定高锁定吃进了弹起速度。** `playerjet_board.inc:356 HoverAim` 把实测速度 `j.measured` 传给 `aim::Fly`，
  `Climb` 锁定高度时用 `h.y = y + vy·0.5`；触地后 Havok 把机体推出去的速度（数十 m/s）进了 `measured`，
  离地超过 kTouch 时一锁定，定高点就被抬高十几米，然后飞控自己爬上去。
- **前瞻射线单位错误。** `jet_flight.cpp:679 HoldOffGround` 从机体中心（离机底 8.5 m）沿 3 帧航迹打射线，命中点直接当 floorY
  （少了 `+rest`），玩家旋翼机机底前方的障碍基本看不见，看见了也允许机底压进去 rest 米。
- 停放由原版步拉平（同第 2 条）。

### 修法

- `src/nacelle_reach.h`：前/后推进舱在 0…−110° 每 5° 的最低模型 y（由 `aircraft_collision.nacelle_lowest` 从 Root.cpk 量出）；
  `Thrusters` 新增参数 `clear`（机底离地），离地 50 m 内每个推进舱最多转到「从 0 转过去的一路上最低点都不低于地面」的角度
  （地面上前推进舱约 −32°，后推进舱不受限）。NPC 空母保持 kMinAlt·2 以上，默认不限。外观不再伸到碰撞体以下的地里。
- `HoverAim` 传 Hover 自己的速度 `e->m.vel`，不再传实测速度。
- `HoldOffGround` 前瞻从机底（`pos − rest`）发出，命中点 `+rest` 换回位置单位（NPC rest = 0，行为不变）。
- 落地停放由 `GroundContact` 按住（第 2 条）。

### 测试

- `jet_obstacle_sim --ground-settle-suite`（CTest `jet_ground_settle`）新增：机底前方 0.5 m 的方块 → 下沉被截住（NPC 同样）；
  推进舱表：60 m 高全转、地面上前推进舱停在机底平面（−0.556 rad，最低点 0.10 m）、后推进舱不受限、3 m 高转得更深但不入地、
  0–6 m 每 0.25 m 全程不入地；弹起后锁定：用飞控速度保持原高（−0.5 m），用实测弹起速度会锁到 +15 m（旧输入的行为）。
- `aircraft_collision_check.py --game`：新增 `test_nacelle_reach_table_is_the_model`（头文件表与模型逐项 ≤1 cm），11 项全过。
  （注意要用不带 `-I` 的 python 跑，否则 `make_jets` 导入失败，这是既有情况。）

### 未实测 / 局限

- 推进舱限角只改外观，不改推力方向（推力由 Hover 计算）；降落时推进舱由竖直转向约 −32°，观感需实机确认。
  推进舱转速有 0.8 rad/s 限速，快速下降时可能短暂落后于限角。
- 机体有俯仰/横滚（空母最多 0.3 rad）时，离地高度仍按中心正下方射线和水平机底估算，角点可能比估计低（agent 量过：俯 17° 时 4 m）。
  这次没有做多点接地射线（会动 FloorClear 契约，范围更大）。
- 碰撞体本身未改（推进舱区域在高空时外观会伸出碰撞体之外，撞建筑时推进舱无碰撞）。
