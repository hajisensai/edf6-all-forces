# 2026-10-09 实机反馈：瞄具（sights 组）

> 用户原话：「这个瞄具做的稀烂，我要的是每个有瞄具的，比如狙击枪，坦克，等，有明显符合对应设定的瞄具」

## 根因

- `src/hud.cpp` 旧 `GunReticle`（本分支改动前约第 2441–2483 行）对**所有**直射武器画同一套「人字 + 两侧密位横线 + 距离阶梯」，
  坦克主炮、机枪、防空炮、狙击炮、激光武器外观完全一样；`SightGun`（旧第 2622–2629 行）只按 `RoundKind::arc` + 有阶梯选人，
  火焰喷射器、酸液这类本无瞄具的武器也会套上这套准星。
- 导弹未锁定时（`StockMark` 与 `HeliGunSight`）只画一个暗圆，不是导引头跟踪框。
- 开镜遮罩 `ScopeShade` 对所有光学瞄具固定画左右下三根粗柱，与武器无关。
- 根本问题是数据结构：`StockArm` 里没有「这件武器该用哪种瞄具」这一项，绘制端只能一刀切。

## 修法：数据驱动的瞄具样式表

新文件 `src/reticle.h`（纯算术，不依赖 EDF.dll）：

1. `Traits`：武器自身数据（弹类、`FireInterval` 射击间隔、弹速、`AmmoExplosion` 爆炸半径、游戏自带开镜标记
   `SecondaryFire_Type==1`、载具角色）。`vhud.cpp` 新增 `SightOf` 从武器内存读：`weapon+0x36C` FireInterval（加载器 `0x68CE36`）、
   `+0x690` SecondaryFire_Type（`0x68D0A4`）、`+0x8B0` AmmoExplosion（`0x68D82F`），均已用 `tools/edfre.py` 反汇编确认。
2. `Classify(Traits) → Style`，`ShellOf → AP/HE/BEAM`；`kSpecs[]` 表给每种样式定开镜柱、是否带距离阶梯、提前量密位间隔。
3. 每种样式一个绘制函数，共用原语（`Cross` / `Chevron` / `Brackets` / `Stadia` / `MilDots` / `Ladder` / 圆环），输出到
   `Sketch`（线、环、点、文字），由 `hud.cpp Render` 用 HUD 自己的四边形与文字渲染：

| 样式 | 谁得到（判据） | 外观 |
|---|---|---|
| cannon（坦克炮手镜，TPD/GPS 风格） | 射击间隔 ≥ 60 帧的炮弹类（Rail/Rocket/SolidExp），或重型能量炮（601） | 倒 V 瞄准标、两侧每 5 密位提前量刻度、下方按真实弹速/重力算的距离阶梯 + 弹道下坠线、弹种 AP/HE/BEAM（能量炮无阶梯） |
| precision（狙击） | 游戏自带开镜标记（贝加尔塔 DLC 长炮、Nix 激光炮），或射击慢且 ≥ 600 m/s 的普通弹（502 狙击） | 双粗细十字（duplex）、每密位一个密位点（挤时翻倍）、竖线上的弹道补偿刻度；开镜时四根柱 |
| autocannon（机枪/机炮/IFV 速射炮） | 射击间隔 < 60 帧 | 圆环 + 中心点 + 三根短柱、短距离阶梯、弹种；开镜无柱 |
| flak（防空环形计算瞄准具） | 载具角色防空（`kAntiAirClasses = 603_Flak`）且速射 | 中心点十字 + 横穿速度 90/180 km/h 两个提前量环，半径 = 焦距 × tan(atan(目标速度/弹速))，环间辐条 |
| energy（速射激光/光束） | 能量武器且速射 | 大间隙十字 + 小菱形，BEAM，无阶梯 |
| missile（导弹未锁定） | 制导弹 | 导引头跟踪框（四角括号 + 中心小十字），锁定后仍由原 `LockAt` 画 |
| rocket / none | 无制导火箭、榴弹/抛射、火焰/酸液/凝固汽油 | 不画炮手准星（保留各自落点标记） |

- 所有角度刻度（密位、提前量环）都用**当前帧视图投影**量出的焦距换算（`FocalAt`），倍率改变 FOV 后自动一致。
- `SightGun` 改为：样式是炮类准星 (`GunStyle`) 且（能量武器或有弹道阶梯）才启用；固定/未知安装 (`physicalOnly`) 仍只画物理路径，不变。
- `ScopeShade` 的开镜柱按样式表：坦克三柱、狙击四柱、环形瞄具无柱。
- `LadderTicks` 与新瞄具共用同一个 `reticle::Ladder`（直升机机炮阶梯同源，去掉重复实现）；直升机与地面载具的导弹未锁定都走 `SeekerGate`。
- 炮手镜倍率仍是 1/3/6x（`sightzoom.h`），只在已安装实体瞄具定位骨（403/404/505/601）时生效，本轮未改。

## 盘点（Root.cpk 只读核对）

`tools/reticle_check.cpp kWeapons` 列 24 件代表武器（坦克主炮 AP/HE、能量主炮、机枪、加特林、Striker 速射炮、防空炮、
防空榴弹、502 狙击、喷火、贝加尔塔长炮/开镜长炮/火箭、Nix 激光步枪/开镜激光炮/追踪激光、404 侧导弹/侧榴弹）及应得样式；
`tests/sight_data_audit.py` 逐行把这些数值与真实 Root.cpk SGO 对照（24/24 一致），现已注册为 CTest `sight_data_audit`（无游戏目录返回 77 跳过）。

步兵手持狙击枪的开镜是游戏原生画面（`docs/zoom-re.md` §1），插件不接管，本轮未改。

## 测试

- 新增 `reticle_check`（CTest）：24 件真实武器的分类；flak 环半径 = f×v目标/v弹（1x 与 3x）、过快弹只出可见环、无弹速无环；
  密位点间隔 f·tan(m/1000)、挤时翻倍（1x 8 密位、6x 2 密位）、duplex 粗柱从细线末端起；坦克人字尖在瞄准点、提前量刻度落在 5 密位、
  阶梯 5–20 百米自上而下、能量炮无阶梯；250 m 步长 2.5/7.5、50 m 步长米数、太近刻度省略；跟踪框 12 笔均在框内且为暗色；开镜柱表。
- `hud_view` 新增 `SightStyleScenes`：7 种武器（真实 SGO 弹道）各 1x/3x，共 14 张图，检查弹种/环速度文字在、无文字重叠、
  `SightGun` 归属正确、开镜遮罩 64 片；无瞄具武器不出炮手准星。
- 离线渲染图（模拟背景，非游戏截图）：`tmp/sights/*.png`（`contact.png` 是 8 种样式中心拼图，`scopes.png` 是狙击/坦克 3x 开镜）。
- 结果：插件 + offline_checks 构建通过；`ctest -j 3` 全部 181/181 通过；`tools/selftest.py` 132/132 通过。

## 未在游戏里实测的部分（如实说明）

- 全部为离线检查与模拟渲染，**未启动游戏**；实机上各样式的大小、颜色对比、与原版 HUD 叠放、手柄/鼠标操作感均未验证。
- 读取 `weapon+0x36C/+0x690/+0x8B0` 依据静态反汇编，未在运行时读回；`FireInterval`、`AmmoExplosion` 经星级曲线 `0xD7CE0`，
  高星级武器的实际值可能与 SGO 基础值不同，但阈值（60 帧、>0）对盘点到的武器都有足够余量。
- 防空环的目标速度取 25/50 m/s（90/180 km/h）是设定上的选择，未测 EDF6 各飞行敌人的实际速度；环忽略重力下坠（游戏弹丸无阻力，横向提前量与重力无关，但俯仰方向的下坠由距离阶梯另给）。
- 坦克镜在 3x/6x 开镜时准星相对视野偏小（固定像素尺寸），后续可按倍率放大。
