## 行为变化（升级后玩家会注意到）

- 直升机（玩家驾驶）W/S 从「前进速度」改为「升降」，机头俯仰控制前后速度。
- 坐在载具上时原版左上护甲 / 耐久块整块隐藏（`HideStockGauges=0` 恢复）。
- 地图里右键单击地面 = 移动、右键单击敌人 = 集火，Z = 攻击移动；联机命令协议升到 v3，新旧版本互不接受。
- 普罗透斯联机协议升到 v2；删除了 `ProteusMarkKey/Button`、`ProteusShieldArc/Block`、`ProteusDriverGun`、`ProteusGunRate/Damage`、`ProteusSalvo*`（`ProteusSalvoKey` 保留，改为驾驶员发射原版导弹架）。
- EDF5 任务包旧版通关记录不会迁移到新包存档；打通 EDF5 最后一关不放结局。
- 多人房间的支援需要所有人装 EDF6Coop 2.5.0 以上；单人房间房主本地生成。
- 用户本机 `EDF6AutoTurret.ini` 的 `AimModeKey=Z` 与 `SightZoomKey=Z` 冲突，需改为 V 或重跑安装器。

## 整合审查后的返修

整合后做了一次只读审查（没有确认的崩溃、内存越界或作弊面），以下意见已由各组修复：

- 普罗透斯新旧插件混房：收到旧版本包、或本机驾驶而 3 秒收不到新版护盾计数时，本机退回原版行为；副本端改用写回后的护盾值判断（不再闪烁重立）；逆向确认护盾墙与车辆帧在主循环同一线程串行（`docs/proteus-re.md` §8b）。
- 支援新旧混房：hello 宣告能力位（线上仍是 v2，配套 EDF6Coop 不受影响）；有旧版对端时房主回退为步枪与默认架数并在 HUD / 日志说明。
- 分屏原版 Q：按士兵保存各自视口的视图投影，1P / 2P 各用自己的镜头射线。
- 俯瞰点改用炮塔武器（`TurretGun`），与炮塔瞄准一致。
- 稳定器满打时参考线直接取炮的实际角，回落那一帧不回拉。
- 钻头存弹改为恒为 1（存弹 0 会让插件 HUD 误报弹尽），飞行状态由钻头行显示。
- 飞机速度读取签名失配的降级路径：停放交回原版步，滑跑垂直速度用实测值。
- `support_soldier_native` 在 main 上就偶发访问冲突：测试夹具私有映射 EDF.dll 时未初始化 TLS，已修夹具。
