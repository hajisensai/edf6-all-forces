# 2026-10-09 第三轮：命令语义与精简（cmd 组）

分支 `feat/fb1009c-cmd`，基于 `fix/fb1009b-rts` 933c61a。**只做了离线验证（编译、离线 check、`hud_layout`），没有进游戏实测。**

用户原话：「一个移动攻击是全消灭再走。一个移动攻击是先走次要消灭」「加一个全体下车？下车是除了驾驶员，炮手等操作席都下车。全体下车是全部人」「看看还有什么指令能砍一砍，或者优化操作的，感觉还是有点复杂了」。

## 1. 两种移动

- **移动**（右键地面，`Order::move`）：不变——强制前进，路上照常转向开火，不躲不站战斗位，到点转守点。
- **攻击移动**（Z / G，`Order::attackMove`）：第二轮把它改成「只有 15 m 内的敌人才停」（`mapcmd::Pursues(..,close)`），那其实就是「先走次要消灭」，和移动重复了。现在恢复为「遇敌停下全歼再走」，并补上两个以前没有的东西：
  - **整队一起停**（`mapcmd_logic.h AttackMoveHolds`，`npcai.cpp AttackMoveSee`）：小队任一成员本帧或上一帧有目标，整队就停下交战；没有自己目标的成员原地站着（`attack-move stand`），不再一个人顺着编队走向终点把队伍拉散。
  - **「附近清空」判据与防卡**：清空 = 全队没人选得到目标（选目标范围 = 士兵自身的 leash + 武器射程，与原来一致）。一个谁也打不到的目标（隔墙、超出射程、视线被挡）会让「有目标」永远成立，所以停下只在「正在打」时成立：从停下起 8 秒内（给第一枪的时间）或距最近一次有人开火 8 秒内。超过就继续前进（路上仍对目标开火，和移动一样），有人再开火就重新停下。这是可观测事件（开火）判据，不是给卡住加超时。
  - 每个新的点位命令清掉这套状态（`GuardOrder`）。
- 第二轮日志里「move 有目标却 fire=0」：WingDiver 射程 80 m，而选目标范围是 leash+射程，目标在射程外时本来就不开火；离线无法再细分（瞄准误差 / 视线），本轮没有改开火判据，需实机 `Debug=1` 的 `NPCAI ... move=move order fire=` 行确认。

## 2. 下车 / 全体下车

- 座位角色沿用插件已有的 `SeatPriority`（0 驾驶席、1 有武器的座位、2 乘客座）。纯判据 `mapcmd::LeavesSeat(role, all)`。
- **下车**（N，`Order::dismount`）：`DismountSquad(top,..,all=false)` 只踢乘客座上的本队士兵；驾驶员与炮手留车。没人在乘客座时拒绝并给新原因 `NpcCommandReason::noPassengers`（「没有乘客座上的人…要全部下车请用全体下车」）。
- **全体下车**（Shift+N / 按钮，新 `Order::dismountAll` = 12，追加在枚举末尾）：所有本队士兵下车。
- 选中**载具**也能下这两个命令：`mapcmd.cpp List` 给载着可指挥乘车小队的载具标 `carries`，`Give` 把命令转给车里的小队（小队自己也被选中时只由它自己那一行下一次）。因为第二轮起乘车小队不参与框选，这是框坦克后让车里的人下车的入口。
- 断剑运输（`transport.cpp`）的自动下车**保持「整队下车」**（`NpcSquadDismount` 用 all）：运输配对里车辆自己的机组（支援车的司机）本来就不属于乘客小队，不会被踢；而「小队自己开空车」时驾驶员是小队成员，若按乘客口径留在车上，小队会被拆成车上一人 + 地面若干（队长常是司机，整队状态变成乘车中），行程的卸载阶段也永远等不到全员下车。所以运输里「驾驶员留车」由小队/机组划分保证，而不是座位角色。

## 协议

命令协议 `kVersion` 4 → 5（`dismountAll` 新值、`noPassengers` 新原因；且「下车」语义变了）。旧版本互相拒收，不会误执行。

## 还没在游戏里确认的

3. 选中载具下「下车」时车里有多个小队的情况。
