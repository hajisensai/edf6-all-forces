## 1. 移动不听话：删除远距离派车（TransportAutoRange）

- 原因（代码推断）：与载具配对的小队（大队 = 3 个 4 人队，直升机机降 / 有人卡车送达后都会配对），收到远于 200 m 的移动 / 攻击移动时交给载具：小队被原地守点「等车」，载具来不了（找不到路线、要求三个队长都在 45 m 内才开始登车）就一直站着，最长 90 秒后才放弃。
- 改法：`transport_logic.h Rides(paired, aboard)`：只有**已在车上**的小队才走载具；步行的小队一律自己走。`Config::transportAutoRange`、ini `TransportAutoRange`、`plugin.cpp` 读取全部删除。

## 2. 支援载具送达后直接返回

- `transport.cpp`：`TransportDeliver` 的行程带 `Trip::leave`。行程结束且载具静止（直升机落地 / 地面车停下）时：仍在车上的乘客下车、解除与它的所有配对、`SupportWithdrawVehicle`（直升机飞离、地面车开回入场点，由 `Retire` / `WithdrawGround` 连同机组删除）。空中结束（例如小队队长阵亡并入别队）不撤离，保持原行为（守点 / 原地待命），避免带着人飞走。
- 有人运兵车 / 轻卡（`support_dispatch.cpp` 到达分支）与直升机机降（`Assign`）都经 `TransportDeliver`，所以都返回。坦克与空车交付不变。

## 3. 摇的人半路变棍木 / 卡车虚化

没有日志，下列是按代码能确定的「卡住 / 遗留」路径，全部修掉：

- **路线永远等不到**：地面支援车路线 `pending/blocked` 时每帧原地保持，没有超时（乘客坐在车里不动）；步行入场的小队路线受阻时「安静移动」把队长按在原地，同样没有超时。现在 `Deployment::stuckSince / infantryStuck`：位置 20 秒（`kStuckMs`）内移动不到 5 m（`kStuckMove`）即判定卡住：
  - 有人运兵车 / 轻卡：`TransportDeliver(..., here=true)`，乘客就地下车、以目标点为守点命令步行过去，车辆返回；
  - 空车交付：就地交付（司机下车跟随玩家）；坦克：就地交付；
  - 步行小队：放开入场路线，给目标点守点命令，由小队自己的 AI 走过去 / 交战，可被正常指挥。
- **坐着的士兵被直接删除**：`Retire` / `WithdrawGround` / `Destroy` 删除座位上的支援兵前不让其下车，座位可能仍指向已释放的对象（车体删不掉 → 部署放弃该车，无人驾驶；乘客停在座位姿势）。现在统一 `Unseat`（原版下车 `NpcMoveSeat(v,seat,-1)` → SeatKick `0x62E1A0`）后再 `DeleteSupportSoldier`；撤离车辆仍有 NPC 乘客时在第 30 / 90 帧把他们踢下再重试删除。

**日志**（用户：「那你加日志啊」）：`Trace` 对每个本机部署常开、限频地写 `SUPPORT TRACE`：入场途中每 5 秒一次、交付后再写 60 秒（撤离中一直写）。头一行是阶段（started / assigned / delivered / withdrawing、卡住了几秒、当前绘制距离），每个单位一行：是否还在、位置、距上一行走了多远（入场途中步行且几乎没动标 `(still)`）、所在载具和座位号、team、对象标志 `+0x380`、离玩家多远、是否超出绘制距离（`(past draw)`）；载具另有乘员数和是否有 NPC 驾驶。另外回滚 / 途中损失 / 单位全没了 / `Assign` 失败都各写一行原因。下一份日志里按 `SUPPORT TRACE` 能直接看出「棍木」的人是在车上（座位号）、在原地不动（still）、还是只是在绘制距离外。

**视距改为无限**（用户：「改一下上限，改成无限呢」）：ini `ViewDistance` 默认改为 `-1` = 无限，插件把近景远裁剪面抬到 max(世界对角线 2.83 × WorldHalf, 20000 m, 关卡自己的远景终点)，地图上任何车辆 / 士兵都不会被插件的裁剪面切掉；正数不再有 10000 上限（≥1000）。日志 `CONFIG ViewDistance=-1 (unlimited)`。

注意（如实）：
- 原版模型自己的淡出距离（着色器 `g_fadeout_distance`）、动画降频不受远裁剪面控制，如果「虚化」来自这一层，视距改无限不会消除它；需要 `SUPPORT TRACE` 的 `(past draw)` / 距离数据再判断。
- 近 0.1 m、远 ≥20000 m，远处地面 / 建筑可能出现深度闪烁（z-fighting），帧率也会降；觉得不好可改回 3000。
- 支援入场点原本放在「绘制距离 + 200 m」之外，视距无限后做不到，会退到「玩家视线被地形挡住的点」/「最远的点」，可能又能看见支援在远处出现。

## 4. 步兵不乘车

- 原因（H）：原版空车在 team 5（`docs/camera-re.md`），`npcai.cpp Gather` 只走友军队伍（`0x5E11D0` 不含 team 5），所以「上车」永远找不到空车，只能上玩家正坐着的车。
- 改法：`Gather` 另用 `0x5E0D60` 走一遍 team 5（签名同 `map.cpp kOneTeamWalkCode`），只收 `NpcDrivable` 的地面载具（不收飞机 / 直升机：停放的战机、等玩家的救援直升机），只作 `BoardTarget` 候选。

## 5. Tempest 电视制导

- 视角被导弹挡住：原来视图在原版步进**之前**按旧位置 + 4 m 发布，原版随后把弹体推进一帧（加速后每帧数米）→ 眼睛落进模型。现在 `missile.cpp UpdateHook` 在原版步进之后调 `TvAfter` 用新位置 / 新速度重放视图；眼睛在弹体前 8 m + 一帧位移（模型实际长度未测，L）。
- 切不回原视角：Esc 多半先打开暂停菜单（暂停时士兵预更新不跑，TV 读不到键，恢复后 TV 照旧）。用户：「要能来回切换电视和玩家视角」——**右键**在导弹视角 / 玩家视角间来回切换：玩家视角下人物自由行动，导弹仍归 TV、保持方向直飞；切回导弹视角继续操纵。出弹时已按住右键（放大瞄激光）不算一次切换。导弹视角下 Esc / B 交还激光制导。
