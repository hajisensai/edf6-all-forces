# 2026-10-12 AI 打金色飞船浪费子弹、战斗机对空不如直升机（ai-targeting）

## 用户原话

> ai还会无脑攻击金色飞船浪费子弹，应该只有能打到弱点的时候才开火
>
> 战斗机对空能力甚至不如直升机

## 一、金色飞船（传送舰 UfoCarrier）：只在打得动的时候开火

### 游戏怎么判定一发打没打疼（静态逆向，EDF.dll 0x678CCB46，H）

- 伤害结算 `0x547C30` 在扣血前调目标的 slot 16（`0x54808A`，目标 `+0x380` 有 `0x800` 时跳过）。返回假且 GameDamageInfo `+0x60` 没有 `0x40` 时，`0x548092 → 0x5480C7 → 0x548625` 直接退出，**HP 不变**。
- UfoCarrier（508 vtable `0x17C9DC0`、基类 `0x17C9930`）的 slot 16 = `0x4F7190`：
  - `+0xD85 == 0` → 一律返回假（整艘打不动）；
  - 否则取离命中点最近的那条命中记录（GDI `+0x78` 数组、`+0x88` 条数、每条 0x30 字节，`+0x20` 是部件），经 `0x6EA430` 换成部件号，**只有等于核心部件 `+0xD8C`（SGO `UfoCarrier_CorePartsName`）才返回真**。
- `+0xD85` 由传送舰 CAS 动画事件写：「ダメージ許可」→ `0x4F6590`（置 1）、「ダメージ禁止」→ `0x4F6580`（置 0），注册点 `0x4F68DF` / `0x4F69F7`；构造时 `0x4F61C8` 置 0。即**舱门开合动画决定能不能打疼**，开着时也只有打进核心才算。
- 打在船壳上的子弹照样进结算、照样走到 `0x547C30`（目标就是传送舰），只是 HP 不变——所以插件已有的伤害钩子能看到「这一发打中了但没打疼」。

### 根因

插件所有 AI（步兵 `npcai.cpp`、炮手 `NpcGunnersInput`、驾驶位挂载 `DriverPayloadAim`、直升机 `heli.cpp ForEachTarget`、战机 `jet_combat.cpp VisitTarget`、地面机器人 `ground.cpp Consider`）选目标只看距离 / 射程 / 视线，从不问这一枪能不能造成伤害；原版 AI 也一样（插件只在 `Veto` 里替它挡友伤）。于是舱门关着时所有单位对着船壳倾泻弹药。

### 修法

新增 `src/wasted_fire.h`（纯逻辑）+ `src/wastedfire.cpp`（接线），对外 `WastedFire(shooter,target)`：

1. **确定的门**：目标是 UfoCarrier、`+0x380` 无 `0x800`、`+0xD85 == 0` → 谁都不打（不选为目标、扳机拿掉）。这与游戏自己的判定同一字段，不是猜。
2. **按射手的反馈**：伤害钩子（`damagestats.cpp DamageHook`，原本只给统计页用，现在无论统计开关都喂这一份）把每次结算的「攻击者、目标、HP 是否下降」交给 `WastedFireHit`。同一射手对同一目标**连续 4 发命中都没掉血** → 这个射手对这个目标停火 6 s，到期再试（舱门可能开了、它可能走到了船底）；期间任何一发打疼立刻解除；超过 15 s 没再打中则重新计数。这覆盖舱门开着但站位打不到核心的射手，也适用于其它任何「打中不掉血」的情况，不按敌人种类写特例。
3. **接到所有 AI 选目标 / 开火处**：`npc_logic.h PickTarget` 加 `usable` 谓词；`npcai.cpp` 的步兵选目标、标记目标、`Veto`（含原版 AI 自己的目标）、炮手 `GunnerVisit` 与标记、`DriverPayloadAim`；`heli.cpp ForEachTarget`；`jet_combat.cpp VisitTarget`（地图集火的明确命令仍保留）；`ground.cpp Consider`。
4. 日志：开始停火时一行 `WASTEDFIRE <射手>: 4 hits on <目标> hurt nothing: its fire at it held 6 s`；关舱的船第一次被跳过时一行 `WASTEDFIRE ship <p>: its hatch's damage window shut`。

### 关于「金色飞船」是哪一种

EDF6 里会出现「只有弱点能打」的飞船是传送舰（`E508_CARRIER*`，类 UfoCarrier508），本修复的确定门针对它。金色 UFO（`E507_GOLDUFO`，耐久 75）和帝国 UFO（`E515_IMPERIALUFO`）的 SGO 没有部件判定参数；若用户说的是别的金色单位，第 2 条反馈机制同样生效（只要它确实「打中不掉血」）。

## 一·续、泛化到所有「有无敌窗口 / 只有弱点可伤」的敌人 + 命中预测（用户追加）

> 这个不止金色飞船啊，还有类似传送塔（传送茅塔）、新型传送飞船，有可能都打不到。加个预测之类的？

### 游戏的判定点（静态逆向，H）

`0x547C30` 扣血前：`+0x380 bit0`（全类通用的无敌标志，`0x5480F8`）→ slot 16「这一发算不算」（`0x54808A`，`+0x380 & 0x800` 时跳过）→ slot 17（`0x5480A2`，同时给倍率）。任一说不，HP 不动。

RTTI 扫描全部 150 个 GameObjectBase 派生类（`vtable-8` 的 COL 基类表含 `GameObjectBase`），按 slot 16 / 17 实现分组：103 个两者都是基类的恒真（`0x54AA40` / `0x54AA30`）；21 个改写 slot 16、15 个改写 slot 17。

| slot 16 实现 | 类（SGO） | 判定 | 插件怎么用 |
|---|---|---|---|
| `0x4F7190` | UfoCarrier / UfoCarrier508（E508 传送舰）/ **DropBoat512（E512 新型传送船）** | `+0xD85`（伤害窗口，舱门动画「ダメージ許可/禁止」切换）为 0 一律否；否则只有离命中点最近那条命中的刚体映射到核心部件 `+0xD8C` 才是 | **问它**；窗口剩余时间可读：`+0xD84` 舱门开、`+0xD90` 关门倒计时（帧，`UfoCarrier_CloseInterval` 180，`0x4F8507` 每帧减 1） |
| `0x3F6970` | EDF6_TimeShip_Anchor（E612/E666 **传送塔/锚**） | 挂着的母船活着且 `+0x1106==0`，或 `+0x10A8 & 4`，或母船无敌 → 否；否则命中点在 `+0x1128` 那个盒子里才是 | **问它**（仅当母船 slot 12 是原版恒假 `0x266BE0` 时，它会调那一格） |
| `0x401200` | GeneratorPoll（E505 发生器柱） | 命中点在 `+0xCA0` 的盒子里才是（伤害类型 4 例外） | **问它** |
| `0x3EE2F0` | EDF6_TimeShip（E611 时间舰本体） | 恒否（只能打它的锚/部件） | 直接判否 |
| `0x4D1790` | MovingFortress 炮台/炮（E510 部件） | 无敌标志或 slot 12 真 → 否 | 状态判定 |
| `0x54AA40` / `0x4BC8A0` | 绝大多数敌人 / Monster | 恒真 | 只看无敌标志 |
| 其它（`0x504720` 母舰、`0x51EFB0` 母舰部件、`0x4C6650` 移动要塞本体、`0x30E200` 护盾运输车、`0x374230` 祖母、士兵/人类…；以及所有 slot 17 改写） | — | 有副作用（发网络包 `0x777B90/0x778950`、写对象字段）或没逐条读通 | **不调用**，只靠兜底（4 发不掉血停 6 s） |

被调用的 4 个函数逐条读过：只读对象/命中记录，辅助函数 `0x6EA430`（刚体→部件号）、`0x6BB5A0`/`0x6BB4A0`（形状的世界变换/半尺寸）、`0x71810`（矩阵求逆）也都只读；入口字节作版本门，EDF.dll 不同就整套退回兜底。

### 预测怎么做（`src/hit_predict.h` 纯逻辑 + `src/wastedfire.cpp`）

1. **拦截点**：按弹速、重力、目标速度（逐帧位置差）两三轮迭代提前量，得到瞄准点和飞行时间（弹速未知时按直线、0 飞行时间）。
2. **弹道打到哪**：从射手（或给定炮口）沿瞄准点打一条 **layer 11**（子弹查对象用的层，`docs/bullet-pass-re.md`）射线，取最近刚体 → `0x108260` 换成对象：
   - 是目标 → 用命中点和刚体 id 拼一条命中记录（`+0x30` 点、`+0x78` 记录数组、`+0x88` 条数，记录 `+0` 点 `+0x20` 刚体），**调目标自己的 slot 16**；
   - 先撞到别的对象 → 这一发打不到它；
   - 什么都没撞到：本局射线已证明能撞到对象时判否，否则（层可能不对）只按状态判。
   对目标的每个锁定点都试，取第一个被游戏接受的作为瞄准点（**瞄准弱点**）。
3. **窗口**：每个特殊目标记录开合（无敌标志、传送舰伤害窗口、锚的屏蔽），统计开着的时长和两次打开的间隔（滑动平均）。开着：剩余时间可读（传送舰倒计时）就要求「飞行时间 < 剩余」，读不到就要求「已开时长 + 飞行时间 < 平时开着时长 × 0.85」；关着但按节律 2.5 s 内要开（或刚过期不到一个周期）→ **wait**：保留为目标、瞄准、不扣扳机（**预瞄**）；否则 skip。
4. **接到 AI**：选目标（步兵 `PickTarget`、标记、炮手、直升机、战机、地面机器人）跳过 skip；扣扳机（步兵、`Veto` 含原版 AI 自己的目标、炮手座位、驾驶位挂载）要求 fire；步兵把视线对准预测给出的弱点瞄准点。普通敌人不做射线（只看无敌标志），每对射手-目标的计划缓存 150 ms。
5. **兜底**：原来的「同一射手连续 4 发命中不掉血 → 停火 6 s」保留，覆盖不调用的那些类和预测没算到的情况。
6. **日志**：特殊目标每 3 s 一行 `WASTEDFIRE plan <射手> -> <目标> (ship/anchor/generator/never/fortress part): window open/shut left … ms, … rays N met N on it N (body …), accepted …, flight … ms: fire/wait/skip`——实机看这一行就知道射线层对不对、刚体 id 游戏认不认。

## 二、战斗机对空不如直升机

### 证据（本机游戏日志 `Mods\Plugins\EDF6VehicleCrew.log.1`，17:09–17:10）

三架 multirole 追飞行目标（目标根部 y≈700 m，`JET target … flies`），距离 22–760 m，`msl=2`，模式在 `missile` / `crank` 间来回，**每一行 `fire=0/0`**；全日志没有一行 `missiles:`。

### 根因

`jet_combat.cpp Attack`：只要还有导弹，对任何飞行目标都走 `Missile`（视距外对峙）：机头对准 2.5 s 有锁定才发；目标近于导弹射程 45%（≈500 m）就 `kTurnAwayAngle` 转开、`crank` 4.5 s；这一分支里 `gunsOk` 恒为假。EDF 的飞行怪都在几百米内成群，于是战机永远在转开—再转回之间，机炮从不放开，导弹也锁不满。直升机悬停直接开枪，所以反而强。

### 修法

飞行目标在机炮射程（`GunReach` = 武器射程与 `gunOpen` 取小）内就是**狗斗**：走 `Chase`（机炮，导弹锁上了也照发），离开到 1.5 倍射程才回到对峙（防止边界来回切）；机炮射程外仍用导弹对峙。`Fire` 的机炮射程同用 `GunReach`。

### 试过又撤回的

低空飞行怪（离地 < pullAlt+60 m）改走对地扫射航线（`Strike`）：离线仿真里比直接狗斗更差（多数用例 0 帧），已撤回。

## 未验证 / 缺口

- **未真机验证**（传送舰 / 新型传送船 / 锚 / 发生器 / 战机都没进游戏；本轮游戏一直被别的会话在队列里占着，测试场的调试生成表里也没有这几类）。实机看日志：`WASTEDFIRE plan … rays N met N on it N` 证明 layer 11 射线能撞到这些刚体，`accepted 1` 出现在船底/锚盒子里；`WASTEDFIRE <射手>: 4 hits …` 是兜底触发。
- **layer 11 射线**能否打到敌方刚体、射线给出的刚体 id 是否就是命中记录里 `+0x20` 的那个 id，是静态推断（M）：本地测试用替身射线和替身「刚体→对象」验证了流程，没有用真物理世界验证。射线一次都没撞到对象时插件不会据此判否（只按状态），所以层不对只会退化成「只按窗口状态 + 兜底」，不会让 AI 永远不打。
- 母舰、移动要塞本体、护盾运输车、祖母、各 slot 17 改写（约 20 个类）**没有预测**，只有兜底。
- 预瞄只在步兵路径里真正「瞄着不打」；炮手、直升机、战机、地面机器人在 wait 时直接不选该目标（不浪费，但不预瞄）。
- 战机、直升机、地面机器人调用时不传弹速，按直线算；只有窗口剩余时间可读的传送舰会因此偏宽（飞行时间按 0）。
- `+0xD85` / `+0xD84` / `+0xD90` 语义、锚的 `+0x1106` / `+0x10A8` 都来自静态逆向，未在运行时读数核对。
- 攻击者归属：NPC 士兵的弹头 owner 是士兵、载具武器是载具（`docs/damage-stats-re.md` §2.1）；炮手座位的弹按载具记。
- 战机：从目标正上 / 正下近距离开局、或 1400 m 外对 40 m 高目标时，第一个通过受地面防撞的拉起预测限制压不下机头，要绕一圈；对地扫射同距离开局一样（既有限制，未改）。战机修复未真机验证。
