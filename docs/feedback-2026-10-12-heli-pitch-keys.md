# 原版直升机键鼠俯仰键（2026-10-12）

用户指定 W 压头、S 抬头，空格/Ctrl 升降，鼠标保留瞄准和航向。Instructor 的俯仰源改为座位前后输入轴，鼠标画面边界只约束瞄准方框，不再约束机头俯仰；W/S 松开回平、减速悬停。原机型最大倾角仍由原版参数决定，起飞的地面和短暂垂直上升阶段不给水平倾角/速度。

旧 CyclicSpeed 固定使用约 3° 死区；最大倾角小于死区的重型机始终得到零前进速度。死区改为固定值与本机最大倾角 10% 的较小者，保持所有机型的完整控制行程。

鼠标上下移动仅改变瞄准方向；集体升降只读空格和 PlayerJetBrakeKey（默认 Ctrl）。手柄和插件的其他旋翼机控制方式保留。HUD 的四种语言键位提示、配置说明和 README 同步。

离线飞行律检查涵盖 W/S 正反俯仰、松开回平与停止、升降独立、地面 W 不起飞、空格配合 W 垂直起飞、0.02/0.04 rad 小倾角机型、鼠标极端方向不干扰键盘俯仰、协调转弯、升降保持高度和现有偏航控制。未启动游戏，没有宣称真实机型实测通过。
