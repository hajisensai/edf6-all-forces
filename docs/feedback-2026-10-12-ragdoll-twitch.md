# 2026-10-12 飞机残骸布娃娃抽搐（部分修复）

用户原话：「飞机炸的时候，尸体布娃娃会抽搐」。

结论先行：**现象已稳定复现并测量；找到并修掉了其中一个确定的缺陷（代理叠在一点），但残骸在击毁约 0.6 秒后仍会被踢起并持续不稳定，第二个来源尚未定位。**本 PR 只是部分修复，不能对用户说「修好了」。

## 现象（实测）

测量方法：实验构建（未提交，补丁见本节末）每帧遍历 hknpWorld（`*(image+0x20B2958)` → `+0x68` → `+0x20`，vtable 0x18BC9C0）里的全部动态刚体，按刚体统计每 2 秒的路径长度与净位移；调试召唤的空载具路径在玩家旁生成一架原版 V506 直升机（`EDF6TR_V506_HELI_MISSION`）和一架插件对地攻击机（`EDF6TR_PJET_STRIKE_MISSION`），12 秒后用 `Die506` 同时击毁。`tests/autopilot/drive.py run range`，`--place` 放入文件、跑完逐字节还原。Havok 在相同输入下逐位确定，同一场景可以严格 A/B。

| | 原版 V506 直升机 | 插件飞机（main） |
|---|---|---|
| 击毁后布娃娃 | 8 部件转动态；机体、尾部、后轮原地静止，旋翼+桨叶按死亡特效被平稳甩出 | 8 部件 6 帧内一起离地，随后翻滚 10–20 秒 |
| 每 2 秒路径 / 净位移 | 机体约 4 m / 0.5 m | 每个部件约 300–420 m / 10–70 m（贴近 maxLinearSpeed 202.8 m/s） |
| 最高 | 地面 | 80–325 m（多次实验） |

在空中击毁（不触地）时没有抖动。

## 缺陷 A（本 PR 修复）：喷气机布娃娃代理叠在一点

- 原版 V506 的每个代理跟随自己的骨骼（body / rotor / tailRotor / bend_roterA–D / rearWheelSus），骨骼就在 SHKT 的静止姿态位置上（`RAGDOLL_V506_HELI.SHKT` body cinfo：旋翼在机体上方 1.56 m，桨叶在其周围 0.5158 m，尾桨 (0.44, 1.65, −7.15)，后轮悬挂 (0, −1.35, −7.25)，朝向全部为单位四元数）。约束（1 个 prismatic、6 个 limited hinge）在各刚体局部坐标里按这个姿态写。
- `pylib/vcobjects.py _jet_ragdoll` 把 8 个代理全部绑到机身骨骼、平移统一为 `centre`，却保留了 V506 绑定的旋转（桨叶绕 Y 轴 ±90°/180°，后轮绕 X 约 19°）。8 个代理叠在同一点、朝向各异，与约束的静止姿态完全不符。
- 击毁时布娃娃转为动态，约束一步就把它们拉开：实测（E2）6 帧内整架残骸离地 8–12 m 并散开。
- 修复：有 `centre` 时每个代理放在 `centre + V506_PROXY_LAYOUT[代理]`、单位旋转，反向绑定取逆。实测（E3，同场景）：击毁后前约 0.6 秒残骸安稳躺在地上（y 不变）。
- `tools/selftest.py`：`carrier_camera_and_ragdoll_on_its_box_centre` 改为按布局断言；新增 `jet_ragdoll_proxies_in_the_v506_rest_pose`（有游戏 Root.cpk 时逐项对照原版 SHKT 的位置与朝向；未知代理名拒绝）。

## 尚未解决：约 0.6 秒后的第二次踢起与持续不稳定

E3 之后约第 36–42 帧（0.6–0.7 s）残骸被突然踢起，此后照样翻滚、升空（多次实验 82–208 m）。已排除（同场景 A/B）：

| 假设 | 实验 | 结果 |
|---|---|---|
| 辅助代理 1 cm 方块与机体/彼此碰撞（组过滤只隔开了桨叶-旋翼、旋翼/尾桨-机体） | 辅助代理改为与机体同子系统且互不碰撞（E4） | 与 E3 **逐位相同**，过滤没起任何作用，未保留 |
| 飞行刚体（veh+0x1650）与布娃娃机体用同一个整机复合形状、完全重叠 | 关掉 `MakeAirframe`，飞行刚体回原版小盒子（D1） | 与原轨迹逐位相同：两者不相互作用 |
| 插件对飞机的每帧控制 | `PlayerJet=0`（E6） | 与 E3 逐位相同 |
| 506 机体质量档补丁 | `VehicleWelding=0`（E7） | 照样升空 |
| 速度增益里的机型标记（7202） | 击毁前改回原版 80（E9） | 照样升空 |
| 机体惯量沿用 V506 直升机（回转半径约 2.6 m） | 清掉 massDistribution 让 Havok 按整机算（E8） | 照样升空 |
| 机翼格子只有 6 cm 厚（SKIN=0.03） | SKIN=0.25（E15）在一处有效，另两处复测**无效**；SKIN=0.1（E16）无效 | 不是根因 |
| 有人在设速度 | 挂钩 Havok 写接口 0xA0–0xD8 各槽，只看残骸部件（E10） | 击毁后 7 秒内只有 1 次外部冲量（死亡特效爆炸步骤 `0x5F89B6` → `0x6E5DB0` → `0x11B0CB0`），没有任何设速度调用：能量来自求解器（接触/约束） |

线索：

- 把同一架飞机的布娃娃换回原版 `Ragdoll_v506_heli.shkt`（E11）：不再升空，但仍在地面附近抖动（1 秒约 26 m）；同场景原版直升机机体 2 秒约 4 m。生成的机体复合形状（338–466 个柱状格子）放大了不稳定，但不是唯一因素。
- 死亡特效第 0/2 步（`[[0.4, 0.15], [['mdl']], ...]`、`[[0.5, 0.46], [['mdl']], ...]`）的中心在 `mdl` 骨骼（喷气机模型原点 = 机轮着地点），原版在 `body`。把两个第二参数置零（E5）后 0.6 秒那一脚消失，但之后照样升空。`ExplosionAddSelectActivePartFunc` 执行步 `0x5F8900`：对列表里的部件调 `0x6E4050`→`0x6E4370`（改部件状态 +0x9C、断开其约束），再无条件调 `0x6E5DB0` 对半径内所有部件按质量加冲量。插件把原版 `[['rotor', 6]]` 与 `[['tailRotor', 2]]` 两个列表清空了（`_dead_effect`，避免 -1 下标崩溃）。
- 辅助代理降为 1 kg（E12）：持续抖动缩短到约 4 秒，但一开始仍被抛起；质量比 30000:1 本身也不稳，未采用。

下一步建议：在 cdb 里对 `0x6E5DB0`、`0x5F85A0` 及 hknp 接触/约束求解入口下断，记录击毁后第 30–45 帧残骸各部件的接触对与约束误差，确认第二次踢起来自接触穿透还是约束；同时测试「死亡特效中心改到机体中心 + 新布局」的组合。

实验补丁（每帧动态刚体探针、写接口调用方追踪、调试召唤自动生成/击毁）未入库，保存在本机会话目录 `tmp/rd/experiment-probe.patch`。
