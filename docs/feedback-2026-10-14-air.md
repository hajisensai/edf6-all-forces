# 2026-10-14 反馈：飞机尾焰、预瞄线、地底召唤、炮舰机炮手、换武器丢瞄具

用户原话：

1. 「飞机的尾焰不对」；追问后：「入场尾烟在飞机很后面」「1也修一下」（即下面第 1 条找到的两个尾焰缺陷）。
2. 「飞机在外面会有红色预瞄线」。
3. 「地底也能召唤飞机支援。。。。明显不对，应该只能召唤地底的钻地战车这种」；追问后拍板「只留步兵+钻地车」。
4. 「炮舰机的炮火位没办法用机枪开火，只能用炮欸」；追问后拍板「副射击=加特林」。
5. 「切换武器的时候会把瞄具取消到。比如泰坦用机枪的时候，镇魂炮的瞄具就没了」。

| # | 根因 | 修复 |
|---|---|---|
| 1 | `booster.cpp` `JetFrame`：尾焰长度只在 Booster 创建时（构造参数 +0x40）定一次，加力开关后不再变；油门为 0 时仍每帧写 `+0x3F0=1`，停机怠速也喷火 | 加力状态变化时按另一长度重建该喷口的 Booster；`intensity` 为 0 时 pulse/hold 写 0、让它熄灭，未点燃时不建 |
| 2 | `aim_line_want.h`：空座位仅在 NPC 驾驶时隐藏红线 | 空座位一律隐藏（见 `aim-line-re.md` 同日一节） |
| 3 | M 地图支援栏不看任务限制，地下照样列出飞机（选了才被拒）；坦克 / 运兵车 / 轻卡在地下放行；钻地战车请求 `use_underground=0`（与原版直升机请求同） | `support_policy.h` `Allowed`：地下只放行步兵；`SupportCallForbidden` 让支援栏把不可用条目变暗、点了提示原因，请求入口当场拒绝；潜水母舰地下也拒绝；`tools/calls.py` `underground`：只有钻地战车请求写 `use_underground=1`，其余插件载具请求写 0 |
| 4 | 炮手座有加特林，但只能用切换键（R / 手柄 LB）轮到，HUD 不提示；副射击在炮手座没接 | 按住鼠标右键（ini `GunshipGatlingKey`；手柄 RB，座位按钮位 0x20）直接打加特林；HUD 读数下多一行：切换键与「按住：加特林机枪」 |
| 5 | `hud.cpp` `StockMarks`：只有最近按下的扳机上的武器画完整瞄具，另一扳机上的炮降级成暗色小十字；`vhud.cpp` 只给选中的那把测距 | 两个扳机上的炮各自画完整瞄具（`OtherTriggerSight`），选中的那把名字带括号，放大镜视场仍只给选中的；每把扳机上的炮都测距 |

未解决：

- 「入场尾烟在飞机很后面」：静态核对了原生尾迹发射器（`0x2F6110` 每帧在 core+0x50 生成静止节点、速度参数为 0），插件每帧写入的位置偏移和读法一致，理论滞后最多一帧（约 3 m），没找到会拖后很远的代码路径。需要一张截图（哪架飞机、入场时机）再定根因。（2026-10-21 已定根因并修复：尾烟物体的矩阵用了喷口世界矩阵，节点被二次变换，见 [feedback-2026-10-21-jet-trail.md](feedback-2026-10-21-jet-trail.md)。）
- 第 3 条：EDF6 原生 `use_underground=0` 的载具请求在地下是否被禁用由武器 `+0x1790` 位决定（`0x6a61d7`），静态没确认；插件飞机请求在地下能不能叫出来要实机核对。
- 以上都没有进游戏实测（用户正在玩，不关游戏、不发键）。
