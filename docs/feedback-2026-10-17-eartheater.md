# 2026-10-17 反馈：噬地者（Earth Eater / アースイーター，4.1 的 UfoMother401）的血量与激光炮台

分支 `fix/edf41-eartheater-hp-1017`。地址：4.1 为 `EDF41.exe` RVA，EDF6 为 `EDF.dll` RVA（TimeDateStamp 0x678CCB46）。
可信度：**H** 反汇编 / 游戏文件直接读到；**M** 由读到的代码推出；**U** 没核。

## 用户原话（不可信数据，只当证据）

- 「噬地者的血量是不是不对」
- 「噬地者的某个激光的炮台攻击方式好像不对」

## 结论

**血量确实不对：移植版里噬地者的每个部件在所有难度、所有关卡都只有 1 级（s = 1）的血量。**4.1 原版按船体的有效等级缩放（s = 等级 / 10），
所以困难约少 4–6 倍，地狱少 11–15 倍，炼狱少 22–28 倍（例：M018 炼狱的核心 4.1 是 448 000，移植版 16 000）。简单 / 普通基本一致
（简单甚至持平），所以低难度玩家不会察觉，高难度明显「太脆」。

**激光炮台的根因是同一处**：炮台子弹的伤害、散布、速度、粗细、追踪速度都按同一个 s 算（SPEC 1.6 的式子），移植版固定 s = 1，
所以在困难以上：小型激光炮散布始终是最大值 0.23 rad（4.1 炼狱 0.05 rad），狙击光束速度 5.5（4.1 炼狱 19）、更粗，
速射激光的追踪角速度最慢，各炮伤害只有 4.1 的 1/4–1/28。**攻击的「流程」（状态机、充能时长、射程、开火间隔、子弹类、
连射节奏、追踪方向）逐项与 4.1 一致**（见第 4 节），所以「哪一门不对」静态上指不出单独一门，最可能被注意到的是
小型激光炮（绿激光，单发、大散布、几乎打不中）和速射激光炮（紫色连射扫射）。玩家说的是哪一门，没有更多信息（U）。

两件事一起修：部件记下船体的有效等级（EDF6 SetLevel 写的 +0x49C），HP 与子弹参数按 s = 等级 / 10 算。

## 2. 4.1 原版的血量公式（H，本次重读）

- SetLevel `0x28eab0`：`+0x258 = level × game_object_level_adjust`，`+0x25c = 0xd98e0(raw)` = `raw × lerp(lvMin, lvMax, 任务序号 / (任务数 − 1))`
  （`CONFIG.SGO` ModeList 当前模式当前难度的行），然后 `0x56b930(&8)`：第一次置位调**槽 3**。4.1 的 CreateEnemy / CreateNeutral
  （0x152c0d、0x151b33 等，队伍 1 / 3）都调它。
- **船体槽 3 = `0x261bf0`：`+0x490 = +0x25c`**（`8b815c020000 898190040000`）。构造时 +0x490 = 10.0（0x25ee2a）。
  旧笔记（`docs/edf41-ufomother401.md` 1 节、插件注释）写「+0x490 = 10.0 从未改写 → s = 1」，**是错的**，移植就照它把 s 钉成了 1。
- 布局 `0x25fbb6`：`panel->0x26f9f0(hull +0x490)`；`0x26f9f0` / 炮台的 `0x269a80`：`HP = level / 10 × 耐久(+0x160) × R[3][0] × R[1][人数−1]`，
  写最大 / 当前（+0x168 / +0x16c），然后尾调槽 29 / 28 用同一 level 建子弹块。Panel01 的槽 29 `0x26ebb0` 把 level 交给每个炮台
  （0x26ec1c）。炮台在 Panel01 构造（0x26e4b0）里建、先拿默认 10.0，布局时再被改成船体等级。
- 单机 R[3] = R[1] = 1（4.1 与 EDF6 的 CONFIG.SGO 都是）。

## 5. 修复

- `src/edf41mother401.cpp`：`Part::level`（4.1 的部件等级，10 = 1 级）；`MakePanel` 记 `LevelS(船体) × 10`（船体 +0x49C，EDF6 的 SetLevel
  在 CreateEnemy / CreateNeutral 里按脚本等级和 EDF6 难度行写的有效等级）= 4.1 0x25fbb6；`MakeBatteries` 把面板的等级交给炮台 = 4.1 0x26ebb0；
  `InitPart` 的 HP = `Difficulty(耐久 × s)`（同 UfoCarrier508 0x4F6D00 与本仓 301 / UfoRobo 的写法）；`SetupBullets` 的 s = level / 10。
  每类第一个部件写日志 `level … (s …), durability … -> …`，实机可直接核。
- 对齐准则：部件用**船体在 EDF6 里的有效等级**（与同一关 EDF6 的其他敌人同一套难度缩放），公式与 4.1 逐项相同；不按难度写死倍率。
- `docs/edf41-ufomother401.md`：更正第 1 节「+0x490 从未改写」与 2.4 的 HP 式子。
- `tools/selftest.py` `edf41_mother401_parts_take_the_hull_level`：源码契约（面板 / 炮台记等级，HP 与子弹按 s，不再有 `Difficulty(base)` /
  `s=1.0f`）；装了 EDF4.1 时逐字节核 4.1 的路径（SetLevel → 槽 3 → +0x490 → 布局 → 0x26f9f0 → 槽 29 → 炮台 0x269a80 → 槽 28）；
  再装了 EDF6 时核两边难度范围让噬地者各关 s 相差 ≤ 10 %。没装游戏打印 skip。
- 数据：无需再生成（SGO 耐久本来就对）。`edf41port/` 不动。
