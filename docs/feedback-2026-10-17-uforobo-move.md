# 2026-10-17 UfoRobo 机器人形态「光攻击不动」

## 原话（玩家反馈，不可信数据，只当证据读）

> UfoRobo 是不是少了ai，怎么感觉他光攻击但是不动

对象：4.1 UfoRobo（`OBJECT/UFOROBO401.SGO`；M007、M411、DLC M415 / M416 / M010），规格见 `docs/edf41-uforobo.md` §1。

## 根因

**事实**（日志 / 数据 / 反汇编）：

- 飞行形态会动：已有实机日志里 A1 期间位置一直在变（`rfp_M416` 出生 229 300 −40 → 第 600 帧 161 288 −52；`rfp_M010` 三台同样），本次不改它的行为。
- 机器人形态不动：收尾实机（`jobs/14618f05/tmp/gametest/rfp_M411`、`mg2_M411`、`rfp_M416`、`rfp_M010`，开发开关全 0）每 600 帧一行的状态**几乎全是 `S9 attack`**，位置几分钟不变（`rfp_M411` 第 600–8400 帧一直是 −271 −6 412）。日志顺序：`S7 -> S9`、同一帧 `A5 -> A3`，5–7 秒后 `A3 -> A4`，攻击片段放完 `S9 -> S7` 的下一帧就选下一个攻击 `S7 -> S9`。
- 数据没问题：打包的 SGO 里 `edf41_robo_motion` 18 项、名字全是 CAS 状态（`walk_f_nl` 400 帧前进 50，`turn_l90` 840 帧 +1.571 …），`robo_attack_table` 8 项；步伐的根运动写入在别的跑里生效过（`net6_M411`：−300 453 → −3 51）。
- 攻击片段很长（`UFOROBO401.CAS`）：`attack_fire_straight` 1702、`attack_fire_cross` 1722、`attack_fire_genocide` 1120 + 1118、劈砍 / 践踏 1498–1500 帧，即 25–37 秒；实测 S9 每次 29–38 秒，与之相符。
- 攻击计时器 600/s–1800/s 帧（`s` = 2.35 时 4–13 秒），在 A3 里每帧倒数（4.1 `0x27A3D9` 调 `0x271AB0`）。
- **偏差**：插件的 A5 在身体离开 S7（进入 S9）的那一帧就回 A3（旧 `edf41robo.cpp` `case kA5: … if(r.body!=kS7 …) AiSet(r,kA3)`）。于是攻击还在放时 A3 已在倒数，4–13 秒就到期进 A4，A4 等到 S9 一结束就选下一个攻击 —— S9 首尾相接；腿的阶段 1 / 2 计数也在攻击期间耗光，阶段 2 的前进 / 后退基本轮不到。
- **4.1 的做法**（EDF41.exe）：A5 进入时（`0x27A770` 主机分支）选好攻击后**直接把身体切到 S9**（`0x27AAE2` 调 `0x27E950(+0x15B0, 0x278C20, 项号)`），之后每帧（`0x27AB46..0x27ABD3`）只有身体回到 S7 才回 A3。所以攻击期间 A3 不跑：计时器不倒数、腿的计数不减；攻击结束后先有 4–13 秒的 A3（转身 / 前进 / 后退 / 接近），再下一次攻击。

**同时对照出的小偏差**（一并按 4.1 改，事实）：
- 计时器 `0x271AB0` 在「减之前的值 ≤ 0」时触发（插件是减之后 ≤ 0，早一帧），且总按距离窗口判断（攻击计时器窗口 0–1000、传 0）。
- 接近模式（`+0x1538`）里横移只在阶段 1、2 都用完后才跑，用完且间隔 ≤ 0 时横移 + 参数一起重掷（`0x27A2DF..0x27A325`）；插件原来每帧都叠横移。
- 命令用 4.1 的原值（巡航 ±90、横移 ±22.5、接近 ±1），不再归一成 ±1（S7 的选择结果相同）。
- 选中的攻击由 A5 直接进 S9，不再经 S7 的 `+0x161C` 分支：原来脚相位非 0 时 S7 先选「收脚」步伐，A5 随即回 A3，这次攻击就丢了（`net6_M411` 日志 `A5 → S8 step`）。

**推断**：玩家看到的「光攻击不动」就是上面这条 —— 机器人形态几乎一直处在 S9，四组炮（膝 / 肩自动开火）也一直在打。

## 修复

- 新头文件 `src/edf41robo_ai.h`（纯逻辑，可离线测）：4.1 的计时器 `TimerTick`、参数重掷 `Reroll` / `RerollSide`、腿 `RobotLegs`（`0x27A180` 主机分支，接近 / 普通两条路）、A3 / A4 / A5 一帧 `RobotAiStep`（A5 持有到身体回 S7）、S7 的选择 `MoveOf` / `ChooseInStand`（`0x278810`）、根运动采样 `SampleMotion`。
- `src/edf41robo.cpp`：A3–A5 走 `RobotAiStep`；A5 进入时 `ChooseAttack` 后直接 `BodySet(S9)`，没有合适项（或没目标）回 A3；S7 走 `ChooseInStand`，转身替换步伐时不再先进一次 S8 再改回；腿的字段收进 `edf41robo::Legs`。
- **不照抄**：4.1 A5 没有合适项时把**身体**状态机设成 A3 的函数（`0x27AAB3`/`0x27AAFF` → `0x27E950(+0x15B0, 0x27A180)`，身体再也回不到 S7），插件改为 AI 回 A3。只在目标 > 1500 m 或没有目标时会发生。
- 测试 `tests/edf41robo_ai_test.cpp`（ctest `edf41robo_ai`）：计时器、MoveOf、S7 选择、两种模式的腿、「A5 持有整段攻击、计时器不动」，以及 10 分钟的整机模拟（真实片段长度、目标 800 m 外、s = 2.35 / 2.73）：普通模式 18–23 步、移动 150–560 m，接近模式 22–23 步、离目标从 800 m 到 260–490 m，攻击 14–16 次，攻击帧里 AI 从不在 A3。把 A5 改回旧行为，这个测试失败。

## 未验证
