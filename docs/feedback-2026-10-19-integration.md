## 明确边界

未写入游戏目录，未启动、控制或中断用户游戏。离线、私有 DLL 指令执行与 WARP 渲染检查不等于真实驾驶、反射/听感、完整任务通关或两台机器的联机验收。

- 热像当前验证主视口的不透明世界 pass；不支持的表面保持光学并提示原因。未承诺全部透明效果/所有 Boss/分屏第二视口的热像覆盖。
- M163/BMPT 为自建模型；外部模型 API 无认证时返回 401，没有宣称已经下载。M163 六管尚无独立旋转动画，碰撞外形与悬挂使用经过骨/炮口核对的原生基础近似。
- 4.1 材质适配恢复基色与原透明度合同，光照仍为 EDF6 PBR；没有声称完整复现旧引擎的 Phong 渲染。
- 配装页仍通过常驻提示的快捷键进入，使用原生控件；未新增尚无已验证回调的原版菜单按钮。
- 未把旧战役全量转成 AC，也未按 BVM 后缀强制改难度。原生审计没有证实普遍固定难度泄漏，不会基于猜测改写全局难度。

更新此构建需要更新 DLL，并重新运行安装器生成载具、材质和房间布局；只复制 DLL 无法补出新资源与入口元素。
