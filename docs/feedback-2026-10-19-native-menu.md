# 2026-10-19 配装的原生菜单入口

用户要求将离线 HQ 与联机待机房的配装功能做成能直接找到的原版菜单。这次新增真正的原生菜单项，名称为本地化的「支援战前配置」；鼠标可点击，键盘/手柄沿原版菜单移动焦点并确认。进入后打开现有载具与 NPC 配装页，F2 / L3+R3 保留。

入口由游戏自身的 Button、列表布局、Click/focus/kill_focus 事件与弱画面回调构造；定义不进初始布局树，插件未加载或关闭时不留空白焦点项。原版资源逐字节保留；画面销毁、遮挡、关闭按键尚未松开时不能误打开。具体契约和证据见 [原生菜单逆向](room-native-menu-re.md)。

安装后需重新运行安装器更新两份布局。仅更新 DLL、沿用旧 Mods/UI 布局时继续保留快捷键入口并记录需要更新布局的日志。

定向验证：原有房间菜单、预览、同步、隔离测试连同新用例共 12 项 CTest 全通过；纯界面逻辑 702 项、布局 559 项、真实源码 native ABI / 生命周期替身 79 项、实 DLL 与源码门禁连接 116 项检查通过。运行时对象使用严格 MSVC `/W4 /WX` 编译。没有启动游戏，鼠标/手柄实际体验与双机房间仍需游戏验收。
