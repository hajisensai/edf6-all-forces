# EDF4.1 玩家外观：真实染色链验证（2026-10-19）

用户要求新的角色外观继续使用原有主色、副色。上一轮只校验 SGO 参数名与资源完整性，这不足以证明游戏实际上传了颜色。本轮补查了原生取色、实时编辑、材质常量上传，以及原始压缩纹理在实际像素着色器中的结果。

## 原生取色和上传

`tests/outfit41_palette_native_test.py` 将受支持版本 `EDF.dll` 映射到私有 Unicorn 模拟器，执行已核对 SHA-256 的原始机器码。没有启动游戏，也没有向游戏安装目录写文件。

- HQ `0x93B466..0x93B4E3`：从存档取当前玩家、兵种、原版外观的两色，写入模型构造描述 `+0x24/+0x34`。
- 战斗 `0x591965..0x5919FC`：执行实际 `CALL 0xD8700` 取原版外观，按 `soldier_color` 的颜色槽读取同一存档颜色。
- 实时调色 `0x93C202..0x93C249`：只有玩家、兵种、外观三项都匹配时才更新预览目标色 `+0x158/+0x168` 和留存描述 `+0x33C/+0x34C`，另一色不变。
- 材质上传 `0x6C32B3..0x6C32F9`：执行原生参数到常量缓冲区的写入，并验证 GPU 脏位。运行库 `memcpy` 是唯一替代的外部调用边界；参数写入地址和长度仍由实际原生指令计算。实际 shader 的 RGB 为 12 字节，上传保持其后常量填充不变。

夹具给两名本机玩家、四个兵种、四个原版底外观、两个颜色槽分别设置不同的合法自定义色与选中颜色索引。HQ 与战斗读取结果均与所选输入逐字节相同，实时调色身份不匹配的消息不写入。**271 项执行校验通过**。

`src/outfit41.cpp` 的自定义第六项只保存额外外观开关和重建模型，保留原生存档外观编号。上述原生调用因此继续使用同一组颜色；无需额外 hook 或另建与原生编辑器脱节的调色表。

## 实际材质与像素输出

`tests/outfit41_color_native_test.py` 从原版 EDF4.1 / EDF6 的 `DX11.cpk` 读取 `snd_Chara_2ColorChange` 和 `_Alpha`。原始四兵种模型、转出的玩家外观、正文和两档 LOD 都参与核验。

两代 shader 的真实反射数据一致：`change_color0/1` 均为 `float3`，位于材质常量缓冲区 `cb2` 的偏移 16/32。`t2=param_cm0_cm1_occ` 的 R/G 通道分别控制主色、副色，B 为遮蔽。转出 MDB 将原参数类型 `0x302` 转为 EDF6 的 `0x402`，有效色值、材质遮罩引用、BC1/BC3 DDS 数据保持原样。

`tests/outfit41_color_warp_test.cpp` 在 D3D11 WARP 上直接运行原版 4.1、原版 6、兼容 alias 6 的像素字节码，采样真实压缩纹理并写入实际材质默认值和独立切换的两个颜色槽；未用 CPU 上重写的公式替代 shader。测试着色器对整个 UV 平面采样，验证材质输入及 Deferred 基色输出，不重现角色几何、照明和完整游戏帧。

实跑结果：

| 范围 | 结果 |
| --- | --- |
| 四职业 × 正文/LOD1/LOD2 | 全覆盖 |
| 实际被绘制的染色材质 | 86 个 |
| 原始 DDS 与转出 DDS 比较 | 344 次，均逐字节相同 |
| 去重后的材质/纹理/shader 夹具 | 23 组 |
| 实际像素着色器执行 | 1,130,496 次 |
| 原版 4.1 与 alias 6 的 RGB 最大差 | 0 |
| 独立调主色/副色的每职业最大 RGB 变化 | 均大于 0.31 |
| 调色导致的 alpha 变化 | 0 |

Deferred 与 Forward 的四组 alias 反汇编差异也受到核验：只有已审核的反射泛白 MAD 因子改变，染色指令、色槽和参数元数据未改动。Forward 在此验证字节码差异，未将其像素输出等同于 Deferred 的基色附件。

## 结论与复现

未发现现有四套 4.1 玩家外观的颜色路径或遮罩通道有需要修改的错误，因此本轮没有为制造差异重写正确的模型或增加覆盖原生颜色的运行时 hook。现有额外外观使用原生主/副色，现有材质兼容修复保留真实染色能力。新增的是原生代码和实际 GPU 输出的回归保护，补足上一轮仅检查参数存在的证据缺口。

```powershell
python -B tests/outfit41_palette_native_test.py "D:\steam\steamapps\common\EARTH DEFENSE FORCE 6\EDF.dll"
python -B tests/outfit41_color_native_test.py --probe build/outfit41_color_warp_test.exe
```

WARP 探针已独立用 MSVC C++17 `/W4 /WX /permissive-` 编译通过。第一项需要 `pefile`、`Unicorn` 与支持的原生 DLL；第二项需要 Windows、两代原游戏档案与编译好的探针。依赖不可用时退出 77，明确跳过。

仍未进行实际游戏画面与双机联机验收；此处证明本机两玩家原生路径、材质输入及着色器染色契约，不能替代真实游戏照明和远端外观同步的画面验收。没有把截图当作新角色模型的源文件，也没有新增未指定的第三方角色。
