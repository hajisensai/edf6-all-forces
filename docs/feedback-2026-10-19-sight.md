# 2026-10-19 反馈：激光瞄准线滞后、切换成像没反应

用户原话（`docs/feedback-2026-10-19.md` 第 1、2 条）：

1. 「跳或者移动的时候红外瞄准的线没有实时跟随」
2. 「切换成像没反应」

## 1. 激光瞄准线滞后

「红外瞄准的线」是步兵武器上的 `WeaponAttachment_LaserSight`（岩雷鸟、KFF LS 等），不是载具红线（载具红线在玩家座位上已由插件 HUD 取代）。

起点从哪来（H，静态逆向，`tests/fp_render_native_audit.py` 逐字节校验）：

- slot 2 `0x6890A0`：`r8 = [weapon+0x1D0]`（第一个枪口条目），起点 = 条目 `+0x90` 的位置行 − 0.02 × 其上方向行（常量 `0x17AA990` = 0.02×4），方向 = 条目 `+0xB0` 行；结果写主对象 `+0x90`。
- slot 3 `0x688970`：把 `+0x90` 抄到主对象 `+0x130`，即绘制子对象（`+0x10`，虚表 `0x17E2480`）的 `+0x120`。
- 枪口条目 `+0x90` = 局部矩阵 `+0x10` × 骨骼记录 `[+0]` 的 `+0xB0`，由武器自己的更新（slot 5 → `0x6934F0` → `0x6969A0`）写入。

因此绘制线程读到的起点属于某一个更新步，而枪模用的是绘制时的姿态数组；绘制线程最多落后游戏线程 3 步（`fp-render-re.md` §17）。

- 第一人称（根因，代码确认）：`LaserDrawSelected` 用的是**镜头步进时**的 `d.view[hand]` 去变换这个起点，而枪模本身按**本次绘制**的 `DrawTransforms`（`anchor_now⁻¹ × placeWeapon × C_draw`）放置。走动 / 跳跃时这两者相差镜头步进之后游戏又走过的位移，线就离开了枪口——正是 `DrawTransforms` 当初为枪模解决、但激光没跟上的那类问题。
- 第三人称（推测，未实机）：激光 slot 2/3 与武器 slot 5 在同一步里的先后未逆向到调度器，若激光先于武器更新，原版自身就会晚一步。

修复（`src/firstperson.cpp` `LaserMuzzle` / `LaserDrawSelected`）：每次激光绘制时，从武器第一个枪口条目的局部矩阵 × 该骨骼在**枪模绘制姿态数组**里的矩阵重算起点（同样减 0.02 上方向）；第一人称再乘本次绘制的 `DrawTransforms`（与枪模同一个 T），第三人称直接用。读不到枪口条目 / 骨骼时第一人称退回原做法（镜头步进 T × 原生起点），第三人称保持原生。命中点、射线、子弹、网络都不改，绘制后逐字节恢复。

## 2. 切换成像没反应

`thermal.cpp` 原逻辑：`N` 只在 `inSight`（实体瞄具已开 `SightZoomMounted`，或炮舰炮手）时才被接受，`SetMode` 同样要求 `inSight` 和渲染钩子已装；否则按键被直接丢弃，HUD 仍显示「光学」。

- 坦克上不先按 `Z` 进实体瞄具时按 `N`：无任何变化。
- `ThermalClass` 把 `603_Flak`、`506_Helicopter`、`Helicopter409` 列为有热像设备，但这些模型没有 `vc_optic_` 镜头（`pylib/vehicle_optics.py`），`SightZoomMounted` 永远为假：HUD 一直显示「[N] 切换成像」，按了永远不生效。
- 渲染钩子没装上时 `SetMode` 返回假，按键同样无声无息。
- 没有热像设备的座位按 `N`：提示行根本不显示。

修复：

- 有设备的座位随时可按 `N` 循环所选模式，HUD 立即显示所选模式；不在观瞄里时附「进入观瞄视角后生效」，进观瞄后转为「热像准备中」直到第一次合成成功（`active`）。
- 「观瞄」增加该座位的第一人称视角（`FirstPersonVehicleView`），无镜头的防空车 / 攻击直升机由此可用热像。
- 钩子缺失 / 表面不支持时显示光学 +「热像不可用，已回退光学」（琥珀色）。
- 无设备座位按 `N`：HUD 2.5 秒显示「[N] 切换成像：此座位不支持热像」。

验证：`thermal_runtime_test`（瞄具外按键、第一人称算观瞄、无设备座位应答、钩子缺失原因）、`pvp_hud_layout_test`（HUD 文本）、`fp_ride_lifecycle_test`（第一人称 / 第三人称起点按绘制姿态）、`fp_render_native_audit.py`（激光起点来源字节）。

未实机：GPU 合成能否在实际观瞄画面里成功（`MainView` 判定、表面格式）、第三人称原版是否本来就晚一步、手柄座位仍无切换键（`keys` 只认键盘座位）。
