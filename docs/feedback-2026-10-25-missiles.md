# 2026-10-25 反馈：载具导弹弹道（BMPT 钻地、天启炸到自己）

用户原话：

> bmpt的飞弹怎么会往地里射？天启也会射到自己身上导弹

## 根因（静态 H：生成数据与已逆向的开火路径；未进游戏复现）

插件的每一种导弹挂载（`pylib/vcobjects.py` `STORES` 里的 `Missile`：战机的 AIM / AGM / Hydra / ESSM / LAHAT、BMPT 的
9M120 / 9M120F、通古斯卡 9M311、天启防空导弹、爱国者 PAC-3，以及沙扎比的盾牌导弹）都由 `_missile_sgo` 从原版直升机导弹
`V_506HELI_MISSILE01.SGO` 改出来。`Missile.params` 改了弹速、寿命、锁定等，但**没有写 `FireAccuracy`**，于是全部沿用模板的
**0.3**。

- `FireAccuracy` 是出膛散布锥的半角（弧度）：开火 `0x691B02 → 0x4E820`，极角在 `[0, FireAccuracy × weapon+0xE14]` 内均匀取
  （`src/launcher.cpp` Cone、`tools/make_katyusha.py` 已逆向）。0.3 rad ≈ 17°。原版直升机导弹是「乱喷 + 原版纯追踪」，散布是它的
  设计；插件导弹关掉了原版追踪、改用比例导引（`src/missile.cpp`），出膛方向就是导弹真实的初始航向。
- 出膛方向：这几种导弹的炮口定位点是模式 0（直升机模板的 MAB 定位点没有 `fire_model_direction`，本机 Root.cpk 读出），方向 =
  挂点骨骼的前向行（`0x633DD0` 每帧拷到 `weapon+0x150`）。地面载具的导弹挂在 `cannon_main`（炮塔偏航骨骼，绑定朝向为单位阵，已对
  V603 原版与战雷 BMPT / 天启骨架逐一核对），即「沿车体水平、随炮塔转」。骨骼与发射点本身没有错。
- 弹刚离轨只有 `eject` 0.3 m/帧，比例导引的指令加速度 ∝ 速度，前十几帧几乎纠不回来；`AmmoGravityFactor` 0。
  - **BMPT**：发射管高 2.37–2.65 m。向下偏 17° 的一发约 8 m 就触地（0.3 m/帧起步、0.05 m/帧² 加速，约 13 帧），即「往地里射」。
  - **天启**：导弹巢在炮塔两侧 (±1.8, 3.1–3.3, 1.0–1.2)，向下 / 向内偏的一发落在车前十米内，12 m 爆炸半径罩住自己；向内偏
    的还会擦过炮塔侧面（离发射点 0.59 m）和双管（x ±0.11–0.93，y 2.34–3.17，z 2.8–9.7）。即「射到自己身上」。
  - 战机同样受影响：Hydra 70 无制导火箭 17° 散布；AGM / LAHAT 也是先偏再导引回来（载机速度大，不太显眼）。

## 修复

- `Missile.spread`（新字段，`FireAccuracy`）：导轨决定导弹的出膛线，有制导的一律 0；无制导的 Hydra 70 给 0.006 rad（一次四发
  不叠成一个洞）。`Missile.params` 写入 `FireAccuracy`。共享代码一处改，所有导弹挂载（战机、地面车副武器、潜艇母舰、沙扎比）一起
  生效。
- `tools/selftest.py` `missiles_leave_along_their_rail`：每种导弹的 `FireAccuracy` 等于它自己的 `spread`、有制导的为 0、无制导的
  在 (0, 0.01]；有游戏文件时确认模板本身仍是大散布（> 0.1），并对每种导弹实际生成的 SGO 逐一核对。

## 后续（2026-10-26，合并审查提出的两处）

### 1. BMPT 未锁定发射仍沿车体水平（已修）

- 根因：导弹挂点 `cannon_main` 只偏航不俯仰，出膛方向 = 挂点骨骼前向行（模式 0，`0x633DD0`）。没锁定时导弹沿车体水平飞；
  瞄上坡目标、或车头朝下停在坡上时仍会钻地。
- 战雷原模型里四根 Ataka 发射管（`9m120_rocket`，含管口玻璃）和它们的托架 `gun_mask_03 / 04`（战雷里 `gun_mask` 是随炮俯仰的
  炮盾节点）本来就挂在武器模块上，真车也一样：发射架随双 2A42 一起俯仰。旧规则把它们留在炮塔上，是因为导弹挂点写死成
  `cannon_main`。
- 修法：
  - `tools/prep_wt_tracked.py`：新增 `Vehicle.missile_bone`（默认 `cannon_main`）。BMPT 的发射管和托架挂到武器模块
    `cannon_l`（耳轴 y 2.44 / z −1.47，与 `cannon_r` 同一条俯仰轴），炮口契约的骨骼取 `missile_bone`。如果发射管被规则放到了
    别的骨骼上，prep 直接报错。
  - `models/wt_bmpt/model.json` / `model.npz` 用本机 Sketchfab 源（`D:\APP\edf6-models\downloads\wt_bmpt`）重新生成。规则不变时
    这两个文件逐字节复现；这次只有发射管（35440 个三角形）和两个托架（12982 个）从 `cannon_main` 换到 `cannon_l`。
  - `tools/make_tracked_combat.py`：导弹挂点取炮口契约的骨骼（必须只有一根），不再写死。BMPT 生成的挂点从左到右依次为
    `cannon_slide_l, cannon_slide_r, cannon_l, …`；通古斯卡、天启、爱国者仍是 `cannon_main`（不变）。
  - 结果：导弹沿炮管线出膛，锁定锥也从炮管线量起（玩家准星），NPC 副武器的瞄准门同样读这个方向。
- 碰撞不变：武器模块的碰撞本来就并在炮塔里（`collision` 按节点名分），发射管仍在其中。
- 没改的：通古斯卡（真车发射架也俯仰，但它的 9M311 只锁空中目标）、天启（导弹巢在耳轴后方 1.4 m，绕炮的耳轴俯仰会把巢压进
  炮塔）、爱国者，以及无战雷模型时的程序化 BMPT（`pylib/bmpt_model.py`，仓库带了 `models/wt_bmpt`，平时用不到）。

### 2. 天启「射到自己」：自己的弹会不会打到自身部件（核实：不会，未改代码）

静态 H（EDF.dll，指令逐条读过；可达性只沿直接调用追）：

- 离线时车载武器的弹 owner 是载具本身（`src/online_authority.h` ShooterIsAttacker）。收集器 `0x232AA0` 在 bit 0x80 未置位时，
  按 owner 指针跳过 key-0 对象等于载具的候选刚体。
- 部件刚体的 key-0 对象就是载具：用户日志（只当证据读）里炮舰机诊断行一直是「0 by a part's body id only」。
- bit 0x80 对车载导弹永远不会被置位：
  - 移动类型由 init 清 0（`0x231CE7 xor edi,edi` / `0x231CE9 mov [rcx+0xAF0],edi`），分派 `0x235E2E` 走类型 0 `0x2364D0`；
    类型 2 的 `0x235FA0`（含 `0x2361E4`）对导弹不可达。
  - 类型 0 里 `0x236662 or [rbp+0xAF4],0x80` 前的门（`0x23654A..0x236560`）要求 core+0xB04 ∉ {0,3} 且 core+0x6D8 非空。init 在
    `0x231D13` 把 +0xB00 清零；+0x6D8 只由 EfsBullet 工厂的函数写，二者从导弹出发都追不到。
  - init 的 `0x231D24 bts / 0x231D29 btr / 0x231D2D cmp [rsi+0x8B]` 取 InitParam+0x8B。武器构造 `0x682EA0` 把它清零（`0x683448`
    memset、`0x6834B5`），开火 `0x696FD0` 不改。
  - 全二进制另外两处置 0x80（`0x2612E3` FlameBullet02、`0x28E9AB` SolidExpBullet01）都不在导弹路径上。
- 联机时，玩家开的弹 owner 是玩家，由已有的 `SparesOwnRide` 跳过其所乘载具。
- 所以 2 m 命中球即使扫过本车炮塔 / 双管，也不会直击自己；#262 之前「炸到自己」的来源是 17° 散布让导弹落在车旁、12 m 爆炸
  罩住本车。爆炸伤害走另一条路径（`0x542xxx`），是否伤及本车没有分析；去掉散布后导弹不再在车旁爆炸。

## 未改 / 未实测

- 没进游戏：BMPT、天启、通古斯卡、爱国者的导弹出膛后是否笔直离轨；天启在平地上近距离打低空目标是否还会掉到车旁。
- 发射架俯仰（后续 1）没进游戏看：发射管随炮俯仰时有没有穿进炮塔侧甲（尾端在耳轴后 0.19 m）、导弹是否从管口沿炮管线出膛。
- 通古斯卡 / 天启 / 爱国者的导弹仍挂 `cannon_main`，未锁定时沿车体水平（它们是防空导弹，靠锁定）。
- 后续 2 的结论是静态的；爆炸伤害路径是否伤及本车未分析。
