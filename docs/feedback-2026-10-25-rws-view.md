## 1. 武器站全屏、黑块

### 根因

`remote_display` 座位（无人炮塔 / 武器站）的第一人称由 `cockpit_screens.inc RwsDisplay` 画「显示器」，它调 `ScopeShade` 的 sensor 分支：
`scopeview.h RectHalf` 把视场定成屏高 80% 的 4:3 框，`RectBands` 在框外画四条 97% 黑带。宽屏上左右两大块、上下两条全黑。

### 修复

传感器画面就是整屏（`scopeview.h`：`RectHalf` = 整个视口减去短边 3% 的边距，`RectBands` / `kRectHigh` 删除）。`ScopeShade` 的
sensor 分支不再画黑带，只画贴边的细边框、四角标和视场名；`RwsDisplay` 的显示器淡绿色铺满全屏。炮舰机炮手的传感器视场（放大时
`sightzoom::Mask::sensor`）走同一函数，一起变成全屏。`tools/scopeview_check.cpp` 的 sensor 用例改为：各种分辨率下边框在视口内、四边
同样窄的边距、没有黑带。

## 2. 抬炮管看不见、炮舰机炮手位第一人称不能转视角（同一个根因）

### 根因（代码路径已核对，未实机）

载具第一人称的镜头 = 模型里标记骨骼 `vc_eye_<席位>` 的世界矩阵（`fp_vehicle.cpp VehicleEye` → `firstperson.cpp Ride`：
`memcpy(cam+0x220, ride.frame)`），位置和**朝向**都取自这根标记所挂的骨骼。`remote_display` 座位的标记挂的骨骼都不带瞄准：

| 座位 | 标记挂在 | 结果 |
|---|---|---|
| 通古斯卡 / BMPT / 火炮台 / 激光 / 轨道炮 / 88 炮 / 爱国者 / TOS-1 / 钻地车 / 天启 0 号位 | `cannon_main`（炮塔偏航骨骼） | 镜头跟炮塔转但永远水平，炮抬起来就出画（截图） |
| 炮舰机 1 号位（侧炮手） | `bomber401`（机身） | 镜头钉死在机身左侧；炮手的瞄准是插件的虚拟方向（`playerjet_crew.inc GunnerLook`，没有骨骼），鼠标转了，画面不动 |
| 410 运输直升机 1 / 2 号位（吊舱炮） | `gunCam_l` / `gunCam_r`（机身子骨骼） | 同上，画面不跟瞄准 |

中键自由观察（`VehicleLookCamera`）只是在这个固定朝向上再叠一层，所以看起来「能动一点」但松手就回去。

### 修复（统一规则，不逐车）

`fp_view.h GunCameraFrame` / `GunCameraSeat`：一个座位有武器站显示器（`vc_scr_<席位>_sensor_` 标记，即 `remote_display` 套件），且不是
玩家亲自飞的载具（插件飞机 / 直升机 / 沙扎比）的 0 号位，它的第一人称就是「炮上的摄像头」：

- 位置：仍是模型标记的眼点（不动模型、不动安装器）；
- 朝向：该座位**原版镜头**这一帧的朝向（原版步进后的 `cam+0x220`，第一人称覆盖之前），保持水平不滚转。原版镜头对每种座位都随玩家
  的瞄准转（炮塔座位的原版镜头、炮舰机炮手的 `GunshipGunnerCamera`、吊舱炮的原版机位），所以一条规则覆盖全部炮手位；
- 中键自由观察照旧叠在上面；有 `vc_optic_` 的座位放大 / 1 倍瞄具仍由 `sightzoom.cpp` 接管（不变）。

于是抬炮时画面跟着抬、准星在画面中心附近；炮舰机侧炮手和 410 吊舱炮的第一人称随鼠标转。驾驶座、有实体座舱的炮手座不变。
日志：`FP seat N: a gun camera, laid with the aim` / `its cockpit's frame`（每次变化写一行）。

已知取舍：镜头方向取原版镜头的视线方向（平行于它），眼点不在原版镜头处，近距离目标有视差（几米 / 几百米 ≈ 1°）；真正的弹着由弹着点
十字和提前量标记标出（它们按炮口实际弹道算），不受影响。

离线：`tools/fp_view_check.cpp GunCamera`：各种偏航 / 俯仰下，摄像头从自己的眼点看原版镜头的方向、去掉滚转；原版没有前向时不接管；
`GunCameraSeat` 的取舍（显示器座位都算，飞行器驾驶座除外）。

## 3. 第一人称伤害数字没了

### 根因（静态反汇编，未实机）

载具第一人称有座舱屏时 `FirstPersonHidesStockHud` 让 `map.cpp StockHud` 把原版 HUD 的总开关（镜头 `+0x200`）按在 0。伤害数字
`ui::DamageNumberDrawTexture` 属于 `ui::HUiHudDamage`，经外层 `ui::HUiHudDamageObject` 的绘制 `0x8168B0` 画，它第一件事就是检查
`+0x200`，为 0 整层跳过。细节见 `docs/hud-re.md` §12.3。

### 修复

只给伤害层「借」开关：`HUiHudDamageObject` 自己的 vtable 第 3 槽串上 `map.cpp DamageDrawHook`；记录里多一位 `damage`（这次按住开关的
只是载具第一人称，不是地图视角）。条件成立且游戏想显示 HUD（过场藏 HUD 时不借）时，在 `hudLock` 下临时写 1 画这一层再写回 0。
雷达、武器栏、护甲条、准星仍藏着（它们的信息在座舱屏上）。离线：`tools/map_hud_check.cpp` 新增 6 条。

## 4. 火控 / 瞄具按载具配（`src/firecontrol.h`）

现有：按武器自动选分划（`reticle.h`：坦克炮人字 + 密位 + 弹道表尺、机炮环、防空炮提前量环、狙击十字）、弹着点十字、目标提前量点
（`vhud.cpp GunMarkOf`，准星 5° 内的敌人）。这次加的是「火控系统档次」，按武器文件（每门插件炮都有自己的 SGO）决定它在分划之外还显示什么：

| 档次 | 载具（武器文件前缀） | 测距读数 | 计算提前量点 | 解算数据（飞行时间、目标速度） | 提前量引导线 | 截获锥 |
|---|---|---|---|---|---|---|
| 光学瞄准镜 | 88 mm 高射炮、突击虎 | 无（靠密位与表尺估距） | 无 | 无 | 无 | 5° |
| 陀螺提前量瞄具 | M163、四联火神 | 有 | 有 | 无 | 无 | 5° |
| 激光测距 + 弹道计算机 | BMPT、TOS-1，及原版非防空 EDF 载具（未来战争：坦克、步战车、机甲……） | 有 | 有 | 有 | 无 | 5° |
| 跟踪雷达 | 通古斯卡、GDF-005（天空卫士）、密集阵，原版防空车，以及其它借 `Vehicle603_Flak` 类、表里没列的插件炮（火炮台、激光、轨道炮、天启……：沿用原有「603_Flak 即防空」的判据） | 有 | 有 | 有 | 有（虚线从炮口线到提前量点） | 15° |

- `vhud.cpp`：`StockArm` 记下 `fcs`、到提前量点的飞行时间 `leadFlight`、目标速度 `targetSpeed`；光学档不算提前量（`GunMarkOf`），
  截获目标用座位火控那门炮的截获锥（雷达 15°：不必把目标放到准星正中）。
- `hud.cpp FcsLead`：提前量标记 + 雷达的虚线引导线 + 计算机 / 雷达的解算行（「飞行 x.x 秒  目标 n km/h」）；`GunReticle` 和放大瞄具
  的 `ScopeData` 在光学档不显示测距数字。
- 武器站显示器（`RwsDisplay`）右上角在武器名下面写出该炮的火控档次。
- 离线：`tools/firecontrol_check.cpp`（各炮的档次、原版炮默认、档次之间功能逐级包含）。
