## 插件固定翼（`src/playerjet.cpp` ReadStick / Lever）

- 键鼠：W / S = 加 / 减油门，油门是一根停在原位的杆（空中、地面都是），满 95% 以上是加力；油门收到 0 再按 S 才放减速板。
  `PlayerJetBoostKey`（Shift）同 W。
- 俯仰改为空格（拉起）/ `PlayerJetBrakeKey`（Ctrl，压低）；A / D 横滚、鼠标瞄准照旧。
- 着陆时不再把键盘的油门自动收到 0（以前空中松手回 55% 巡航，着陆要清掉这个「没人推的巡航」；现在杆是玩家自己推的）。
- 手柄不变（Ace Combat 式）。插件旋翼机（空中航母、无人机）键位不变：W / S 仍是前进速度，Shift 巡航、Ctrl 下降（`Stick::boost`）。

## 原版地面车（`src/drive_gear.h`、`src/drivegear.cpp`，ini `VehicleGears`）

- 键盘点 W 升一挡、S 降一挡（按住每 0.4 秒再换），R / N / 1 / 2 / 3 / 4，松手保持挡位。
- 1–3 挡保持这辆车自己最高速度的 1/4、1/2、3/4（2026-10-26 起；之前按类别取 `vehmix.h` 的 16 / 22 / 30 m/s，见文末）；4 挡全开；R 倒车；N 松油门。
- 实现：`crew.cpp` InputHook 在原版输入前（`nextInput` 之前）把驾驶座左摇杆 Y（seat+0x2C4，前进为负）换成挡位的值，原版输入之后还回键盘自己的值，
  下一帧仍按键盘值换挡，不会把自己写的值当成按键。
- 原版对「半推」摇杆是否成比例没有记录（docs/heli-input-re.md 只记了扳机键盘是 0 / 1），所以定速用开关式：低于目标 − 6% 顶速时全开，到目标松开。
- 车速是位置差分投到车头方向（`kMatrix` 第 3 行），0.15 s 平滑。

## 2026-10-26 按每辆车自己的极速分挡

用户（转述；看到 ini 注释「1 / 2 / 3 挡分别保持这类车最高速度的 1/4、1/2、3/4（重车 16、轻车 22、摩托 30 m/s 为基准）」后）：要求挡位按每辆车自己的真实极速来分，不按车型类别的固定基准。

- 极速来源（`docs/vehicle-top-speed-re.md`）：CarBase 的齿轮表（`+0x1760` 起始、`+0x1770` 行数、16 字节一行），设定 slot 46 用 `setup[1][1]` 缩放每行速度（`0x66E1A0`），末行速度就是这辆车的极速（原版取值函数 `0x66CF00` 读同一行），单位 m/s。呼叫的车由请求的 setup 决定，同一种车不同等级差别很大（403 坦克 10–20、Striker 27–80、601 14–35、摩托 30–60 m/s）。
- `src/drivegear.cpp` `TopOf` 改为读这个值（`Readable` 检查表头与末行；`drive_gear.h` `TopOfGears` 判行数 1..32、值有限且 > 0）。读不到 = 该车不给挡位，日志一行 `GEAR v=... its gear table (+0x1760) unreadable, no gears for it`，不回退到类别常数。换车时日志一行 `GEAR v=... its top X m/s`。
- 哪些车给挡位不变（`Geared`：402 / 403 / 404 / 505 / 507 / 510 / 601 / 603 / Car / 607 / 60X / 503 / 511）；引擎声仍用 `vehmix.h` 的类别常数。
- 检查：`drive_gear_test`（`TopOfGears` 边界；极速 5 / 14 / 57.2 / 80 m/s 时各挡保持各自份额）、`drive_gear_native`（有游戏文件时：表偏移与 `0x66CF00` / `0x66E1A0` 一致、每个给挡位的类的 slot 46 都走到缩放、速度与 Havok 线速度比较即 m/s、11 个原版对象 SGO 算出的极速）。
- 未实机：没在游戏里看过日志里的极速是否与 SGO 推算一致；实际跑到的速度可能低于表值（坡道 / 阻力），那时 3 挡接近全开。
