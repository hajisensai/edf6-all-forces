# 2026-10-26 反馈：SDL1 驾驶员手臂伸得很远

**离线分析与离线检查，没有在游戏里实测。**

## 用户原话

- 「人手臂伸出去好远」
  （截图：第三人称后视角，玩家坐在 SDL1 Z 型驾驶座，HUD「CAR 速度 1 km/h 耐久 100% 挡位 1」，座席「1 驾驶席 你 / 2 炮手席 -」，
  左侧边斗上一挺机枪；驾驶员两条手臂像两根细杆从肩部向前右上方伸出，远远越过车把，指向远处。左上「…请求SDL1 Z型!」是请求消息）

## 是哪辆车

EDF4.1 移植的 `VEHICLE408_MOTORBIKE.SGO`（所有 SDL1 型号共用，`pylib/edf41bike.py`、`src/edf41bike.cpp`）。不是本插件的
EDF6 边三轮 `EDF6VC_SIDECAR`（那辆是 Vehicle503_Bike，边斗在右、没有炮手座）。

## 原因与修复

见 `docs/edf41-bike-re.md`「2026-10-26 反馈：驾驶员手臂伸向地图原点」。一句话：10-25 起驾驶座播 V503 的
`vehicle503_bike_driver`，这个姿势把双手 IK 到座位 `+0x40 / +0x80` 两个握把矩阵；只有 Vehicle503_Bike 每帧把自己的
`te_ik_l / te_ik_r` 骨骼写进去，408 是 Vehicle_Car，从没人写，矩阵一直是座位构造时的单位阵，目标就在地图原点。
修复：408 模型加同名两根骨骼（挂在车把 `handle` 下，位置与朝向取 4.1 驾驶员在这辆车上握把的手），插件在 Car 的 update 之后照 V503 的
`0x617A30` 把它们复制进驾驶座。
