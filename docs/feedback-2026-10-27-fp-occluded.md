# 2026-10-27 反馈：武器站第一人称抬炮后被自己的发射架挡住

用户原话：

> 有些载具第一人称会被挡到，比如温压弹火箭车，抬炮管以后看不见前面了。

（温压弹火箭车 = TOS-1，`EDF6VC_TOS1`，模型 `models/wt_tos1`。）

## 根因（几何离线核对，未实机）

武器站座位（`remote_display`）的第一人称是「炮上的摄像头」（`docs/feedback-2026-10-25-rws-view.md` §2）：位置 = 眼点标记
`vc_eye_<席位>` 的世界位置（`src/fp_vehicle.cpp VehicleEye`），朝向 = 炮口实际方向（`src/fp_view.h GunCameraFrame`，
`src/vhud.cpp SeatGunLine`）。朝向跟着炮俯仰，位置只跟标记挂的骨骼走。

TOS-1 的眼点挂在炮塔偏航骨骼 `cannon_main` 上，位于发射架后端上方 (0, 3.5, -2.4)；发射架（`cannon_slide_l`，其父骨骼是俯仰铰链
`cannon_l`）的俯仰轴在它脚下 (y 1.6, z -2.7)，即眼点下方 1.9 m、后方 0.3 m。发射架抬起时绕这根轴向后上方转，顶面扫过不动的眼点：
沿炮口方向的视线从 **31°** 起打在发射架上（再往上眼点干脆在发射架里面），V603 的仰角上限是 60°（俯仰铰链 `[1, -60, 5]`）。
爱国者（`EDF6VC_PATRIOT`）同构：眼点在箱组后端上方，箱组的轴在后端脚下，**26°** 起被挡。

`pylib/cockpit_kits.py remote_display` 的约定本来就是「眼点在炮的瞄具 / 摄像头处，挂在它的俯仰骨骼上」，原版车的武器站
（Blacker 的 `subCannon_*_aim`、`MachineGun_*_aim`）都这样挂；插件车一律挂在 `cannon_main`，对炮在眼点前方抬起的车没问题，
对发射架绕眼点下后方的轴抬起的车（TOS-1、爱国者）就会扫过眼点。

## 修复

- `pylib/cockpit_fits_plugin.py`：TOS-1 与爱国者的眼点改挂俯仰铰链 `cannon_l`（坐标不变，静止姿态下与 2026-10-24 预览的画面
  一样）。眼点随发射架一起抬，相对发射架不动，任何仰角下看到的都是 0° 时的画面；不俯仰的炮塔 / 车体绕它转，整个仰角范围内都不挡。
  不是「一律挂俯仰骨骼」：其它车把眼点挂到 `cannon_l` 上反而会在高仰角转进炮塔（突击虎 45°、无畏舰中 / 短炮塔 37° / 41°、
  电磁炮 41°、88 炮 58°），所以按几何选。
- `pylib/cockpit_sweep.py aim_blocked`：在车自己的模型（`wt_tracked.load`，炮台也是）上把炮从 -5° 抬到 60°，从眼点沿炮口方向
  投射视线，求打到车体自身的仰角。
- `tests/gun_camera_sweep_guard.py`（ctest `gun_camera_sweep_guard`，不需要游戏）：每个 V603 插件车的 `remote_display` 座位
  整个仰角范围内视线都不碰车体；并验证旧的 TOS-1 挂法（`cannon_main`）会被它抓到。模型文件夹不在（无畏舰炮塔是用户的模型）则跳过。
- `tests/test_emplacement.py`：炮台眼点骨骼允许 `cannon_main` 或 `cannon_l`（爱国者），是否挡视线由上面的守卫判断。

核对过的座位（眼点沿炮口的视线在 -5°..60° 全程不碰车体）：BMPT、通古斯卡、PzH 2000、突击虎、天启、TOS-1、无畏舰中 / 短 / 长炮塔、
密集阵、88 炮、GDF-005、激光、电磁炮、爱国者。喀秋莎是驾驶室座位（`truck_cab`，不是炮摄像头，镜头取驾驶室骨骼朝向，发射架在
驾驶室后方），不受影响；钻地车的钻头不俯仰；M163 / 四联火神是开放炮位（`open_rider`；2026-10-31 起也沿炮口看，`docs/feedback-2026-10-31-fp-aa-view.md`，已纳入同一扫描）。

## 未实机

- TOS-1、爱国者抬到高仰角时第一人称画面（应与 0° 时相对发射架一样）；
- 爱国者选 PAC-3（导弹挂在 `cannon_main`，只能偏航，镜头沿原版镜头方向）时，原版镜头俯角低于箱组俯角的情况下箱组会出现在画面
  下部——与改动前相同，不是这次引入的。
