# 2026-11-08 反馈：支援战机换成对应机型的模型

## 玩家原话

- 及开（2026-11-07，QQ 群）：「飞机的模型换成对应的模型」

## 维护者决定（2026-11-08）

- 指的是插件的**战机支援**：截击机、对地攻击机、多用途机、制空战斗机、炮艇机等（`tools/calls.py` 的
  `EDF6VC_CALL_INTERCEPTOR[_F]` / `STRIKE[_F]` / `MULTIROLE[_F]` / `FIGHTER[_F]` / `GUNSHIP[_F]` 一类）。它们现在是原版轰炸机模型缩放出来的，
  要换成各自对应机型的模型。
- 模型来源按优先级：EDF6 原版资源里已有的飞机模型 → 已入库或模型包里的移植资源（EDF5 / EDF4.1 素材包、`D:\APP\edf6-models`、
  `edf5port/`）→ 都没有时列出需要的外部模型（不自行下载第三方模型，授权未知的不用）。
- 能用现有资源的直接接上，碰撞 / 挂点 / 尾焰 / 座舱位置按新模型重算并有离线检查；没有合适来源的机型保持原样并列出需要的模型。
- 模型缺失属于安装坏了，不写回退分支：新模型必须进安装包 / 模型包并由安装器校验。
