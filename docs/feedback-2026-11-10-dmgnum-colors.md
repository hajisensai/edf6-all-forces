# 2026-11-10 反馈：伤害数字显示 NPC / 援军的伤害，弱点与误射用不同颜色

**全部是离线分析与离线检查，没有在游戏里实测。**

## 用户原话

维护者（2026-11-10）：

- 「屏幕上显示 NPC 和援军打出的伤害数字及弱点、误射颜色。我的意思是想加上弱点，误射的伤害颜色」

反馈站：这次没有对应的反馈站条目（需求直接来自维护者）。

## 理解

1. 屏幕上原版的伤害数字（`ui::HUiHudDamage` / `ui::DamageNumberDraw`）只显示**本机玩家自己（含自己坐的载具）**打出的伤害；
   NPC 队员、援军（插件的支援直升机 / 战机、无人驾驶的 NPC 载具、哨戒炮之类的友方物体）打出的伤害原版不在任何人的屏幕上显示。要显示出来。
2. 打到**弱点**的伤害、**误射友军**的伤害各用一种颜色，普通伤害保持原版颜色（白色）。

## 做法与结论

见 `docs/damage-numbers-re.md`（逆向与钩子）、README「伤害数字」一段（ini `DamageNumberColors` / `DamageNumberWeakColor` /
`DamageNumberFriendlyColor` / `DamageNumberAllies` / `DamageNumberAllyColor`）。

## 需要实机确认

- 数字颜色真的按通知里的填充色画（HUD 复制两种颜色那一步是静态逆向，M）。
- NPC / 援军的数字出现在受击位置、与玩家自己的数字合并 / 淡出的方式和原版一致，不会刷屏。
- 哪些敌人的部件倍率 > 1（弱点）：人形敌人的头部等部件、贝壳类开壳、狂战士等（静态逆向见 re 文档 §3），实际倍率值未在游戏里读过。
- 联机：伤害只在受击对象的权威机器上结算（`0x547E1D..0x547ED9`），NPC 打的数字只出现在结算那台机器的屏幕上。
