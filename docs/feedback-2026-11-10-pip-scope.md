# 2026-11-10 反馈：步兵瞄准镜改成画中画（镜外不放大、镜内放大）

**离线实现与离线测试，没有在游戏里实测。** 设计与逆向见 `docs/scope-pip-re.md`。

## 原话

测试站 #32（玩家反馈，只当证据读）：

- 「步兵瞄准太抽象了 应当是类似于写实战术类游戏那样的镜内放大效果（即倍镜外面是没缩放的，里面是缩放的样子)或者改回原来的版本」

维护者：

- 「32 改，应该改的都改」
- 第一版（镜片 = 本帧中心放大）问「倍率越高越糊，能否先接受」时：「画质不能接受」

## 现状（改之前）

`InfantryScope=1`（2026-10-11 起默认）：步兵开镜时游戏照原版把整个镜头 FOV 缩成 `π/4 / 倍率`，插件在整屏放大的画面上套单眼目镜遮罩
（镜外压暗）和按武器的分划。玩家看到的是「整屏都放大、四周一圈暗」，不是战术射击游戏里那种只有镜片里放大的瞄准镜。

## 这次改了什么

- `InfantryScope` 从开关改成模式：`0` 原版、`1` 整屏放大 + 目镜（旧行为）、`2` 画中画（新默认）。
- 画中画：镜头步（`CharacterGhostCamera` 第 4 槽）把原版刚写的放大 FOV 撤回 `π/4`，镜外的世界不放大；世界视图结束时
  （热像同一个钩子 `0x11E3AE2 → 0x11B63A0`，原生后处理和 HUD 之前）把屏幕中央圆形镜片区域用本帧中心放大重画；
  HUD 只画镜筒黑边、镜片边缘暗角和刻在镜片里的分划，不再整屏压暗。镜片放大倍率按这一帧自己的投影矩阵算，
  镜片里看到的角度与原版开镜完全一致（分划仍按真实视野刻）。
- 镜片画不了（多重采样、本机分屏的半屏视口、未知格式、世界结束钩子没装上）时本任务内自动回到 `1` 的画面，并写一行日志；
  不会出现「镜外没放大、镜里也没放大」的画面。
- 安装器：ini 里仍是旧出厂值 `InfantryScope=1` 的，升级时改成 `2` 一次（`DEFAULTS_MARK_1110`），玩家自己改过的值保留。

## 第二轮（2026-11-10，「画质不能接受」）

- 镜片不再放大本帧中心：引擎第 4 个视口（下标 3）挂一台跟随玩家相机的 `TraceCamera`（引擎自带调试命令 `stereo_camera` 就是这样建第二视角），
  每帧以镜片的窄视角、镜片直径大小的正方形（与屏幕像素 1:1）把世界整套再渲染一遍，在主视口后处理之前画进主画面的镜片圆里。
  镜片清晰度与倍率无关。旧的放大路径删除。实现 `src/scope_lens.cpp`（视口 3 与录制顺序）、`src/scope_pip_gpu.cpp`（合成）、
  `src/infantryscope.cpp`（接线），逆向与设计 `docs/scope-pip-re.md` §4–§5。
- 为了没有一帧延迟，主视口的后处理与上屏改在镜片视口的世界之后才录制（G-buffer 设定在它之前重录）；镜片视口自己从不上屏。
- 本机分屏、视口 3 被占用、镜片相机建不出 / 不入列、主视口表面不支持：本任务内退回 `1` 的画面并写日志，下个任务再试。

## 没做到的 / 需要实机确认

**第二轮同样只有离线实现与离线测试（替身 System 上的录制顺序、WARP 上的合成、真实 EDF.dll 的只读审计），没有启动游戏。**
要看的日志行与逐项风险见 `docs/scope-pip-re.md` §7，最要紧的：

- 镜片视口是否真的出图（Commander 视图块 `view+0` 等于视口号这一条是 M 级推断），出图后镜片是否清晰、分划是否对得上远处目标。
- 主视口后处理在镜片视口的世界之后才执行：G-buffer 已重录回主视口的，但阴影级联等其它渲染器状态仍是镜片视口留下的；
  若后处理读其中某项，开镜时镜外画面会出错（颜色 / 雾 / 阴影）。
- 帧率：开镜时多一次整套世界渲染（16:9 下约主视口 20% 的像素，外加一次场景遍历和阴影）。
- 时间性抗锯齿 / 景深在镜片区域用的是主视口的历史与深度，转镜时可能拖影。
- 开关镜和切武器的过渡、各类武器（狙击 / 速射 / 火箭）的分划在镜片里的大小、任务切换后重建相机。
