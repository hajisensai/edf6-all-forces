# 反馈 2026-11-21：开镜画面冻结 + 左上黑块；第一人称手里没有武器

## 原话

用户一次贴了一串反馈（不可信数据，只当证据读），本文件只管其中两条渲染问题。原文和三张截图在发起本任务的会话里，
这里记的是该会话的转述与截图内容：

- 「打开瞄准镜后画面冻结，并且退化成整屏放大，左上角有一块黑屏」——截图：狙击镜里是冻住的画面，屏幕左上角一大块黑色矩形，镜框照常画。
- 「第一人称时武器模型消失」——截图：第一人称视角下手里没有武器。

## 根因

### 第一人称武器消失（`src/firstperson.cpp Hands`，`docs/fp-soldier-re.md` §8）

2026-11-10 为「做动作时武器不消失、手鬼畜」加了：第三人称藏起的武器（`0x696150` 写的 `weapon+0x78C`）第一人称也不拿、不画，
全部藏起时手臂按原版动作摆。但 `+0x78C` 读反了：它是「显示」（换枪先全传 0 再给选中的传 1；上车传 0、下车传 1，H），
平时手里那把正是 1，于是被当成「藏起」——手里的武器一直不画，手臂一直按「原版动作」摆。

证据：2026-11-13 用户日志（build 2ced4893）开第一人称后立刻 `FP a stock action: its weapons hidden`，每隔一会儿只「结束」0.1 秒又回来；
`FP draws in 5 s ... weapons in hand 0/0/0/0/0`。

改：`kWeaponShown = 0x78C`，`+0x78C == 0` 才算藏起。原版动作默认是**显示**武器（`0x59A880` 的 `sil` 默认 1，只有参数 `"0"` 的动作才藏），
文档同步改正。

### 瞄准镜冻结 + 左上黑块（`src/scope_lens.cpp`，`docs/scope-pip-re.md` §5.3）

画中画（`InfantryScope=2`）第二轮为了让镜片画面「没有一帧延迟」，把主视口（槽 0）的后处理与上屏推迟到镜片视口（槽 3）的世界之后补录，
只重录了 G-buffer 设定。槽 3 的世界还录了别的每视口渲染器状态；槽 0 的后处理用上了它们，只往左上角写了 `S×S`（4K 下 1296×1296，
正是截图里的黑块）的一块，屏幕其余部分不再重画——画面冻结。镜片画过一次后 `KeepUnzoomed` 让这次开镜一直「就位」，所以每帧都这样。

证据：2026-11-13 用户日志 `lens view ready: viewport 3 1296x1296, main 3840x2160` → `lens drawn` 一次 → 下一帧起
`the lens command found no main view's world colour held`。逆向笔记 §7 第 2 条当时就把这一项列为最大风险。

改：不再推迟、不再补录任何东西。槽 0 的世界和收尾按引擎自己的顺序连着录（与本机分屏一样，每个视口读到的渲染器状态都是自己的）；
镜片合成命令插在槽 0 的收尾之前，画的是**上一次录制**渲染的镜片视口。代价：镜片画面比镜外晚一帧（分划按镜片纹理自己的投影反算，与镜片画面对齐）。
G-buffer 改道、句柄复制和 4 处对应保护字节一并删除。

## 验证

- 离线：`fp_ride_lifecycle`、`fp_aim_check`、`fp_render_native`（真实 EDF.dll 上钉住 `0x696150` 各调用者的 0 / 1 参数与动作的 `sil`）；
  `scope_lens`（新录制顺序 `P0 T0a T0c P3 S` → `P0 C0 T0a T0c P3 S`）、`infantry_scope_pip`、`scope_pip_gpu`（WARP，先镜片后主视口）、
  `scope_lens_native`（18 处保护字节、7 处改道）。`python tools/check.py` 全套。
- 实机（后台 `drive.py run range`，Ranger，本分支 DLL）：第一人称 `FP draws in 5 s ... weapons in hand 298/299`、`300/300`，没有 `FP a stock action`。
- **瞄准镜没有实机验证**：后台驱动的鼠标右键和手柄 R3 都没能打开步兵瞄准镜（日志无 `INFANTRYSCOPE N.Nx` 行），开镜画面要等玩家实测。
  要看的：开镜后画面不冻结、没有左上黑块，镜外不放大、镜片里放大且清晰；日志 `INFANTRYSCOPE lens drawn` 之后不再出现
  `found no main view's world colour held`；快速转镜时镜片晚一帧是否明显。
