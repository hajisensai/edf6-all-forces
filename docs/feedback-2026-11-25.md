## 验证

- 当前工作树成功重建插件，42 项定向 CTest 全通过。另生成了三份弹幕资源。单机靶场运行结束逐字节核对并恢复安装前的 DLL 和 INI。
- 单机 M001 的后台实机测试用手柄 Back 触发与 M 共用的切换路径。截图确认第三人称视角保留指令面板，地图网格、高度和比例尺只出现在俯瞰视角。测试还未覆盖实际联机开房、洞穴小队接令和坦克绕建筑。
- `feat/ui-rewrite` 在独立工作树调整整备页 Esc 的回退，并修复长提示写出渲染文本缓冲区的问题。底栏按当前列显示操作，弹窗提示随弹窗绘制。该分支本地构建成功，7 项 UI 定向测试通过。

## 需要重现的其余现象

- 波次停住和加载播片的残余顿挫仍需按实际关卡复现。已有压力场景显示 GPU 3D 占用约 3–17%，重场景主要在游戏线程。当前数据还不足以定位尸体休眠、粒子、重寻路、越界弹体或 HUD 中的具体瓶颈。
- 传送舰避让和支援扫射航线仍需原战役场景复测。新版 UI 待与主线整合后实机验收，双机联机待有独立客户端参与时验证。
