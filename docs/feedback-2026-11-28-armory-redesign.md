## 逐条理解

1. **切兵种闪退**：整备武器页把兵种 0 换成 4（载具手）后崩溃（日志 20:09:16，dump `EDF6.exe.173128.dmp`）。原版菜单 3D 预览的工作线程给 0 号槽挂手持武器模型时，读到武器 SGO 里没有 `animation_model`，于是抛 `InvalidVariantException`，栈为 0x93F910 → 0x940100 → 0x93AA00 → 0x6BF380 → 0x6BB890。载具手的载具行和空行（`ZW_V1`…`ZW_V9`、`ZW_VehicleNone`）是从 `aSupportNone` 克隆的，没有这个键。代码只在新兵种分支，修复在 `claude/1128-zw-preview-crash`。
2. **进去时闪一下旧 UI**：选关窗口滑入 / 滑出的约 0.3 s 里，插件不盖画面（`worldmap.cpp` `Still()`）；地图回整备时，要等本部拿回输入才打开整备。原版选关窗口和本部菜单会露出来，三个方向都有：进本部 / 房间自动开地图、地图 → 整备、整备 → 地图。用户给的方向是：改用原版自己最前面那层遮罩做过渡，并重做它的样式。
3. **整备「各种意义上的烂」**：11-24 的方案只照原版视觉画了画板，没做交互设计。之后各分支各自加功能，没有实机走过整套流程。改为按交互重设计稿重做，见 [plan-2026-11-28-armory-redesign.md](plan-2026-11-28-armory-redesign.md)。
4. **世界地图操作难受，要重写**：图钉上显示「这一堆有几关」的数字，没有意义。改成显示任务名和状态；以列表为主操作面，地图跟着列表走（设计稿 07）。
