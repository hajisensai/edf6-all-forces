# 2026-11-28 反馈：天顶截击机换成武库鸟

## 用户原话

> 天顶飞机换成这个。名字可以改一下，这个底下是无人机。一个是无人机模式，一个是全是导弹的模式。

（「这个」指 ACE COMBAT 7 mod「Arsenal Bird (AIAS)」的武库鸟模型，机腹下挂 M101 无人机。）

## 设计决定

- 名字：机体统一叫「武库鸟」（SC）/「武庫鳥」（CN）/「アーセナルバード」（JA）/「Arsenal Bird」（EN），「天顶截击机」不再使用。
- 一个机体，两种模式，在支援栏里是同一行「武库鸟 · 守点 / 跟随 / 出击」（`tools/calls.py` `_catalog` 按 SC 名分组，出击排在同名的守点 / 跟随后面）：
  - **导弹模式**＝原来的天顶截击机出击（7808 `sortie_missile_rain`，ID 和 ini 键 `SORTIE_MISSILE_RAIN` 不改），只换名字、说明和模型：
    整舱导弹齐射，一轮后飞出地图。
  - **无人机模式**＝新增的守点 / 跟随两个呼叫（7122 `ARSENAL_BIRD` / 7123 `ARSENAL_BIRD_F`，按 `RELEASED` 规则追加），
    `JetRole::arsenalCarrier` → Body::arsenalCarrier（标记 7071）：照 Helicarrier 母舰的飞法盘旋，机腹逐架放出 M101（标记 7072，
    机炮无人机的耐久、武器、AI，缩放到 5.7 m 长），回收、装弹后再出动。
- 地图图标：无人机模式用母舰图标（同 Helicarrier），整行显示第一个条目（守点）的图标。
- 可登乘：Helicarrier 母舰可登乘，所以武库鸟（无人机模式）也可登乘（旋翼母舰行）；M101 照机炮无人机（固定翼行）。两者都没有请求来自驾的孪生
  （模型在模型包里）。导弹模式只飞一轮就离开地图，不登记登乘。
- 联机：支援目录多了两项（其后条目序号后移两位），母舰放出的机炮无人机按母舰标记解析机体（武库鸟放 M101），所以房间协议 26 → 27，
  旧版本不能进新房间（房间类型按协议号区分，进房时拒绝并在公告里写明两边的协议号）。
- 没装模型包（`arsenal_bird` 文件夹）时三个呼叫都不出动，日志一行，不退回旧外观（不做兼容层）。
- 细节见 `docs/feature-support-jet-models.md` §6.6、§8。
