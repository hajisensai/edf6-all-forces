# PvP 实验场：空空 / 地地组合对战（实验性功能，设计草案，2026-10-23）

状态：**设计草案**。建立在已合入 main 的两块能力之上（见 §1），新增的只有“对阵卡 + 对局规则”这一层。现有两块能力本身也**还没有实机 / 双机验收**（各自文档写明了），所以第一批测试要先验它们。

用户原话（2026-10-23）：
- 「现有能力 可以优化，问题不大」
- 「玩家可以操纵怪物啊」「玩家操纵怪物 现在已经有代码了啊」
- 「先做空空/地地为主 空地联合出一个就行。主要是实验性功能，所以希望主要测试各种组合方案」

---

## 0. 结论

1. 对战的底层已经有了：**对战模式**（房主开启，每人选阵营 1 / 2，敌对雷达、锁定、支援归属）和**敌方单位操控**（M 地图里接管 34 类原生敌人和 4.1 移植敌人，开对战后受控体跟随操作者阵营）。M 地图「摆放」能放敌人和载具。
2. 缺的是**对局层**：开局阵容、出生位置、禁止换乘 / 脱离、胜负判定、重生、计分、结果记录。这一层做成 **对阵卡**：一局 = A 方单位 × B 方单位 × 规则模板 × 地图。卡片放数据表，加一张卡就是加一行。
3. 以 **空空**（§4）和 **地地**（§5）为主，**空地联合只做 1 张**（§6）。
4. 空位由 AI 补：EDF 一方用插件的 NPC 驾驶 / 飞行，怪物一方用原版敌人 AI。所以一个人也能先把很多组合测一遍。
5. 每局记录指标（§7），按数据判断哪个组合好玩、哪个失衡，再调参数或删卡。

## 2. 对阵卡

### 2.1 字段

| 字段 | 例 |
|---|---|
| `id` | `AA-1` |
| A 方 / B 方 | 每个席位：单位（EDF 单位或可操控敌人的 SGO）、数量、真人 / AI / 任意 |
| 规则模板 | 决斗 / 歼灭回合 / 票数战 / 非对称生存（§3） |
| 规则开关 | 伤害倍率、锁定、雷达、重生秒数、补弹、能否离开 / 换单位 |
| 地图 | 指定或随机（标签：开阔 / 城区 / 山地 / 海上 / 测试场） |
| 测什么 | 这张卡要回答的问题 |

数据表照 `tools/calls.py` 的做法：一份 Python 数据生成插件侧 `.inc`，CI 用 `--check` 校验。

### 2.2 开局流程（新做）

1. 房主在 M 地图对战面板选卡（或按标签随机），开对战；成员选席位，阵营由席位决定。
2. 按卡片在双方出生区**摆放**单位（复用摆放的全员事务）：EDF 载具 / 飞机空车摆好，怪物摆成敌人。
3. 真人入席：EDF 席位直接上车 / 入座（飞机在空中开局）；怪物席位直接走「操控此单位」。
4. 空席位交给 AI：EDF 载具派 NPC，怪物保留原版 AI（阵营改成该方）。
5. 卡片设了“不能离开”时，禁止下车 / 返回原玩家；单位被毁 = 该席位阵亡（用户巨人战场草案里的设定）。

## 3. 规则模板

| 模板 | 规则 | 适合 |
|---|---|---|
| **决斗** | 1v1，无重生，先赢 3 局 | 单位对单位的基准 |
| **歼灭回合** | 小队对小队，无重生，全灭一方算一回合，五局三胜，回合间可换单位 | 阵容组合 |
| **票数战** | 有重生（默认 8 秒，回出生区重新入席），每队 N 票，扣完即输；限时到了按剩余票数 | 人多、混编 |
| **非对称生存** | 一方少而强（巨型怪物 / 王牌），一方多而弱；弱方要在限时内击杀强方，否则强方赢 | 巨型怪物、群 vs 精英 |

共用开关：

- **伤害倍率**：EDF 武器 / 怪物伤害随星级、难度、等级放大，两边数值体系不同。先用每方一个倍率把单局时长调进目标区间；数据不够再考虑按单位类别归一。
- **锁定**：开 / 关 / 只开机炮（空战卡用）。
- **雷达**：开 / 关（关了才有伏击、贴地飞行的价值）。
- **补弹**：无 / 定时 / 回出生区。

GG-6 把用户草案里的设定都保留成卡片参数：
- 1v1：巴尔加型号自选，对手随机。

区别是怪物一方也可以由真人操控，空位由原版 AI 补。

## 6. 空地联合（只做一张）

**SG-1 空地双人组（2v2）**

- 每队 1 名**空中席**（战斗机 / 直升机 / FlyingDyno / UFO 任选）+ 1 名**地面席**（任意兵种 / 坦克 / 防空车 / 巴尔加 / 地面怪物任选）。
- 每队出生区有一个目标（摆放的固定物件或大型怪物）和 2 门 AI 防空炮（AutoTurret 防空车自瞄）。打掉对方目标即赢；限时 6 分钟，到时按击杀分。
- 票数战，空中席被击落 15 秒后重生，可换单位；三局两胜，第二局交换出生区。
- 测什么：空地配合是否成立（飞机独自冲目标会被防空打掉，要等地面先拆防空，或先在空中把对方飞机打下来）；怪物单位混进来是否失衡。

## 7. 测试与记录

每局结束写一份结果（日志一行汇总 + 一个 JSON），可以用 `tools/testhub.py case` 挂到测试站对应的用例下：

| 指标 | 来源 |
|---|---|
| 卡 id、双方单位、真人 / AI 席位、地图、开关 | 对阵卡 |
| 胜方、单局时长、回合数 | 对局层（新做） |
| 每个单位的输出 / 承受伤害、击杀、死亡原因 | 现有伤害统计（来源 × 目标） |
| 平均击杀时间、锁定次数 / 导弹命中率 | 伤害统计 + 锁定日志 |

判卡标准（初定）：
- 对称卡多局胜率 35%～65%；非对称卡强方胜率 40%～60%。
- 决斗一局 1～3 分钟，歼灭回合 2～4 分钟，票数战 8～12 分钟。
- 自由组卡里每种单位都有人选、都有击杀。
- 不达标就调伤害倍率和开关；调不动的组合删卡。

## 8. 测试顺序

| 批次 | 内容 | 前提 |
|---|---|---|
| 0 现有能力验收 | 两机：开对战、选阵营、互相锁定 / 雷达、直击和爆炸伤害、死亡；一方操控怪物打另一方 | 现有代码，不需要新做 |
| 1 单人跑组合 | 不开对战：玩家操控怪物，对手是摆放的 EDF 单位（或反过来：玩家开 EDF 载具打摆放的怪物）。先粗筛 GG-5～GG-10、AA-6～AA-9 的手感和数值 | 现有代码 + 手动摆放 |

| 3 双机跑卡 | 空空、地地全部卡真人对真人；AI 补位 | 批次 0 通过 |
| 4 空地联合 | SG-1 | 批次 3 |

批次 0、1 不用写代码，现在就能开始；批次 1 的结果决定哪些卡值得进批次 2。

## 9. 需要拍板的问题

1. 伤害先只用“每方一个倍率”，还是一开始就按单位类别归一？
2. 重生回出生区重新入席，怪物席位是重新摆一只同款怪物，还是可以换？
3. 第一人称做成规则开关，还是固定某些卡强制？
