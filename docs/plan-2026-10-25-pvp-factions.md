# 对战：带名字的多阵营、角色、房间锁定与房间界面（方案，2026-10-25）

用户原话（2026-10-25）要点：对战地图默认在房间里就能选阵营并显示；4 人以上不要手动翻页，面板往下自动叠加，不必照原版；改原版房间 UI；阵营不只 1 / 2，要带名字（怪物、星岛者、外来者、EDF1 / EDF2……），星岛者和外来者能混战；有指挥官职业（M 视角）和选具体怪物出生；原生只有 7 个队伍号就改队伍；不兼容旧版本，旧版本直接不让进。

底层依据见 [team-manager-re.md](team-manager-re.md)。现有对战协议见 [plan-2026-10-23-pvp-modes.md](plan-2026-10-23-pvp-modes.md)、`src/pvp.h`。**本文是方案，未实现、未实测。**

## 1. 概念：阵营 ≠ 队伍号

- **阵营**：带名字、颜色、允许的角色。阵营表是数据（插件内置 + ini 可加），不是原生枚举。
- **队伍号**：开打锁定时给每个出场阵营分一个原生 team。原生 0..6 保留原义（1 敌、2 友、5 空车、6 环境、3 中立），对战阵营用扩出来的 7 号及以后，互不冲突。
- **对局关系**：每两个阵营之间友 / 敌 / 中立，由预设或房主自定义生成，锁定时整张表算好。

内置阵营（第一版）：

| 阵营 | 角色 | 说明 |
|---|---|---|
| EDF（可开 EDF1、EDF2 等多支） | 四兵种、载具驾驶、指挥官 | 多支 EDF 之间默认敌对 |
| 怪物 | 选具体怪物出生（原生 34 类） | 所有怪物一个阵营 |
| 星岛者（5、6 代） | 选具体单位出生 | 与外来者默认敌对，可设结盟 |
| 外来者（4.1 代） | 选具体单位出生（4.1 移植敌人） | |

关系预设：混战（全员互敌）、人类对外星人（星岛者 + 外来者 + 怪物 一边）、EDF 内战（EDF1 对 EDF2，怪物打两边）、自定义（房主逐对设）。

## 2. 原生扩队伍

- 插件安装时（TeamManager 已由 `0x701488` 建好、还没有对象用到新号）在锁内调用原生 `0x5E2950` / `0x5E27E0` 把行数和每行关系向量扩到 N（暂定 16），新行对角线 1、其余 0。只用游戏自己的容器函数，不手搓 vector。
- 改写死 7 行的 `0x5E0C80` 循环（`0x5E0D28 cmp rsi, 0x188`）改为按 `+0x48` 遍历。
- 钩 `0x5E1E90` / `0x5E1F90` 尾部：原版重置后，如果有已锁定的对局，按锁定表重写 7 号以后各行与 0..6 的关系；没有对局时新行保持中立。
- 本插件里写死 `<7` / `<=6` 的地方（team-manager-re.md §5）全部改成读行数。
- 出生 / 呼叫 / 生成时写死的 1 / 2：本插件生成的东西按「请求者阵营 → 队伍号」走；原版任务脚本生成的敌人仍是 1，对局关系里决定 1 与各阵营的关系（例：怪物阵营直接映射到原生 1，就能和任务原有怪物同队）。
- 雷达友方组 `0x82BB42`、任务倍率、清怪计数：雷达已有 PvP 包装，改成按关系表取友方；倍率 / 清怪在对战地图（PR #251 那几张图永不结束）里不影响，普通任务不开对战时保持原样。
- 先查：`SetTeamDamageAdjust`、`EventFactor_Team*` 的按队数组是否固定 7 项；联机时客机关系表是否各自生成（是的话各端按同一锁定表写即可）。

## 3. 房间：选择、锁定、版本门禁

- **选择**：房间菜单「对战」页，每人选阵营 + 角色（+ 具体单位）。房主选关系预设。选择经 EDF6Coop 成员属性广播，只是声明。
- **锁定**：房主按开打时先不开打：收齐全员选择，配平「自动」，生成锁定表（版本号、成员 PUID → 阵营 / 角色 / 单位、阵营 → 队伍号、关系矩阵），作为房主属性发出；各成员把版本号写回自己的属性。全员回执齐了才放行原版开打。期间有人改选择，版本号作废重来。**待逆向：开打按钮的回调（房间状态 +0xAC0 = 6 的入口），在那里拦。**
- **进任务**：各端按锁定表改队伍、扩关系表、生成角色。原有 Prepare / Apply / Final 只确认「原生已生效」，不再决定阵营；任务中 M 地图面板仍可改（走原协议，改动同步回锁定表版本）。
- **版本门禁**：房间公告所需插件版本（Coop 房间数据），新客户端版本不符自己不加入；不认识公告的旧客户端，进房后几秒内没有发出匹配版本属性，房主用原生拒绝 `0x12C8820`（Coop `joinlog.cpp` 已钩）踢出。不写兼容分支、不降级。

## 4. 角色

- **兵种 / 载具**：沿用现有。
- **指挥官**：主视角 M 地图（现有地图指挥、支援呼叫、摆放），指挥本阵营 NPC 与支援。本体先按「出生点附近无敌、不可被锁定」做，之后再定是否不生成本体。
- **具体单位出生**：开局在本阵营出生点生成所选单位，自动走敌方单位操控接管（现有 34 类 + 4.1 移植）。玩家人体停在安全点并隐藏；单位死亡后按对局规则复活（第一版：倒计时后在出生点重生同种单位）。

- 删掉 Coop 的翻页（`multislot/src/roomview.cpp`），由新的成员列表接管面板构建：不再用原版 4 项模板表，按人数逐行往下叠，每行名字、阵营色块与名字、角色 / 单位图标、准备 / 锁定回执状态。人多时缩行高，再多才滚动。这部分在 Coop 仓库做。
