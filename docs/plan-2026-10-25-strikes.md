# 一次性打击呼叫（2026-10-25）

用户给了 20 种打击的参考方案（直升机 / 战机打一轮就走、组合、远程炮击），原话：「这个制作方案不一定要照抄，参考就行」「攻击都做，
实现方案可以随你」。现实名字（喀秋莎、海马斯、战斧……）只当打法描述：弹和飞机全用游戏与本仓库已有的东西。

置信度：H = 反汇编 / 源码直接读到；M = 推断；L = 待实机。

## 1. 两套底层

### 1.1 远程炮击（#12–#20）：插件弹 + 逐发导引

- **呼叫武器**：`brings='barrage'`，模板仍是 KM6（`eWeapon051`，RadioContact）：瞄准态给目标点和航向，原有的
  `airstrike.cpp RadioStartHook`（0x6A8DFB 的 IFC_Start）认出标记后把架数清 0，原版轰炸机不来。不进 `kCalls`，
  不占支援目录号，M 地图不列。伤害 / pt 用 `flat_curve`（任何星级同值，同天罚）。无线电台词清空。
- **弹**：一份 SGO `EDF6VC_BARRAGE_ROUND.SGO`，从原版 `DEMOINDIRECTFIREE50.SGO`（DemoIndirectFire，RocketBullet01，带尾烟）
  派生：重力 0、寿命 30 s、伤害 0（插件写）。粗细 / 爆炸半径每发运行时写 IFC（`RoundSize` / `RoundBlast`）。
  另有空爆用的冲击弹 `EDF6VC_BARRAGE_BURST.SGO`（`_emc_charge` 配方）。
- **逐发编号**：IFC 配置 0x2B6AC7 把 AmmoHitSizeAdjust（#8）写到 IFC+0x104（H），开火时整块 InitParam 拷进子弹 core
  （core = 子弹 +0x140，偏移 = IFC − 0x70 + 0x9A0），子弹出生 0x231EEF 读 core+0xA34 × core+0xA30 得命中半径（H）。插件每发
  弹单独一个 DemoIndirectFire，开火前把 +0x104 写成 `0x3F801000 | 槽号` 的浮点位（≈1.0005，命中半径几乎不变）。
- **导引**：RocketBullet01 vtable 0x17A38E8 第 5 槽 update 0x287E40（H），它在 0x287F50 调 core 步进 0x235D50。插件包住第 5 槽：
  认出编号的弹，在原 update 之前写 core 速度（core+0xB90，米/秒，H：autoturret re-notes）、清 core 重力（core+0xBA0），
  速度 = (航迹在下一帧的点 − 当前位置) × 60。航迹是纯函数（`src/barrage_plan.h`），所以抛物线、高抛垂直俯冲、贴地巡航
  + 跃升俯冲、弹道导弹、分裂子母弹都是同一套。RocketBullet01 撞地 / 撞物即按爆炸半径爆（原版行为），寿命到期不爆（H，
  carrier-laser-re §3）：子母弹分裂时把母弹寿命拨到头（静默消失），同点发冲击弹闪光 + 子弹。
- **发射点**：在目标「来向」反方向 1.2–5 km（按种类），钳在 Havok 世界内（`WorldHalf() − 200`）。**地图外生成的弹会不会被删
  没有证据（L）**，钳在世界内是这一点的保守做法；实机看到弹在世界边缘消失再调。
- **联机**：RadioStartHook 对远端玩家的呼叫也会跑（airstrike.cpp 注释，H 代码路径）。每台机器按同一份输入（目标点、航向、
  种类）和种子（目标与航向的位哈希）本地重放整场炮击；弹的 owner 是呼叫者的副本，`ShellMake` 的 `OnlineShotCounts`
  只让呼叫者那台机器计伤害（同天罚，H）。HIMARS 的分目标在各机本地选（敌人位置各机略有差异，伤害以呼叫者为准）。

### 1.2 出击（#1–#11）：支援部署 + 一次过境

- 走现有支援部署（场外入口、真实机组、全员确认），呼叫表 `tools/calls.py` 的 `sortie` 字段（`SORTIE_PASSES`，即 `crew.h
  SortiePass`）经 `SupportAircraft::sortie` 传到 `ActivateSupportAircraft`：喷气机 `SortieBegin`（`src/jet_sortie.cpp`），直升机
  `HeliSortie`（`src/heli.cpp`）。出击呼叫没有守点 / 跟随两种，进 `kCalls`（M 地图支援栏、局内切换都能用）。
- 过境线（`src/sortie_plan.h Line`）：沿飞机进场方向，穿过标记点；编队里各机保持横向间距（最多 80 m），三架轰炸机铺三条带。
- 打完：喷气机 `Withdraw`（`Away` 爬升飞离玩家，出视野后由支援调度删除机体和机组），直升机 `StartLeave`（同普通呼叫）。
  找不到目标 45 s 或飞过标记点也收手；燃油（150–180 s）兜底。
- 武器全是飞机自己的原生挂载（各机都看得到的原生弹），开火仍走 `jet_combat.cpp Fire` / `heli.cpp Fire` / `DoorGun`；出击只改
  进场、打谁、何时结束：导弹每发换一个目标（`SortieStruck`：打过的目标 +4000 评分），锁定保持 0.7 s、发射间隔 0.7 s（原 2.5 s）；
  导弹猎手的直升机导弹间隔 1.2 s（原 `HeliMissileMs` 4 s）。

- 第二波（`then` / `then_after`）：第一波请求被本机受理后（武器呼叫或 M 地图都走 `SupportCallComposedAt`），由**呼叫者那台机器**
  在 25 s 后对同一点再发一次支援请求（`airstrike.cpp SupportFollowUpQueue / Tick`）。被拒（单机时另一项支援还在核实路线）则每 3 s
  重试，最多 10 次；联机时房主那边的拒绝不重试（日志 `SUPPORT second wave ... accepted=0`）。
- 支援调度原有的 30 s 全局冷却已删除（用户 2026-10-25：「支援调度 30 秒的全局冷却 删掉不就好了，以后限制我用pt来做」）。

- 与方案的出入：直升机（布鲁特 / Eros）没有火箭挂载，#1 用机炮和导弹；#10 用制空战斗机（支援部署不能带无人机：无人机没有座位，
  支援入场要真实机组）；#11 的「标记」就是炮艇机绕圈开炮。

## 3. 待实机确认

1. 插件弹在世界边缘附近（发射点）是否存活、远处是否可见（`use_far_render`）。
2. 写 core 速度后 RocketBullet01 的姿态 / 尾烟是否跟着速度走（update 把 core 矩阵拷到 +0x60..+0x90，矩阵由谁按速度更新未追）；
   core 步进（0x2364D0）有没有对火箭再加速度（会让每帧有一点超前，下一帧按实际位置纠回）。
3. 远端玩家呼叫时 RadioStartHook 的目标点 / 航向是否与呼叫者那台完全一致。
4. 截击机的空空导弹（AIM-54 / AIM-120）能否锁定地面目标（#8）；锁不上就只会飞完航线撤离。
5. 各出击的高度、速度、距离（`sortie_plan.h` 常量）是否合适：低空过境会不会撞楼、导弹锁定窗口够不够。
