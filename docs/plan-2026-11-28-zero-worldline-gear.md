# 零号世界线：主角载具与武器清单（交接用）

来源：测试站大纲 3「平行世界：零号世界线干涉行动」和设定集（https://edf6.fushi.moe/design.html ，#36–#49），2026-11-28 与维护者对话确定。本文是给实现者的清单：要加哪些载具和武器、各自做成什么样、在仓库里套哪条现成管线。

数值只写相对档位（和原版同类、同等级的武器比），具体数字由实现者按星级曲线调。

## 0. 两个主角怎么落到兵种上

游戏只有 4 个玩家兵种（`docs/loadout-re.md`：0..3 = 游击兵 / 飞行兵 / 空降兵 / 重装兵），本仓库没有新增兵种的先例。所以两个主角都用「原版兵种 + 新外观 + 专属装备」来做。外观按 `docs/edf41-outfits.md` 的做法新增，不顶替原版外观。

| 主角 | 底子兵种 | 理由 |
|---|---|---|
| 冷战载具手 | 空降兵（AirRaider） | 只有空降兵有载具槽（分类 306–309、320）；呼叫点正好当「后勤点」用。 |
| 以太主角（刻印剑士） | 重装兵（Fencer） | 原版近战分类只有重装兵有（200 ShortHammer、201 ShortPile）；跳跃推进器（206）的连跳可以先当「踏阵」。 |

以太主角要求「能飞」。原版能量飞行只有飞行兵有，飞行兵却没有近战分类。所以先用重装兵的推进器连跳做出踏阵的手感，真正的滑翔 / 悬停放在第二期，由插件做（见 §2.1）。

## 1. 冷战载具手（主世界线 1983，解放军装甲兵）

玩法（设定集 #36）：
- 装备栏只有载具，外加一把固定的 54 式手枪。
- 每关开局坐在选好的载具里入场。
- 车被打爆后用手枪自保，攒后勤点呼叫补车。
- 载具按战役进度解锁，关卡里也能缴获「完好的车」，开到撤离点或撑到关卡结束就解锁这一型。
- 已删掉、不要做的：接管友军的车、战场残骸修复。

### 1.1 载具清单

都是新增的插件载具，走现成管线：
- 在 `tools/calls.py` 的 `CALLS` **末尾追加** `Call(..., 'vehicle', ...)`。不能插队，否则会打乱已发版存档的武器行。
- 在 `pylib/vcobjects.py` 的 `GROUND_VEHICLES` 加定义。
- 写一个 `tools/make_<名>.py` 生成器，接口照 `tools/make_tos1.py`。
- 改完跑 `python tools/gen_calls.py`，把 `src/calls.inc` 一起提交。

### 1.2 入场与补车

1. **开局坐在载具里入场。** 仓库里没有现成功能。最接近的是 `src/boarding.cpp`（登车狙击枪，`docs/boarding-re.md`）和 `docs/insertion-re.md`（支援单位入场）。做法：出生后由插件生成玩家选的那辆载具，并把玩家放进驾驶位。联机下每个客人都要放进自己的车（维护者要求所有功能都支持联机，插件消息走 `src/plugin_net.h` 的通道注册表）。
2. **后勤点补车。** 直接用空降兵的呼叫点（击杀积累）。改的是交付方式：车由 NPC 从地图边缘开来、开到玩家身边下车交给玩家；直升机飞到附近降落。**不做空投。**
3. **解锁。** 战役进度按 V 表的「解锁」列开放；关卡缴获在关卡里放一辆「完好的车」，开到撤离点或撑到关卡结束就解锁这一型。

### 1.3 54 式手枪

| 项 | 内容 |
|---|---|
| 设定 | 解放军制式手枪，装甲兵随身配枪；固定携带，不占载具选项 |
| 手感 | 8 发弹匣，单发，威力低（只够清身边的小虫子），换弹快 |
| 落点 | **待定**：空降兵没有枪械分类（只有 302 支援、303 炸弹、305 特殊、306–309 载具、310–314 呼叫、330–334 无人机），要么借一个分类放手枪、要么由插件给它单独一个下车时可用的武器位。实现者先评估再定，并回头更新本文 |

## 2. 以太主角（以太世界线，以太联军刻印剑士）

设定集 #37。一战风格的以太联军军官制服加短披风，飞行时背后和脚下浮出刻印光阵。

**统一特效：** 以太蓝紫色光痕，刃口偏白；命中点炸开一个小型刻印光阵。所有武器共用一套光阵贴图和光痕材质，按武器换尺寸和颜色强度。

### 2.1 飞行：刻印推进「踏阵」

- 一期（原版能力就能做）：用重装兵的跳跃推进器（206 `Weapon_Heavy_Support_Booster`）连跳。每次起跳脚下生成一个刻印光阵特效，手感就是「空中踩阵再跳一次」。
- 二期（插件）：
  - 新增一个「以太槽」，飞行、滑翔、悬停都耗它，落地回充。
  - 光阵浮游炮「七星」和战锤「坠星」的空中下砸也耗这个槽（多射就少飞）。
  - 风险：重装兵本身没有能量槽，要插件自己维护一个槽并画 HUD。

## 3. 实现顺序建议

1. 冷战载具 V1–V4（开局四辆）+ 后勤点补车，先让主世界线能玩。
2. 开局坐车入场（含联机）。
3. 以太主角外观 + M1、R1、R3（全靠现成分类），一期踏阵特效。
4. V5–V9、关卡缴获解锁。
5. M2、M4、M5、R2 的插件部分，以太槽（二期飞行）。
6. M3 回旋刃、R4 信标、54 式手枪落点（都是待定项，要先评估）。

## 4. 不在本清单里

- 以太联军 NPC 的载具（设定集 #15）、冷战各国 NPC 的部队和载具（#6、#13）：关卡用，不是主角装备，另列。
- 4 代 / 6 代暴风一号：就是原版玩家，不加专属装备。
