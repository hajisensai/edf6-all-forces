# 2026-10-07 open PR integration review

Scope: `edf6-all-forces` PRs #65–#73 and their interaction with
`edf-coop-stable` PR #23. All nine all-forces PR heads are retained as merge
parents, so their individual histories remain reviewable.

## Findings and resolutions

- **#65, cave commands:** a rejected floor below the reference height ended the
  scan even when a nearer, standable lower floor remained. Stop only after an
  accepted lower floor. The regression models a roof, an intermediate floor
  without headroom, and a usable lower floor; it fails with the old condition.
- **#70, mech NPC driving:** family detection read a slot already replaced by
  `InputHook`. Use stable vtable identities. The regression replaces slot 4 on
  all four mech families before testing driver eligibility and map commands.
- **#69, installer preferences:** fresh/default-only installations could miss
  the defaults-migration marker, allowing later reinstalls to undo user choices.
  Persist the marker on both paths. Lifecycle tests disable each migrated option
  and verify a subsequent install preserves the user's file.
- **#68 + #72, player guns:** retain `Shooter::localPlayer` through
  `PlayerSideGun -> GunShot -> Shell`, for both cannon and gatling. Mutating
  either call loses the integration guard.
- **#67 + #70 + #72, door guns:** retain the shared gun state and refill policy,
  local medic aiming without taking over the player's trigger, and the early
  return for another machine's player. Removing the remote-player gate fails
  the integration guard.
- **#71 + #72, bullet collision:** keep the offline path free of candidate-body
  lookups, while allowing an online local player's round to spare its vehicle.
  The installed-hook regression exercises both paths using the real player
  identity predicate.
- **#71, existing fixes:** retain per-hand weapon vetoes, recruited-player
  ownership, leader-change command invalidation, family update hooks, and the
  independent sidecar/aircraft hook behavior.

- **#66, launch heat:** latch overheat immediately when launch heat reaches the
  limit, before frame cooling can hide the transition. The production-function
  regression fails on the original launch path.
- **#66 + #72, drill replication:** send versioned flight/return/home snapshots
  through the tank's native NetworkObject channel. Remote copies update their
  real bone pose without local keyboard input or independent damage simulation.
  Replay watermarks cover 1024 senders; periodic snapshots recover a lost launch
  or catch. Session/object reset and driver-change cases are exercised.
- **#23 + #72, empty-seat authority:** empty, expired and unregistered NPC driver
  seats select the host consistently. Only a live registered current driver uses
  the stock runner. This avoids simultaneous host/client plugin authority after
  a client leaves and the host seats an NPC. The drill's control epoch follows
  the same current-driver rule and rejects the preceding driver's queued packets.
- **#23, attacker lifetime:** the native ReferenceId function consumes its weak
  argument by value. Pass an incremented local copy rather than consuming the
  GDI's resident reference. The regression executes the real DLL function through
  the production forwarding path, including send failure.
- **#23, large rooms:** player sync tracks now use the room's 1024-player bound,
  rather than a separate 64-entry table. Replacing the fix with 64 causes the
  new full-room regression to fail; restoring it passes 13,079 checks.

- **#73, tailgate model:** review the removal predicate, retained vertex rows,
  seam reconstruction and winding against the native model. Restore the existing
  bone/launcher-retention assertions to the executing test body; the PR had
  accidentally placed them after a helper's unconditional return.

## Validation boundary

The final combined plugins and native offline checks compile with MSVC `/W4 /WX`
using three build workers. All 73 CTest entries passed without skips, and the
installer/data self-test passed 107/107 with the real Root.cpk data enabled.
The separate native drill transport test passed all 24 checks against the
installed EDF.dll; this executable is not part of the 73 CTest entries.
The late #73 model change subsequently passed 6/6 model-shape tests with the
real Root.cpk, including complete archive generation and retained bone checks.

The coop capacity/statistics revision passed 81/81 tests without skips. The
subsequent weak-reference and empty-seat changes passed all 12 targeted hit and
plugin-load tests; the native hit test executed 206 checks against EDF.dll.
The statistics test now examines the full active sending interval, rather than
mistaking a final idle statistics period for a failed classification.

The medic data was generated and read back from the installed game's original
data in memory. No game installation or running game was modified. Source and
native/offline tests do not establish two-machine gameplay, flight feel, healing
effects, or large-room performance; those still require game sessions.
