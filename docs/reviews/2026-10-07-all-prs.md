# 2026-10-07 open PR integration review

Scope: `edf6-all-forces` PRs #65–#72 and their interaction with
`edf-coop-stable` PR #23. All eight all-forces PR heads are retained as merge
parents, so their individual histories remain reviewable.

## Findings and resolutions

- **#65, cave commands:** a rejected floor below the reference height ended the
  scan even when a nearer, standable lower floor remained. Stop only after an
  accepted lower floor. The regression models a roof, an intermediate floor
  without headroom, and a usable lower floor; it fails with the old condition.
- **#70, mech NPC driving:** family detection read a slot already replaced by
  `InputHook`. Use stable vtable identities. The regression replaces slot 4 on
  all four mech families before testing driver eligibility and map commands.
- **#69, installer preferences:** fresh/default-only installations could miss
  the defaults-migration marker, allowing later reinstalls to undo user choices.
  Persist the marker on both paths. Lifecycle tests disable each migrated option
  and verify a subsequent install preserves the user's file.
- **#68 + #72, player guns:** retain `Shooter::localPlayer` through
  `PlayerSideGun -> GunShot -> Shell`, for both cannon and gatling. Mutating
  either call loses the integration guard.
- **#67 + #70 + #72, door guns:** retain the shared gun state and refill policy,
  local medic aiming without taking over the player's trigger, and the early
  return for another machine's player. Removing the remote-player gate fails
  the integration guard.
- **#71 + #72, bullet collision:** keep the offline path free of candidate-body
  lookups, while allowing an online local player's round to spare its vehicle.
  The installed-hook regression exercises both paths using the real player
  identity predicate.
- **#71, existing fixes:** retain per-hand weapon vetoes, recruited-player
  ownership, leader-change command invalidation, family update hooks, and the
  independent sidecar/aircraft hook behavior.

## Validation boundary

The combined plugins and native offline checks compile with MSVC `/W4 /WX`.
The intermediate integration passed 69 CTest entries. The final counts and drill
network validation are recorded with the finishing integration commit.

The medic data was generated and read back from the installed game's original
data in memory. No game installation or running game was modified. Source and
native/offline tests do not establish two-machine gameplay, flight feel, healing
effects, or large-room performance; those still require game sessions.
