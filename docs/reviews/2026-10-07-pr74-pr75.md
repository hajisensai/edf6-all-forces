# PR #74–#77 review

Reviewed heads: #74 `d6c847e`, #75 `514b635`, based on main `175ac09`.

## Confirmed findings

- #74: cooling contacts filled the first eight scan slots before cooldown was
  checked, starving later enemies. Filter them during collection. The production
  EnemyRam regression covers a fresh ninth contact and preserves cooldowns.
- #75: insertion of the 32nd target compared against an uninitialized tail slot,
  excluding later nearer targets. Compare against the tail only when already full.
- #75: a global pose scratch buffer made one mech's muzzle, axe and funnel docks
  consume another mech's pose. Each Mech now retains its own computed pose.
- #75: compacting live target slots changed the meaning of a funnel's saved index.
  Remap by object identity; a lost target follows the existing reacquisition path.
- #75: the no-model fallback request still referenced unavailable custom weapons,
  causing clean installation to fail. Preserve the native Eros request setup and
  derive dependencies from the actual request, including upgrade/downgrade cases.
- #75: standalone test ranges omitted custom weapons/beam resources and failed
  to share their ownership with installed content. Generate and retain them in
  the range ledger; removing either owner preserves the remaining consumer.
- #75: the remote player's Rider::other path treated the mech as idle, with no
  custom action/state replay. Native vehicle position and ordinary holder shots
  are distinct from the missing guard, axe, cannon, funnel and joint animation
  state. The completed native snapshot path now replays these states without
  remote input, AI decisions, positive damage or physics ownership. The wire
  preserves object/driver epochs and per-sender sequence watermarks; stale shield
  state is rejected. See [sazabi-online.md](../sazabi-online.md).

## Validation boundary

The initial combined code built with MSVC /W4 /WX, passed 76 CTest entries without
skips, and passed 110 installer/data self-tests against the real Root.cpk.
The completed network integration passed 80 CTest entries without skips. Its
native application packet was measured at 905 bytes against the 1170-byte limit;
505/drill and 506/Sazabi receive hooks were exercised together in a private test
process. The optional zero-damage audit verifies propagation through native
parameter/GDI/attenuation operations; zero damage can still enter hit callbacks,
so this is not proof that every enemy type has no secondary reaction.
Targeted regressions exercise production functions and fail with the corresponding
old behavior restored. Assets were built and checked in private worktree/temporary
directories; the game installation and running game were not modified.

The model sources are intentionally not tracked or fetched in CI. Without them,
the corrected package installs a genuine Eros fallback in the stable Sazabi call
row. A local package can include the available model sources. Offline/native tests
do not substitute for two-machine gameplay or visual acceptance in game.
