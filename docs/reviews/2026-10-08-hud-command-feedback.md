# 2026-10-08 HUD 与小队指令后续反馈

本轮以 main@c21f499 为基线；没有启动游戏、写游戏安装目录或进行双机游戏验收。

## 行为

- 地图小队、图例、命令和挂载使用视口内的统一布局预算；遮挡世界文字的面板同时发布输入区域。常态载具八挂载、状态、切换提示和飞行仪表不再分别占据同一底部空间。
- M 内小队行可点选，亮色挂载行可切换；灰色项只读。点击只改变选择和预瞄，不开火。主线程复核实际人、车、座位、武器、弹药及快照编号；渲染只读取 SRW 锁保护的完整快照。
- UI 起点的左键、Ctrl 左键、右键拖动由 UI 捕获，拖到世界中也不穿透。失焦、过期画面、换分辨率、换车换座取消旧手势。相机拖动在本帧捕获判定之后运行，原标记键边沿先锁存。
- 命令列表接受真实 NPC 司机；显示和执行共享 500ms 有效期。混合职业按实际成员和空席选车，驾驶/炮手/乘客优先；以发起玩家所乘车辆为优先，不误用房主车辆。
- 本机 AI 权威直接执行。远端小队只读展示并发送认证 RPC，由房主校验真实 PUID、关卡 epoch、原生对象 ID、队伍归属和脚本控制。重复请求不重复执行，结果按请求关联。混合本机/远端选择使用同一阵形索引，房主重新验证守点地面。
- 不适用于所选单位的按钮置灰；分组、合并及阵型编辑尚无联机协议，联机时置灰。基础小队命令支持权威转发；旧版房主明确返回协议不可用。
- 固定、单轴或无法确认可动结构的武器使用真实炮口/弹道标记，不再拿相机目标距离替换物理交点。双管逐管计算，只保留一个瞄具主体。黄叉表示预测地形命中，空短横表示没有地形命中，不代表击中敌人。见 fixed-weapon-sights.md。

## 证据

整合后的生产 DLL 和 offline_checks 构建成功，编译并发限制为3。本地36项定向 CTest 全通过，无跳过，覆盖地图输入/身份、挂载点击/并发快照、全 HUD、固定武器、NPC 实际执行、命令编码与身份解析、既有支援网络等相邻路径。原生身份解析与武器安装关系使用本机受支持 EDF.dll/Root.cpk；HUD 图片来自生产绘制函数加模拟场景。

常态 HUD 新压力场景在旧源码产生79项失败；固定炮口旧逻辑在22项生产检查中产生6项失败。恢复修复后通过。快照并发检查包含5000次发布和大量读取，无撕裂；渲染读取测试用不可读取的游戏地址证明访问器不再解引用原生对象。

完整远端 CI、最终包及合并状态以 PR #89 的最终 HEAD 为准。本轮没有修改 Coop ABI；沿用上轮配套 Coop，但房主与客机均需更新全军出击才能使用新增命令 RPC。
