# 常态载具 HUD：挂载区域重叠

根因不是某个按钮偏了几像素。旧布局分别把 StockBlock 末尾固定在 `0.80H`、
挂载放在 `H - 110s`（八挂载再减一行），切换提示另外向上占 64s，三者没有共享
区域预算。高 HUDScale、窄视口和中文长名字时，栏外文字、重复弹药行、banner 会
覆盖状态和 controls。直升机仪表和 RWR 使用固定中心偏移，放大后还会离开屏幕。

修复：

- 挂载按实际文字宽度决定列数，最多四列并自动换行；每行图标、名字与弹药使用同一尺度。
- 统一底部 dock 预算，包含全部挂载、controls 和独立的切换提示区；按预算同时缩放
  几何与文字，保留全部八个挂载和完整切换按键提示。
- 地面载具状态块与 RWR 排在 dock 上方，弹药由挂载区展示，删除状态块重复的弹药行；
  重装填信息仍在对应挂载格显示。原版武器量表继续由既有 cover 机制让位。
- 直升机速度/高度/RWR 的宽度按视口限制；俯仰梯形的完整线段与标签裁剪到中央
  飞行仪表区域，避免线段穿过状态、挂载和按键区。

`hud_view` 运行真实 `HudPublish → HudDraw`、quad/text recorder，而不是只比较两个
独立 panel。新增地面/直升机两种场景，各覆盖 1920×1080、1440×1080、1024×768、
960×1080 和 HUDScale 1 / 1.5 / 2 / 3。四语言共 40 个压力场景，验证八个长名字
加一个切换提示全部出现、controls 没被盖掉、原版量表已让位、文字不越界/互相覆盖、
renderer 创建/释放平衡。现有所有 HUD 场景也通过。

负对照：同一新增 fixture 换回 `c21f499` 的 `hud.cpp`，报告 79 项布局失败；恢复修复
后 `hud_layout` 通过。`EDF6VehicleCrew` 使用 `-j3` 编译通过，两个相关 Python 接线
检查通过。以 Root.cpk 的原版字体生成并人工检查 4:3、窄屏与高 HUDScale 的离线
截图；未运行游戏，字体测量仍为现有 recorder 的近似，未声称游戏内验收。
