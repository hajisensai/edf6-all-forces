# PR 77 review: ground exits and replicated rocket racks

Reviewed `1ab4376` and integrated main `ff94092`, retaining the NPC gunner
authority and medic healing fixes. The old draft finding recorded in
`2026-10-07-pr74-pr75.md` was still present in this snapshot.

## Fixed findings

- **P2: below-bridge exits moved through the deck.** `MapGroundNear` selects the
  nearest height, not proof that a soldier is inside the floor. Ground at y=0,
  deck at y=6 and legal feet at y=3.5 caused a warp to y=6.05. Both the native
  seat exit watch and sidecar step-off now first query below the feet. An existing
  lower floor prevents upward correction; only no-floor-below cases may use the
  nearby upper surface. This deliberately leaves ambiguous penetration into an
  upper floor to native movement instead of guessing through another level.
- **P2: an exit watch outlived its rider lifecycle.** Mission reset with reused
  Human storage, death/revival, or disabling the plugin could keep the previous
  ride pending. These transitions now clear the watch. Production-path fixtures
  cover reset/address reuse, death/revival, disable, watch expiry, and actual
  below-surface correction.
- **P2: a remote Katyusha hid its entire rack after the first shot.** Native
  replay `0x692540 -> 0x696FD0` reaches ammunition decrement `0x69820E`, but does
  not populate `burstLeft` at +0xE18. Thus every remote round has the long
  interval, and the old renderer started reloading all 16 rails on every shot.
  Rail visibility now follows `(AmmoCount - ammoRemaining) % 16`, the same
  counter used for native muzzle selection. The loading interval is used only
  after a complete salvo. The offline fixture compares local and remote rails
  every frame through all 160 shots, exhaustion, and reload boundary cases.
