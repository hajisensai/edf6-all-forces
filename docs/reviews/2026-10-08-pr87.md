# PR #87：放大瞄具视野与直升机距离分划

审查基线 `7bf8275`，并合入含 EDF5 默认启用修复的 main。

确认并修复三项问题：

1. `scopeview::RectHalf` 在窄屏只限制宽度，破坏炮舰机传感器的 4:3 比例。现在同时缩小高度，保持比例并适应视口。
2. 圆形遮罩外圈只比最远角点多 4 像素，没有计入 64 边形的弦内缩。在 7680×4608、15360×8640 和偏心视场出现角落漏暗；现在按 `cos(pi/64)` 补偿外圈。原版新增检查 8 项失败，修复后 826 项全部通过。三角条带的绕序与 HUD 原生 Seg 一致，无须修改。
3. `SazabiLockButton` 与 `SightZoomButton` 默认同为 R3，原实现一次按下同时锁定和放大。现在沙扎比驾驶座的冲突按键优先硬锁，键盘 Z 与不冲突的手柄绑定仍可放大。关闭锁定绑定或沙扎比控制器后释放 R3。原生产代码的负对照准确触发该失败；修后缩放生产路径 154 项通过。

直升机新分划继续使用同一逐帧弹道：继承速度先从 m/frame 转为 m/s，进入 LaunchVel 后除以 60，还原为同一初速。只读核对本机 Root.cpk：506 加特林 speed=4、alive=40、gravity=0；409 为 4/120/2；410 为 6/120/2；三者 OwnerMove 均为 0。零下坠武器的投影刻度可重合，绘制层会省略过密刻度，不额外伪造弹道下坠。
