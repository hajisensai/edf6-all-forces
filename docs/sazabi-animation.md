# 沙扎比：动作与行为（动画器）

代码：`src/sazabi_anim.h`（动画器，纯数学、只有头文件）、`src/sazabi_pose.h`（骨架、站姿、脚底采样、IK 原语）。
离线：`tools/sazabi_pose_check.cpp`（24 个场景按 60 Hz 推进并逐帧校验）、`tools/sazabi_pose_view.py`（在真模型上渲染）。

## 为什么重做（2026-10-09，用户：「现在做的太烂了」）

离线渲染旧版逐个动作看到的硬伤（全部能在旧版 `sazabi_pose_view.py` 输出上复现）：

- **举盾**：盾被转成水平横板架在肩上，没挡在身前；举盾时步枪仍平举。
- **挥斧**：手臂直直举过头、斧柄横着，躯干不转，下半身不参与；斧在手里 1.6×3.4 m 的刃，远看根本看不见。
- **走路**：只有前后一个方向——横移、后退时脚在原地前后蹭，身体平移（滑步）；原地转身整台机体像雕像一样转。
- **切换**：拔斧时步枪直接缩成 0 消失；没有收斧、取枪的过程；所有动作之间没有过渡（参数直接跳）。

根因不是参数，是**表达方式**：旧版所有手臂动作都是「在源模型的绑定姿势上叠相对角度」，而源模型两臂不对称
（右前臂垂在大腿外、左前臂前伸持盾），叠出来的盾和斧朝向不可控。

## 现在怎么做

动画器 `Anim` 是有状态的（弹簧、计时、武器状态），每台机器每帧自己推进（`sazabi.cpp Pose`）。
它需要的东西全部能从已复制的数据推出：移动方向和速度来自速度，原地转身来自 `yawRate`，挥斧状态来自 `swing/combo`，
特殊武器来自 `special`。所以**联机包不变**（`sazabi_net.h` 没动），远端看到的动作和本机同一套逻辑。

### 手臂：解析双骨 IK + 绝对朝向（`SolveArm`）

每只手给出「腕部到哪、肘尖朝哪、手/前臂朝哪」（`ArmGoal`），肘由余弦定理解出；每段骨按「绑定时的轴和弯曲侧」→
「现在的轴和弯曲侧」整体转过去。于是：

- 步枪：手的 +z 就是枪管，`AimGoal` 直接让它沿瞄准方向（误差 < 2°，离线校验），后坐力抬枪口、腕后缩；
- 盾：盾面只能垂直于前臂，所以举盾 / 亮盾（导弹）时**前臂横在胸前**、盾面朝前或朝瞄准方向（`ShieldFront`）；
- 战斧：手的 +z 是刃口、+y 是柄指向刃的方向；关键帧直接写「刃口往哪砍、斧头指向哪」。

### 武器状态机（`StepWeapons`，两端一致）

- 拔斧：第一斩的蓄力前段（`kDrawShare`）里，右手先把步枪挂到右后腰（`kRack`），再到左前臂盾内侧取斧，光刃点亮；
- 三段连斩（斜劈 / 横斩 / 兜头劈），每段：预备 → 蓄力 → 斩（加速通过）→ 收势，躯干扭转、前倾、左脚踏前、下蹲都跟着关键帧；
  手腕走 Catmull-Rom 曲线，手的朝向球面插值；
- 收斧：连斩后持斧待机 `kAxeHold` 秒，然后把斧放回盾上、从后腰取回步枪、举枪（`kStowSec`）；按开火键立即收（`kStowQuick`）；
- 玩法门控（只加了这两条）：**步枪在手、举到位、不在胸炮支撑姿势里才开火**（`RifleReady`，否则子弹会沿着下垂的枪管飞），
  **盾转向瞄准方向后才放导弹**（`ShieldReady`，约 0.2 s；按键请求锁存 0.4 s，点按也能发射）。模型没有沙扎比骨骼
  （没装新生成的模型）时不门控。连斩后按开火：0.32 s 收斧取枪再开火。
- 状态被打断（收斧途中又开斩、拔斧中途被打断）时右臂从当前位置交叉淡化 0.12 s，不瞬移；收斧时步枪已挂腰则再开斩直接去取斧。
- 无人驾驶 / 远端断线时不再读陈旧的速度和转向（否则会原地踏步）；联机包里的 `gait` 仍按动画器相位推进，旧版本对端也能看到迈步。
- 远端没有开火键：从复制过来的后坐力 `recoil` 推断「开过枪」来收斧；盾转向导弹方向只在本机可见。

### 步态（`StepGait` / `Legs` / `Gait`）

- 任意方向的 2D 步伐：步子沿速度方向，髋部转向移动方向的 70%（最多 40°；后退时转向反方向），腰和胸再拧回瞄准方向；
- 横移步幅只有前进的 55%：髋外展有限，长侧步曾把骨盆压低 2.3 m（实测，现与前进一致）；
- 慢速时步子变短变密，被踩住的脚始终跟地面同速（不打滑）；
- 停下：步子继续走完并逐渐收拢（不是瞬间滑回站姿）；
- 原地转身：脚先留在原地、髋部滞后（最多 40°），超过 18° 就迈一组步子转过来；
- IK 初值：按髋到踝的距离用余弦定理给膝盖弯曲初值（从直腿出发时，跑步摆腿会掉进「大腿踢到极限、膝反折」的错误解，
  踝在目标后面 5 m —— 离线检查抓到的）；
- 前倾：随跑速和加减速，沿移动方向；落地下蹲走弹簧。

### 举盾、亮盾、格挡（2026-10-09 第二轮）

用户实机：「缺少举盾效果，举盾和右键攻击重叠了」——右键（护盾飞弹）的亮盾姿势和举盾几乎一样。现在：
- 举盾：前臂横在胸前、盾面朝前、机体下蹲、左肩前送（`ShieldFront`）；
- 亮盾放导弹：盾竖举在左前上方、盾面对准瞄准方向（`ShieldRaise`：肘在肩前下方，腕在肘正上方一个前臂长）；
- 格挡：举盾挡下正面一发（`SazabiMessage` 减伤时 `PoseInput::blocks` 加一，两端都加）→ 盾被震回 `kBlockBack`、胸后仰、膝内收，
  欠阻尼弹簧弹回；本机再放一声金属撞击（`SzSfx::shieldBlock`，`vsynth.h ShieldBlock`，连发时最多每 0.12 s 一声）。

### 次级运动

肩甲随上臂转 35%；头追瞄准（有延迟）；背后推进罐、浮游炮舱随加减速摆动（欠阻尼弹簧）；放出浮游炮时炮舱张开；
切换特殊武器时头部扫一眼对应装备（导弹→左侧盾，浮游炮→上方，胸炮→低头）；站久了重心左右换脚。
