# 星导者群体合体机（敌方）设计与实现计划

EDF.dll TimeDateStamp 0x678CCB46。新增一种**敌方**空中单位：一架「核心」带着十几架小型无人机组成一个整体飞行；
核心被打掉后无人机散开各自追打玩家；任何一架被打爆后，残骸笔直冲向玩家被打爆那一刻的位置，砸地爆炸。

## 1. 为什么用插件驾驶的 506 机体，而不是原版敌人

原版星导者无人机（`E507_GOLDUFO`，类 `UfoSmall507`）的移动、开火、死亡全在原版 AI 里，要编队就得逆向它的运动控制、
死亡与 ragdoll，而且没法在游戏里试（用户在玩）。插件已有一整套在游戏里跑通的 506 机体链路：运行时生成（`SpawnJet`）、
每帧飞控（`Hover` / 姿态 / 离地）、开火字节（0x2020 机炮 / 0x2021 炸药）、同一编队子弹互相穿过（`docs/bullet-pass-re.md`）、
带队伍过滤的点爆炸药（`docs/decoy-blast-re.md` 1.4）、模型管线（`pylib/jet_models.py`）。合体机全部建在这条链路上，
只是队伍设为敌方（1），外形换成星导者的模型。

## 3. 怎么出场

任务脚本（或测试场）像放置喷气机一样放一架核心，放置点要离地至少 15 米（核心的碰撞盒伸到原点下方 10.9 米；测试场把出生点抬高 40 米）：

```
Preload("app:/object/edf6vc_swarm_core.sgo", -1);
CreateFriend("点名", "app:/object/edf6vc_swarm_core.sgo", 1.0, false);
```

插件第一次看到它（JetFrame，按标记 7012 认出）就把它改到敌方队伍（`SetTeam` 保持登记）、按 ini 放大耐久，
随后每帧最多生成 3 架成员（`SpawnJet` 直接以敌方队伍生成），排成编队。没装成员机体时核心单独飞。

## 4. 行为

- **合体**：核心绕玩家盘旋（半径 `SwarmRange`、高出玩家 `SwarmHeight`），机头对着玩家；每隔一段时间从玩家头顶低空穿过一次。
  成员按编队槽位（以核心朝向旋转的「飞翼」形）贴着核心飞：速度 = 核心速度 + 位置误差 × 增益。各自把机头（含俯仰）对准玩家，
  对准且在射程内时按「打 1.6 秒、停 2.4 秒」的节奏开火（错开相位）。核心的重炮对准即开火。同一合体机的子弹互相穿过。
- **散开**：核心进入残骸状态或消失后，剩下的成员各自绕玩家飞（半径、高度、方向按槽位错开），继续开火。
- **死亡行为（残骸冲锋）**：原版扣血 `hp = clamp(hp - dmg, [+0x2F0], [+0x2F4])`，只有 `hp ≤ 0` 才判死亡（0x547C30：0x54815F 夹紧、
  0x54840B `comiss 0, hp` 后置死亡字节）。插件正在驾驶的合体机，它的伤害消息（0x10000000）经 body506 的消息钩子先到
  `SwarmMessage`：只在这一条消息的处理期间把下限设成 1，原版处理完立即恢复（`MessageRestore`）。所以致命一击后它停在 1 HP，
  插件看到就把它转成残骸：记下玩家此刻的位置，HP 设成最大值的 4%，机体翻滚着直线冲向那个点（不追踪），
  离点很近、贴地（阈值按碰撞盒最宽的一半加余量：无人机 6 米、核心 14 米）、被挡停或 12 秒后引爆自带炸药（敌方队伍，伤玩家和友军），
  0.3 秒后删除。冲锋途中再被打一下就按原版坠毁，炸药不响——等于在空中拆掉。
  插件没在驾驶它（`Enabled=0`、`JetPilot=0`、驾驶员没了、这一步出错被跳过）时不拦截：它按原版被击毁，不会留下打不死的敌人。

## 5. 配置（`EDF6VehicleCrew.ini`）

`Swarm`（总开关）、`SwarmUnits`（成员数，默认 12，0–16）、`SwarmHpScale`（耐久倍率）、`SwarmRange`、`SwarmHeight`、`SwarmFire`。

## 6. 风险与验证

- 敌方队伍的 506 + RideAi 假驾驶员开火时子弹的队伍归属、敌人计数、玩家能否锁定：静态逆向见 `docs/swarm-team-re.md`。
  结论：载具队伍每帧按乘员重算（0x630250），RideAi 的假驾驶员写死 team 2（0x6331CC），所以 `SwarmTeam` 把驾驶员改到 1
  （reg=false）再改载具，生成时和每帧（含引爆那几帧）都做；子弹 / 炸药队伍取载具的（weapon +0x214）。
  失去驾驶员的合体机队伍变 5，crew.cpp 的 autoCrew 不给它派友军驾驶员。
- 游戏在用户手里运行，本轮只做构建、静态核对和离线生成（`python tools/make_jets.py` 的 build 不写游戏目录的部分）；
  实机清单见 README「批量实测清单」新增行。
