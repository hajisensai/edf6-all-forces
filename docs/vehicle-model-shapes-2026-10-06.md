# 喀秋莎侧板与边三轮模型修正

本次只改生成模型的几何。模型源是用户本机 `Root.cpk`，仅以只读方式打开；没有安装、覆盖或修改游戏目录。派生产物和预览在独立工作树的 `build/model-review/`，不提交游戏资源。

## 喀秋莎

- 从 V607 卡车嫁接网格中拆去左右货箱侧板和侧板后端锁扣，共 472 个三角面；保留床板、尾板、驾驶室、车架和三轴轮胎。
- 先按原卡车测量发射架安装高度，再拆侧板，避免因为侧板消失而降低发射架。骨骼绑定矩阵、炮口、发射架、液压杆与原模型一致。
- 回归按三角面的完整顶点字节检查保留部分（位置、UV、法线、蒙皮），并执行模型归档往返、骨骼、8 根导轨 / 16 枚火箭、炮口及 0–80° 液压杆 / 发射架间隙检查。

## 边三轮

- 斗口高度由 1.18 m 降至 0.92 m，挡板由 1.48 m 降至 1.10 m，座垫降至 0.56 m；低拱甲板与摩托车身比例更接近。
- 修复甲板与船形外壳独立采样导致的鼻部缝隙：甲板的两侧和尖端直接引用外壳口沿顶点，三角网格没有零面积面。
- 补贯穿横梁、地板纵梁、摩托连接点上斜撑和边轮后斜撑，使斗体与车轮有明确的承力连接。
- 保持总宽度、乘员定位 `(-1.0, 0.30, 0.35)`、地板碰撞体与上下车接口。实际 Ranger 模型测得腿 / 胯半径约 0.296 m，座舱最近壁面 0.361 m；侧斗离摩托 0.144 m，轮胎离地误差 −0.0064 m，挡泥板净空 0.056 m。

## 复验

不读游戏的网格回归：

```powershell
python tools/test_vehicle_model_shapes.py
```

读取指定游戏的 `Root.cpk`，在内存里生成并复验两种模型（不安装）：

```powershell
python tools/test_vehicle_model_shapes.py --game 'D:\steam\steamapps\common\EARTH DEFENSE FORCE 6'
```

共执行 5 项回归通过；其中 2 项要求显式传入游戏目录。`run_checks()` 可接入现有 selftest，默认只跑 3 项不读游戏的回归。

预览来自真实生成 MRAB 的纹理和网格：`sidecar-comparison.png`（上下为修改前后）、`sidecar-after.png`（含 Ranger 站位与碰撞体）、`katyusha-before.png` / `katyusha-after.png`（斜视、侧视、俯视）。只做了离线生成和渲染验证；游戏内光照、动态动画及联机乘坐未在本次验证。
