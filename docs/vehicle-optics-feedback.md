# 载具实体瞄具视角（2026-10-08）

此前 `sightzoom.cpp` 只写 FOV，原版第三人称镜头的位置没有改变，所以开镜仍从车后看整台载具。
现在开镜同时使用已安装模型的实体瞄具定位骨作为眼睛、当前所选武器的真实炮管方向作为视线；
调用原生 `EDF+4E220` LookTo，写入 CharacterGhostCamera 的世界矩阵 `+220`。未给炮口加任意高度/距离偏移。

`optic_mount.h` 仅接受 `vc_optic_00..15` 定位骨。定位骨由真实镜片几何或原生近眼镜头制作；
其父骨必须在当前枪 holder 的有效模型祖先链内，并且是最近的唯一匹配。场景根、同层歧义、
没有定位骨、过期的武器选择、燃料/未知弹种均不会凭空得到瞄具。没有对应瞄具仍可使用原有火控 HUD，
但不能把第三人称放大当作开镜。能量武器由 `RoundModel.style` 决定 sensor 类型，不能按 SolidBullet 工厂假扮加农炮。

相机原函数先运行，再应用实体瞄具。下一帧只撤回仍与自身写值相等的 FOV/矩阵；地图、俯瞰及其退出过渡、
离座、切枪、死亡、配置关闭、弱引用失效和任务重置都会停止瞄具写入。其他相机所有者后写的矩阵保留。
`SightZoomMounted` 给炮塔控制器报告当前真正的实体瞄具状态；该状态由炮塔控制器维持原生炮轴输入，避免把
上一帧镜头炮轴反过来当第三人称自由镜头的新目标。相机只操作当前传入且确认为本机玩家的 camera。

验证：`sightzoom_test` 执行生产相机 hook 和模型/武器挂载选择，覆盖真实眼位、相机恢复、换枪、无瞄具、
歧义与地图互斥。可传真实 EDF.dll 启用 native 模式：DONT_RESOLVE_DLL_REFERENCES 私有映像、指纹验证，
仅接通 LookTo 所需四个 CRT 数学导入，生产 hook 实际调用原生 LookTo；未执行 DllMain 或运行游戏。
真实资源及安装链由瞄具模型生成器的独立测试覆盖；完整游戏渲染、双机和实际操控仍不等同于这些离线检查。

镜头所有权按实时人物、座位、载具弱引用、所选武器与任务重置判定，不使用 200 ms 墙钟寿命。
暂停和慢帧保留已开的实体镜头；暂停菜单中的按键不会被当成恢复后的新按键沿。断开座位/人物死亡/
模型失效仍即时撤回相机，不靠延长 TTL 掩盖生命周期。生产回归实际跨过旧 200 ms 窗口测试暂停、
恢复菜单按键和慢帧，另验证失去骑手引用立即退出。

## 2026-10-14 补齐主炮瞄具（第一人称炮手镜）

盘点所有可乘坐、带可转炮塔火炮的座位（Root.cpk 原版 + 插件生成载具），所选主武器挂载链上缺 `vc_optic_` 的补了三台：

| 车型/选枪 | 来源面（贴图核对） | 父骨 | 眼位（米） |
|---|---|---|---|
| Blacker 403 主炮 | 炮塔圆顶顶沿左侧（炮手侧）观瞄块，Material4 object/mesh 2/0 三角 1586–1587 | cannon_main | (0.910, 2.097, 0.794) |
| Grape 401 遥控炮塔 | 炮塔顶瞄准头圆筒的茶色窗，Material6 object/mesh 0/3 三角 4905–4906 | Battery | (-0.167, 2.589, -0.945) |
| E551 EDF6 特典涂装 | 与 V505_TANK 相同的 Light02 前向潜望镜面 | cannon_main | (0.604, 2.127, 0.724) |

403 的观瞄块装在 12 边形圆顶的斜面上，镜面法线偏离炮膛线 30°；`Lens.bore` 让定位骨原点仍取镜面质心、+z 取父骨炮膛方向（运行时只读原点，视线由所选武器炮口方向给出）。这是观瞄窗而非与火炮同轴的望远镜，玩家若不接受可只删这一条。

未找到真实镜面、保持无实体瞄具的：Kepler 603（炮塔正面只有贴图橙色块，无玻璃几何）、Maser 510（Light01–05 是发射器辉光/车灯/侧灯）、Naegling 402 / 402 特典（发射箱无观瞄，潜望镜在车体驾驶位）、皮卡炮车 610（开放式炮架）、插件自制双炮自行炮 EDF6VC_ARTILLERY（纯色炮塔盒，且生成模型不在 MODELS）、钻头车 EDF6VC_DRILL（非火炮）、普罗透斯 / 大贝加尔塔炮架（沿用 2026-10-08 结论）。E551 EDF4/EDF5 涂装的模型不在 Root.cpk。

验证：`tools/vehicle_optics_check.py --game`、`tests/vehicle_optics_native_audit.py <EDF.dll>`（同时修了审计在同一模型多镜头间沿用上一镜头炮塔转动状态的问题，以及对无镜头的座舱模型去读 SGO 的问题）、`cabin_view.py --bone vc_optic_00` 预览。未启动游戏。
