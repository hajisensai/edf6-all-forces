# 测试站数据与权限边界

## 登录和分组

Worker 在读取业务数据或静态页面前验证现有的账号、签名会话或 HTTP Basic。只有登录页及其脚本、样式可公开读取。
普通账号始终使用账号所属组，忽略客户端指定的其他组；开发者可以选择组。接口不返回账号密码或签名密钥。

## MOD 剧情列表

`story_missions` 单独存储各组的自创剧情，与 `outline`、`proposals` 和游戏任务文件无写入关联。
读取、编辑、删除和移动前均按组查询目标。作者和开发者可以编辑、删除；同组成员可以调整顺序。
参考地图只能引用服务器关卡目录中的键；制作状态使用固定枚举，每组最多 1000 关。

威胁模型包括跨组访问、越权改写、跨站提交、文本注入和高频写入。
所有 SQL 参数绑定；文本沿用策划页的清洗与长度限制，页面使用文本节点展示，不解析用户 HTML。
写操作沿用同源检查、JSON 内容类型检查、正文大小限制和每账号写入限额。CSP 禁止内联脚本。

排序采用相邻行之间的数值，间隔耗尽时事务重编号。并发移动可能形成同值，列表以行 ID 保持确定顺序；多人同时编排时以最后一次成功写入为准。
本功能不提供历史版本恢复；删除前页面明确确认目标关卡。数据库迁移只创建新表和索引，可重复执行，不改动已有策划或反馈。
