两个包都要下：主包（插件、联机修复、安装器）和模型包（载具模型与 EDF4.1 素材）。主包的安装器会检查模型包版本，对不上会拒绝安装。 模型包分成几个 zip 时，每一个都要下载，并全部解压到同一个文件夹。 「下载」用分片加速：每块 4 条连接并发下载，逐块校验 SHA-256 后写进你选的文件，校验不过的块不会落盘。 Chrome / Edge 会先问保存位置；其他浏览器只能下载 1.5 GB 以内的文件（在内存里拼好再保存），更大的请用「普通下载」。 用下载工具（IDM 等）或分片下载失败时，也点「普通下载」。

You need both: the main package (plugins, co-op fix, installer) and the model pack (vehicle models and EDF4.1 assets); the installer refuses a model pack of another version. When the model pack comes in several zips, download every one of them and extract them all into the same folder. "Download" fetches each file in checked chunks (Chrome / Edge ask where to save; other browsers only manage files up to 1.5 GB). For download managers, or when it fails, use "Plain download". Installation steps in English: INSTALL-EN.txt inside the main package.
